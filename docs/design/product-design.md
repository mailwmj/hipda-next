## 1. 为谁、做什么
- 用户：HiPDA 的老用户。高频操作依次是：刷帖子列表、读长帖（翻页、跳楼层、看引用）、看图、快速回复、看短消息和提醒。
- 设备：单手用的手机；折叠屏合上时当手机用，展开后边看列表边读帖；平板；分屏时的窄窗口；手机横屏。
- 目标：读得舒服，找得快，回得顺手。所有复杂的事都由系统处理，用户只管看帖和回帖。
- 功能范围与现有应用一致（tech-plan §1）。删除的只有：举报（旧版是假提交，用户决定删除）、检查更新（已失效），以及第 7.10 节列出的、可以由系统判断或随旧界面一起消失的设置项。

## 2. 设计原则（每条都对应第 10 节的验收）
1. **系统能判断的，不留给用户。** 编码、主题、图片加载策略、阅读位置、登录续期、Cloudflare 验证，都由系统自动处理。
2. **此刻没用的，就不出现。** 不显示数值为 0 的角标；刷新按钮和不再有用的提示不常驻；安全提问的答案框只在选了提问时出现；失效的功能直接删除。
3. **能替人做的，就直接做。** 草稿自动保存；发送失败时内容保留，可以原地重试；离开再回来，从上次读到的地方继续。
4. **同一件事，处处一样。** 一套术语、一套组件、一套动效语言。
5. **按下去有回应，再按能收回。** 按下立即有反馈；收藏、关注、删除这类操作立即生效，可以撤销。
6. **不打断人手上的事。** 错误在出错的地方原地提示，不弹窗；新消息只用角标提醒；刷新时不把人拉回顶部；在前面的页回复后不把人拽到末页。
7. **常用的好做，会丢东西的难误碰。** 回复入口在拇指够得到的位置；清除登录信息要确认，删除能撤销；去掉双击就跳页这类容易误触的手势；常用但不会丢东西的操作（切换已保存的账号）不加确认。
8. **界面自己说明自己。** 不加不必要的次级标签和说明文字；当前处于什么模式（例如“只看楼主”）始终看得见；空状态和错误状态直接告诉用户下一步能做什么。

## 3. 信息架构
一级目的地 4 个：**论坛**、**消息**、**搜索**、**我的**。旧版的抽屉菜单取消，抽屉里的每一项都有新位置（见下表和附录 A 的 S05）。

| 目的地 | 内容 | 旧版对应 |
|---|---|---|
| 论坛 | 顶栏：当前版块名，右侧动作“发新帖”（图标按钮）和“更多”（排序：按回复排序 / 按发帖排序，按版块记住）。顶栏下面是一行版块标签：第一项固定为“今日新帖”，后面是用户关注的版块，可横向滑动；这一行的最右侧固定一个“管理版块”图标按钮，不随标签滚动。标签行随顶栏一起，向下滚动时收起，向上滚动时露出 | 抽屉里的版块、“新帖”、右下角发帖按钮、版面选择 |
| 消息 | 顶部分段标签 `短消息 \| 提醒`，各自显示未读点；两者的未读数加起来显示在导航的“消息”角标上。“提醒”标签的顶栏有“全部已读”。点一条短消息打开对话；点一条提醒打开对应的帖子并定位到目标楼层（短暂高亮），打开即算已读 | 抽屉里的短消息、提醒；通知悬浮按钮 |
| 搜索 | 搜索框（提示：搜索标题、正文或作者）。没输入时显示“最近搜索”和筛选胶囊（版块、标题/全文、作者）。粘贴或输入站内地址时，结果第一行是“打开这个链接”，点一下直接打开对应的帖子、版块或用户 | 抽屉里的搜索；列表菜单的“打开站内地址” |
| 我的 | 顶部是账号卡（头像、用户名，点进“账号”）；下面依次是：收藏与关注（两个标签 `收藏 \| 关注`，各自保留滚动位置）、我的帖子（两个标签 `主题 \| 回复`）、浏览历史、设置 | 抽屉里的我的帖子、我的回复、收藏、关注、历史、设置；长按头像退出 |

- 未读提醒：只在“消息”图标上显示角标，没有未读时不显示。
- 二级页面（不是一级目的地）：帖子详情、用户资料（`资料 | TA 的帖子` 两个标签）、看图、编辑器（发新帖、回复、编辑）、登录、账号、设置的子页。
- 在单栏里，导航胶囊只出现在一级目的地的页面上，进入二级页面时随页面推入一起退场。

## 4. 自适应布局
### 4.1 窗口分档与导航形态
先看高度，再看宽度。宽度指应用窗口的宽度（不是屏幕）。

| 条件 | 典型设备 | 导航形态 | 内容 |
|---|---|---|---|
| 高度小于 480dp（不论宽度） | 手机横屏、折叠屏外屏横拿（797–968dp × 约 411dp） | 紧凑胶囊（见第 5 节），向下滚动时收起 | **一律单栏**，正文最大行宽 680dp 居中 |
| 宽度小于 600dp | 手机竖屏、折叠屏外屏、分屏窄窗口 | 底部悬浮胶囊，向下滚动时滑出屏幕，向上滚动时回来 | 单栏 |
| 宽度 600–839dp | Z Fold 6 内屏竖拿（约 744dp）、Pixel Fold 内屏转 90°（约 701dp）、小平板 | 底部悬浮胶囊，**相对整个窗口水平居中**，浮在两栏之上，不占横向宽度 | 宽度 ≥ 680dp 时双栏：列表 300dp，详情占剩下的宽度（至少 380dp）；小于 680dp 时单栏 |
| 宽度 840dp 及以上 | Pixel Fold 内屏竖拿（约 841dp）、平板 | 左侧导航轨，宽 80dp | 双栏：列表默认宽 = 去掉导航轨后剩余宽度的 35%，限制在 320–420dp 之间；详情占剩下的宽度 |

- 分界都按实际窗口宽度判断，不按机型。具体机型尺寸只作为截图测试的样本（见第 10.1 节）。
- **分隔线**：两栏之间是一条 1dp 的分隔线，**不占布局宽度**；它的拖动热区宽 48dp，横跨在两栏边缘之上。所以“300 + 380 = 680dp”就是双栏的门槛，700dp 的窗口一定是双栏。
- **840dp 断点处的连续性**：列表在 840dp 时为 max(320, 0.35 × 760) = 320dp，加上导航轨后详情为 440dp。跨过断点时详情宽度会变化，这是导航轨从底部移到左侧造成的，只在拖动窗口跨过断点时出现，用 `spatialSlow` 过渡（第 6.3 节“布局变化”）。
- **分隔线的拖动与吸附**：拖动时完全跟手，松手后带着松手速度用 `spatialSnap` 吸附到最近的位置。吸附位置：
  1. **列表收起**（详情占满，沉浸阅读）：只有右栏有内容时才可用；右栏为空时这个位置不存在，拖到最左会弹回默认宽度。
  2. **默认宽度**：按上表计算。
  3. **均衡**：列表宽 = min(0.5 × 双栏宽, 双栏宽 − 380dp, 520dp)，双栏宽指去掉导航轨后的宽度；如果它和默认宽度相差不到 24dp，就不单独设这一档。例：680、700dp 只有两档；744dp → 364dp；840dp → 380dp；900dp → 410dp；1280dp → 520dp。
  - 系统按横竖方向分别记住上次的位置；恢复时如果右栏为空，而记住的是“列表收起”，就改用默认宽度。
  - 详情顶栏有一个按钮在“全屏阅读”和“显示列表”之间切换，效果等同于拖到“列表收起”或拖回上次的宽度。
- **铰链**：屏幕被铰链物理分开（`isSeparating` 为真，例如半折的书本姿态）时，两栏的分界对齐铰链，这条优先于列表和详情的最小宽度：两栏各自最窄可以到 260dp，分隔线固定在铰链处，只保留“列表收起”这一种切换；任一侧不足 260dp 时退回单栏，铺满窗口。此时 600–839dp 的胶囊改为紧凑胶囊，放在有列表的那一栏里居中，不压在铰链上。内屏完全展平时不避让折痕。半折横放的桌面姿态（tabletop）不做特殊布局。
- **键盘**：软键盘可见时（`WindowInsets.isImeVisible`），底部胶囊立即隐藏，不随键盘上推；键盘收起后恢复。
- **字号**：正文和列表标题共 5 档，每档相差 1sp（14、15、16、17、18sp，默认 16sp），再乘以系统的字体缩放。导航胶囊、导航轨和底部工具条里的文字最多放大到 1.25 倍；胶囊和工具条用最小高度（胶囊 64dp），文字变大时长高，不裁切。窗口宽度小于 360dp 时，胶囊只给选中项显示文字，其余只显示图标。
- 帖子正文的最大行宽为 680dp（16sp 中文约 40 字一行），超出部分居中留白。
- 何时双栏由系统决定，没有开关。中等宽度不用 Material 默认的单栏策略，改用上表的规则（tech-plan §7）。

### 4.2 每个页面在各宽度下的布局
| 页面 | 单栏 | 双栏 |
|---|---|---|
| 论坛 | 帖子列表 → 推入帖子详情 | 左：帖子列表；右：帖子详情。没选帖子时，右栏显示安静的占位（图标加“选一篇帖子开始阅读”） |
| 消息 | 分段标签 + 列表 → 对话或帖子详情 | 左：分段标签 + 列表；右：点短消息显示对话，点提醒显示对应帖子并定位楼层 |
| 搜索 | 搜索框、最近搜索与筛选、结果 → 帖子详情 | 左：搜索框与结果；右：帖子详情 |
| 我的 | 菜单 → 子页面 | 左：菜单；右：子页面（收藏与关注、我的帖子、浏览历史、设置） |
| 设置 | 分组列表 → 子页面 | 左：分组；右：子页面 |
| 帖子里点开用户资料 | 推入新页面 | 在右栏内下钻，左栏不变；返回时回到帖子原来的位置 |
| 快速回复 | 底部输入条，随键盘升起 | 在详情栏底部，随键盘升起 |
| 完整编辑器（发新帖、编辑、展开的回复） | 全屏 | 窗口宽度小于 840dp 时，覆盖两栏、水平居中，宽度不超过 680dp；840dp 及以上在右栏内打开，宽度不超过 680dp |
| 看图 | 全屏 | 全屏，盖住两栏 |
| 登录、账号 | 推入新页面 | 覆盖两栏、居中，宽度不超过 480dp |

**双栏的返回栈规则**
- 在左栏点另一条帖子（会话、子页面）时，**替换**右栏的根页面，不压栈。双栏的返回栈始终是 `[列表, 当前项, 当前项内的下钻页…]`。
- 在右栏内下钻（帖子 → 用户资料、帖子 → 站内链接的另一个帖子）时，压入右栏自己的栈。
- 按返回：先退右栏的下钻页；退到右栏根页面后再按一次，清空右栏（显示占位）；再按一次，按一级目的地的规则退出。所以在左栏连点 5 条帖子后，按一次返回就回到“列表 + 占位”，不会逐条回退看过的帖子。

### 4.3 折叠、展开、旋转时的连续性
- 展开：单栏时正在看帖子，就变成双栏——帖子到右栏，阅读位置不变；左栏的列表自动滚到这条帖子并标出选中。单栏时在“帖子 → 用户资料”，展开后左栏是列表，右栏是 `[帖子, 用户资料]`，显示用户资料。
- 折叠：双栏时右栏有内容，就单栏显示右栏的栈顶，返回栈是 `[列表, 帖子, 用户资料…]`，逐级返回，回到列表时停在原来的位置。
- 完整编辑器在任何形态变化后都保持打开，输入内容、光标、已上传的图片都保留；只是按第 4.2 节换成对应的承载方式。
- 正在输入的快速回复、草稿、滚动位置、展开的引用、分段标签的选择，在任何形态变化和进程被回收后都保留。
- 布局切换的动画见第 6.3 节“布局变化”。

## 5. 视觉
- **颜色**：Material 3 配色。Android 12 及以上默认从壁纸取色，只取一个主色作为种子，再按统一规则生成整套颜色；用户也可以从一组预设色里选一个作为种子；取不到壁纸色时用 HiPDA 的品牌色。深色模式保留“纯黑”选项（OLED）。主题默认跟随系统。
- **字体与排版**：使用系统中文字体（暂不做自定义字体导入）。帖子列表标题默认 16sp，行高 1.4；已读的帖子降一级字重并变灰。正文默认 16sp，行高 1.65（行距可选三档：1.5、1.65、1.8）。字号档位见第 4.1 节。
- **形状**：圆角统一分 4 档：小 8dp（标签、按钮）、中 12dp（卡片、楼层引用）、大 20dp（底部面板、对话框）、全圆角（胶囊导航、搜索框、筛选胶囊）。头像统一为圆形。
- **层级**：不用阴影，靠表面颜色的深浅区分层级。只有悬浮在内容上面的东西（导航胶囊、底部工具条、底部面板）才带一层很淡的阴影。
- **顶栏**：纯色，不用毛玻璃。内容未滚动时是 `surface`，滚动后用 `effectsDefault` 渐变为 `surfaceContainer`。双栏时左右两栏各自的顶栏独立变色。
- **毛玻璃**：只用于两处：**主导航**（底部胶囊或导航轨）和**帖子详情的底部工具条**。任何布局下全屏同时最多 2 块。
  - 参数（M4 校准）：模糊半径 24dp；着色为表面色，浅色模式不透明度 70%，深色模式 60%；0.5dp 高光描边（浅色白色 40%，深色白色 12%）；悬浮胶囊下方一层很淡的阴影。
  - 降级：Android 11 及以下、省电模式、系统开了“降低透明度”或高对比度时，改为不透明度 94% 的纯色表面加细描边。降级后文字对比度不低于 4.5:1。
  - 内容延伸到毛玻璃下面滚动；每一栏的末尾留出压在它上面的所有浮层的高度，最后一条内容不会被挡住：单栏列表留“胶囊 + 8dp + 底部手势区”；帖子详情留“工具条 + 底部手势区”；600–839dp 双栏时，左栏留“胶囊 + 8dp + 底部手势区”，右栏留“胶囊 + 8dp + 工具条 + 8dp + 底部手势区”（按胶囊完全可见时计算，不随胶囊收起而变化，避免内容跳动）。
- **导航胶囊**：最小高 64dp；左右各留 16dp 边距，最宽 420dp，居中；距离手势条 8dp。选中项是一个浅色胶囊，切换时滑到新位置。
  - **紧凑胶囊**（高度小于 480dp，或铰链分隔时）：最小高 48dp，只显示图标，选中项加文字。
- **帖子详情的底部工具条**：毛玻璃，含“回复”、页码“第 N / M 页”（点它打开跳页面板）和“更多”。600–839dp 双栏时，导航胶囊和工具条在水平方向会重叠：工具条始终位于胶囊上方 8dp，两者共用一个滚动偏移，胶囊随滚动收起时，工具条落到底部。这时左栏和右栏的纵向滚动都驱动这个偏移：任一栏向下滚，胶囊滑出屏幕，工具条随之落下；任一栏向上滚，两者回来。

## 6. 动效系统
### 6.1 总则
- 动效是为了解释变化：东西从哪来、到哪去、和什么有关。不加装饰性的动效。
- 一套语言：所有动效只从第 6.2 节的令牌里取参数，代码里不能直接写时长、曲线，也不能调用会带默认动画参数的无参 API（见第 10.1 节的扫描规则）。
- 克制：越常用的操作越快。切换一级目的地只做淡入淡出，不做位移。
- 跟手、可打断：凡是和位置有关的动画都用弹簧，新的目标出现时从当前位置和速度接着走，不重新开始。拖动时内容跟着手指走。
- 只动必要的属性：优先只动透明度、位移和缩放（graphicsLayer），不在动画过程中改布局尺寸；必须改尺寸的（展开引用、布局切换）用带令牌的 `animateContentSize` 或面板自带的动画，并检查滚动位置不跳。
- **减少动态效果**：以系统设置为准（动画时长缩放为 0，或开了“移除动画”）。应用把系统的缩放值接到 Compose 的 `MotionDurationScale`；缩放为 0 时，所有过渡 0ms，一帧到位，不留中间状态；数字直接变；不做视差。不另设应用内开关。下面两类不是动画，照常生效：防闪的显示延迟（`loadingShowDelay`，避免加载指示一闪而过）和引用高亮（改为静态高亮，停 `highlightHold` 后直接消失）。

### 6.2 令牌
弹簧参数与 Material 3 `MotionScheme.standard` 的 6 档一致（R2 已对照 androidx 源码）。不用 Expressive 那套阻尼比 0.6 的弹簧，它在高频的文字界面里太弹。

| 令牌 | 用途 | 参数 |
|---|---|---|
| `spatialFast` | 小东西移动：选择指示器、开关、图标位移、按钮按压缩放 | 弹簧，阻尼比 0.9，刚度 1400 |
| `spatialDefault` | 页面推入推出、面板升降、右栏下钻、展开收起 | 弹簧，阻尼比 0.9，刚度 700 |
| `spatialSlow` | 大面积的布局变化：双栏出现或消失、看图的放大和缩回 | 弹簧，阻尼比 0.9，刚度 300 |
| `spatialSnap` | 松手后的吸附和弹回：分隔线吸附、看图下拉未达阈值弹回、面板未达阈值弹回 | 弹簧，阻尼比 0.85，刚度 1400 |
| `effectsFast` | 颜色、透明度的小变化，按压状态层，工具栏显隐 | 弹簧，阻尼比 1.0，刚度 3800 |
| `effectsDefault` | 内容替换时的淡入淡出、顶栏变色 | 弹簧，阻尼比 1.0，刚度 1600 |
| `effectsSlow` | 大面积遮罩、主题颜色切换、高亮淡出 | 弹簧，阻尼比 1.0，刚度 800 |
| `exit` | 所有退场：取对应入场令牌，刚度 × 2.0，阻尼比改为 1.0（不过冲） | 由入场令牌换算 |
| `spinnerPeriod` | 不确定进度圈转一圈 | 1000ms，线性，无限循环 |
| `skeletonPeriod` | 骨架屏的明暗呼吸一个周期 | 1500ms，无限循环 |
| `loadingShowDelay` | **被动加载**（进入页面、翻页、自动刷新）超过这个时间才显示加载指示；一旦显示，至少停留 `loadingMinShow` | 150ms；`loadingMinShow` 250ms |
| `highlightHold` | 引用跳转后目标楼层高亮的停留时间 | 1000ms |

- 主动操作（点发送、登录、移出黑名单）不用 `loadingShowDelay`：按下后 0ms 原地变成加载状态。
- 只有 `spatialSnap` 允许轻微过冲，而且只用在“回到原位或落到吸附点”；退场一律不过冲。

### 6.3 按状态变化分类的处理方式
| 变化类型 | 例子 | 处理方式 | 令牌 |
|---|---|---|---|
| 一级目的地切换 | 论坛 ↔ 消息 ↔ 搜索 ↔ 我的 | 原地交叉淡入淡出，没有位移；切换后导航胶囊如果被滚动收起了，就回到可见 | `effectsDefault` |
| 层级前进和后退（单栏） | 列表进入帖子；帖子进入用户资料 | 新页面从右侧整页水平推入，旧页面向左退让 1/4 宽度并略微变暗；返回时反过来。系统返回手势（预测性返回）跟手：页面随手指缩小到 0.9 并右移，松手后按位置和速度决定完成返回还是弹回 | 进：`spatialDefault`；退：`exit`；弹回：`spatialSnap` |
| 同级换内容（双栏） | 在左栏点另一条帖子、另一个会话 | 右栏原地交叉淡入淡出，没有位移（表示同一个位置换了内容） | `effectsDefault` |
| 右栏下钻（双栏） | 右栏的帖子里点开用户资料 | 新内容从右侧 24dp 处滑入并淡入，旧内容淡出；顶栏出现返回箭头 | `spatialDefault` + `effectsDefault` |
| 出现和消失 | 底部面板、菜单、对话框、快速回复输入条 | 从来源方向出现：菜单从按下的按钮处展开；面板从底部升起；对话框从中心淡入并从 0.9 放大。消失走 `exit` | 面板 `spatialDefault`；菜单、对话框 `spatialFast` + `effectsFast`；退场 `exit` |
| Snackbar | 撤销、回复已发送 | 浮在内容之上（导航胶囊或底部工具条上方 8dp），从下方升起；**不推挤内容** | `spatialDefault`；退场 `exit` |
| 内容替换 | 切换版块、切换“只看楼主”、跳到不相邻的页 | 旧内容淡出；新内容淡入，同时从下方 8dp 移到原位 | 淡出 `exit(effectsDefault)`；淡入 `effectsDefault` + `spatialDefault` |
| 刷新 | 下拉刷新、过期后自动刷新 | 按帖子 ID（楼层按 pid）原地对比：没变的项不动、不淡出；新增的项淡入并让开位置；屏幕上方有新帖时不移动当前内容，顶部出现“有 N 条新帖”胶囊，点一下滚到顶部 | 项的位置 `spatialDefault`；淡入 `effectsDefault` |
| 连续加载 | 长帖向下滚到页尾、从中间页打开后向上滚 | 向下：距页尾 5 楼时静默预取下一页，接在末尾，不打断滚动。向上：插入上一页的楼层前，记住第一个可见楼层的 pid 和它到屏幕顶部的距离，插入后恢复，偏差不超过 1dp。失败时在列表头或尾原地显示“加载失败，点击重试” | 无位移动画 |
| 数值变化 | 未读数、回复数、页码、上传进度 | 数字逐位上下滚动：增加时向上，减少时向下。数字从 0 变成大于 0 时，角标从中心放大出现；变回 0 时缩小消失 | `spatialFast`；消失 `exit` |
| 图标变化 | 收藏和取消收藏；发送按钮变成对勾 | 旧图标缩小并淡出，新图标放大并淡入，同时进行。对勾用描线的方式画出来 | `spatialFast` + `effectsFast` |
| 选择指示器 | 导航胶囊的选中项、分段标签、版块标签、主题色选中 | 指示器从旧位置滑到新位置，宽度跟着变 | `spatialFast` |
| 按压 | 列表项；按钮、图标按钮、标签、导航项 | **列表项**：按下立即显示状态层，不缩放。**按钮、图标按钮、标签、导航项**：按下立即显示状态层并缩小到 0.97，松开弹回。没有旧版那样的 200ms 延迟。确认类操作（收藏、发送成功、长按出菜单）配合轻微的触感反馈 | 状态层 `effectsFast`；缩放 `spatialFast` |
| 加载、完成、出错 | 发送、上传、首次加载 | 都在原地变化：发送按钮变成进度圈，成功后变成对勾，再恢复；失败时变回发送按钮，输入框下方原地显示原因和“重试”。被动加载按 `loadingShowDelay` 延迟显示。首次加载用和真实内容同样形状的骨架，内容到了以后原地淡入替换，不产生跳动 | 进度圈 `spinnerPeriod`；骨架 `skeletonPeriod`；替换 `effectsDefault` |
| 栏随滚动 | 导航胶囊、版块标签行随滚动隐藏和出现；看图工具栏显隐 | 胶囊和标签行的位移跟着滚动量走，停止滚动时按已滚出的比例吸附到全显或全隐。内容短于一屏、切换一级目的地、键盘收起后，胶囊回到可见。看图时单击切换工具栏的显隐 | 吸附 `spatialDefault`；工具栏 `effectsFast` |
| 引用高亮 | 点引用跳到被引用的楼层；从提醒打开定位楼层 | 目标楼层背景淡入高亮色，停 `highlightHold`，再慢慢淡出 | 淡入 `effectsDefault`；淡出 `effectsSlow` |
| 键盘联动 | 快速回复输入条随键盘升起；表情面板和键盘互换 | 输入条逐帧跟随系统键盘动画（`WindowInsetsAnimation`），不自己跑弹簧，所以不会和键盘脱节、不露缝。表情面板和键盘互换时，面板与键盘同高、原地替换，输入条零位移（规则见第 7.4 节）。正在读的那一楼随内容上移，保持可见 | 跟随系统 |
| 布局变化 | 折叠和展开、旋转、分屏改变宽度 | 两栏的宽度平滑过渡；正在阅读的内容保持在同一个阅读位置 | `spatialSlow` |
| 尺寸变化 | 展开长引用；投票结果的柱条 | 引用展开时高度跟着内容一起变；柱条从 0 长到目标宽度 | `spatialDefault` |
| 图片占位 | 帖子里的图片加载完成 | 加载前按真实宽高比占好位置（服务器给了尺寸就用；没给时先读图片头信息；都没有时按 4:3 占位），加载完淡入。真实比例和占位不同时：图片在屏幕上方，就补偿滚动距离，当前看的内容不动；图片在屏幕内，就平滑改变这一项的高度 | 淡入 `effectsDefault`；高度 `spatialFast` |
| 删除与撤销 | 删除浏览历史、搜索历史、移出黑名单、删除失败的短消息 | 该行收起，下面的行补上来；Snackbar 给“撤销”，撤销后该行在原位置展开回来 | 收起 `exit(spatialDefault)`；展开 `spatialDefault` |
| 主题切换 | 深浅色、主题色、纯黑 | 不重启页面，所有颜色平滑过渡；滚动位置、输入内容、焦点都不变 | `effectsSlow` |
| 看图的进入和退出 | 点帖子里的缩略图；关闭看图 | 进入：从缩略图的位置和大小放大到全屏，背景遮罩淡入。退出（下拉关闭、点关闭、系统返回、预测性返回都走这里）：回到**当前这张图**对应的缩略图——缩略图完整位于可见内容区内（不被顶栏、工具条遮挡）时，缩回它的位置和大小；否则在原地缩小到 0.85 并淡出 | 进入 `spatialSlow`；缩回 `exit(spatialSlow)`；降级 `exit(spatialDefault)` + `exit(effectsDefault)` |
| 看图的拖拽 | 下拉关闭看图 | 竖向位移占优时开始跟手。下拉 0 → 240dp 期间，图片从 1 缩到 0.8，背景遮罩不透明度从 1 降到 0.3（不再更低）。松手时位移超过 120dp 或向下速度超过 800dp/s 就关闭，并带着这个速度进入退出动画；否则弹回 | 弹回 `spatialSnap` |
| 看图的高清切换 | 缩略图换成高清图；长图 | 高清图解码完成前一直用缩略图垫底，就绪后高清图淡入覆盖。宽高比大于 2.5 的长图，进入时直接以“贴合宽度、对齐顶部”为目标，加载后不再自动跑缩放动画 | `effectsFast` |
| 下载和播放 | 看图里下载原图；GIF | 原图下载显示确定进度圈，再点可以取消；GIF 左上角有“GIF”角标，点一下播放或停止 | 角标 `effectsFast` |
| 拖拽（通用） | 分隔线、底部面板下拉关闭 | 完全跟手；松手时按速度和位置决定结果，并带着这个速度进入动画 | 吸附、弹回 `spatialSnap`；关闭 `exit` |

### 6.4 性能
- 帖子列表和长帖滚动时保持满帧（按设备的刷新率：60Hz 每帧 16.7ms，120Hz 每帧 8.3ms）。日常 CI 用重组次数断言守住不退化；阶段验收在真机上测（第 10.1 节）。
- 列表项里不使用模糊；毛玻璃全屏同时最多 2 块（第 5 节）。
- 图片按显示尺寸解码，不解码原图；看图时才按需加载原图。

## 7. 交互规范
### 7.1 对旧版问题的改法（审计发现）
| 原则 | 旧版的问题 | 新版的做法 |
|---|---|---|
| 系统能判断的 | 设置里有“使用 UTF8 编码”；图片按 Wi-Fi 和流量有多个设置项；主题要手动切换；重新打开帖子总是从第 1 页开始 | 编码自动识别；图片加载按第 7.9 节自动处理；主题默认跟随系统；帖子记住页码、楼层和偏移量，再打开时回到原处 |
| 此刻没用的 | 刷新按钮一直浮在屏幕上；抽屉里有显示“0”的角标；“检查更新”已失效；页码标签一直显示 | 去掉刷新按钮，改成下拉刷新，内容过期后回到页面时自动刷新；数值为 0 的角标不显示；删除“检查更新”；页码只在帖子详情的底部工具条里显示一处，点它跳页，不再另有浮动的页码标签 |
| 能替人做的 | 退出编辑时弹“放弃发表？”；发送失败后内容只能去草稿里找；上传前图片不压缩 | 草稿按第 7.2 节自动保存和恢复；发送失败时内容留在原处，原地重试；图片上传前自动压缩 |
| 同一件事处处一样 | “回复/回帖”“发表/发布”“只看楼主/只看该作者”等说法混用 | 统一术语（第 8 节），用测试检查（第 10.1 节） |
| 按下去有回应 | 列表项按下后 200ms 才高亮；600ms 内的第二次点击被直接丢掉，没有任何提示 | 按下立即有反馈；用状态防止重复提交（提交中按钮不可再点），不靠时间丢弃点击 |
| 再按能收回 | 收藏、关注不能撤销；删除搜索历史、日志等没有撤销 | 收藏、关注、删除立即生效，Snackbar 里给“撤销”；投票先选中选项，再点“投票”提交，这一步不变 |
| 不打断人手上的事 | 退出登录 1 秒后自动弹出登录框；错误用 Toast；切换主题时重启整个应用 | 退出登录后停在当前页，需要登录的地方原地显示“登录”按钮；错误在出错的位置原地提示；切换主题时颜色平滑过渡，不重启 |
| 难误碰 | 双击列表直接弹出跳页框；“退出并清除登录信息”和普通退出并排放着 | 去掉双击跳页；清除登录信息放在“账号”页的最下面，并且需要确认 |
| 不打断人手上的事 | 点其他账号的头像切换账号 | 在“账号”页点已保存的账号，直接切换，不确认（不会丢东西） |
| 系统能判断的 | 置顶帖或黑名单过滤后一页不足 10 条时，连续拉 5 页就停，然后让用户去网页版改设置（ThreadListFragment.java:614-616） | 后台自动继续加载，直到能填满一屏；不再让用户去改网页设置 |
| 系统能判断的 | “只看该作者”模式下点回复，提示“请先退出只查看该作者模式”（ThreadDetailFragment.java:1071） | 过滤模式下也能直接回复和引用 |
| 系统能判断的 | 登录过期后整屏显示“未登录”，即使保存了账号密码 | 用保存的凭据在后台静默重新登录一次；失败了，再在原地显示“登录已失效”和“登录”。**用户手动退出登录后，不再静默重新登录** |
| 不打断人手上的事 | 发帖时点发送，页面立即关闭在后台发送，失败后内容不在页面上了（PostFragment.java:517-518）。传图、发帖、清缓存都用不可取消的进度框 | 留在编辑页，直到服务器确认成功再关闭；失败时留在原页，可以直接修改后重发。进度一律原地显示，不用阻塞式的进度框，不人为拖延 |
| 难误碰 | 顶栏的返回箭头直接关闭编辑页并丢掉输入，系统返回键却会弹确认（PostFragment.java:387-389、736-748） | 所有返回途径（顶栏箭头、系统返回键、预测性返回）走同一条路径：按第 7.2 节保存草稿后返回 |
| 难误碰 | “右划返回”整屏宽度都响应；首页任意位置右滑 32dp 就打开抽屉（SwipeBaseActivity.java:24-29、MainFrameActivity.java:482-501） | 取消自定义的全屏滑动手势，用系统的预测性返回（只从屏幕边缘触发）；没有抽屉了 |
| 难误碰 | 看图时单击直接关闭，长按才显示工具栏；下拉关闭要先横向滑过阈值（ImageViewerLayout.java:56-74、231-289） | 单击显示或隐藏工具栏，双击放大或还原，下拉关闭（第 6.3 节），长按弹出“保存图片 / 分享” |
| 难误碰 | 点通知按钮一次就把全部提醒清零 | 每条提醒在打开它时才算已读；“全部已读”是单独的按钮 |
| 按下去有回应 | 黑名单的“移除”点了直接消失，没有进度；用户资料页切换内容时先变白屏 | 按钮原地变成进度圈，完成后该行收起并给“撤销”；用户资料改为两个标签（第 7.8 节） |
| 界面自己说明自己 | 退出登录藏在“长按头像”里 | “我的 → 账号”里明确提供“退出登录”和账号列表 |
| 同一件事处处一样 | 跳页面板里，上一页、下一页不收起面板，首页、末页会收起（ThreadDetailFragment.java:885-918） | 跳页面板的任何跳转都会收起面板（第 7.3 节） |
| 界面自己说明自己 | 错误提示直接显示异常类名或“错误代码 (403)”；空列表一片空白；搜索页一进来就显示“没有数据” | 错误提示按第 8 节的格式；技术细节放在可展开的“查看详情”里，只给排错用；空状态显示一个图标、一句话和下一步的操作；搜索页的初始状态见第 7.7 节 |

### 7.2 草稿
- 草稿按业务键自动保存：发新帖 `new:<fid>`（分类、标题、正文、已上传的图片）、回复 `reply:<tid>`（含引用的楼层）、编辑已发表的楼层 `edit:<pid>`。
- 任何返回途径都静默保存，不询问；返回后 Snackbar `已保存草稿`（按钮：`放弃`，点了删除这份草稿）。内容为空或和上次发出的一样时不保存、不提示。
- 再次打开同一个业务键的编辑器时自动恢复，输入框上方显示一条横条 `已恢复上次草稿`（按钮：`清空`）。
- **编辑已发表的楼层**：编辑器顶栏有“还原原文”，只在内容和线上原文不同时出现；点了把内容换回线上原文（可以用 Snackbar 撤销）。退出时照常保存 `edit:<pid>` 草稿；保存成功提交后删除草稿。
- 发送成功后删除对应的草稿。

### 7.3 读帖
- 打开帖子时回到上次读到的位置（页码、楼层、偏移量）。
- **连续加载**：长帖上下滚动时自动接续加载上一页和下一页（第 6.3 节“连续加载”）。底部工具条显示第一个可见楼层所在的页“第 N / M 页”。
- **跳页面板**：点工具条上的页码，从底部升起。内容：页码输入框（可以直接输入）、滑块（拖动时只预览目标页码，不跳）、按钮 `首页`、`-1`、`+1`、`末页`、`跳转`。任何一次跳转（含首页、-1、+1、末页、跳转、输入后回车）都收起面板，并跳到目标页的开头；跳到不相邻的页时按“内容替换”处理，并重建连续加载的范围。
- **位置栈**：跳页、点引用跳楼层、点“回复已发送 · 查看”之前，都把当前位置压栈；按返回先回到跳转前的位置，再按才离开帖子。
- **引用**：点引用跳到被引用的那一楼，并高亮（第 6.3 节“引用高亮”）；长引用默认折叠，点开展开。
- **只看过滤**：开启“只看楼主”或“只看此人”后，顶栏下方常驻一个过滤胶囊 `只看楼主 ×` 或 `只看 {用户名} ×`。点 `×` 退出过滤，回到全帖，并定位到刚才正在看的那一楼。过滤模式下可以直接回复和引用。
- **楼层长按菜单**：`引用回复`、`回复`、`只看此人`、`复制`，自己的楼层另有 `编辑`、`删除`。没有“举报”。
- **回复**：点工具条的“回复”，输入条随键盘升起（第 6.3 节“键盘联动”）。发送成功后：如果用户本来就在最后一页的末尾附近，新楼层插入末尾并滚过去，输入条收起；否则输入条原地收起，不移动阅读位置，Snackbar `回复已发送`（按钮：`查看`，点了跳到新楼层，跳前压入位置栈）。
- **冷却**：服务器对回复有 30 秒冷却、对短消息有 15 秒冷却。发送成功后，发送按钮原地变成剩余秒数的倒计时（向上取整），倒计时期间可以继续输入，结束后恢复发送按钮。无障碍描述：`{N} 秒后可发送`。

### 7.4 编辑器、上传与表情
- **多图上传条**：输入框上方一条横向滚动的缩略图条。选图后立即出现缩略图占位，叠着环形进度（先压缩，后上传）；条上显示汇总 `正在上传 {current}/{total}`。单张失败时缩略图上显示重试图标，点一下重传。点已上传的缩略图，在光标处插入这张图；还没插入正文的图片带一个小角标，点发送时按顺序自动附在正文末尾，不询问；缩略图右上角的 `×` 移除这张图。编辑器里不显示 `[attachimg]` 这类标签，正文里插入的图片显示为缩略图块。
- **表情面板**：
  - 键盘已经展开时点“表情”：面板沿用最近一次键盘的高度，原地替换键盘，输入条零位移；按钮图标在“表情”和“键盘”之间切换。
  - 没有可用的键盘高度时（分屏、浮窗、外接键盘、刚打开还没弹过键盘）：面板高 280dp，且不超过窗口高度的 45%；窗口高度小于 480dp 时不超过 35%。
  - 列数按面板宽度自适应（每格最小 48dp）。分类标签用每组表情的第一个图作为图标，选中指示器用 `spatialFast` 滑动。
- **提交**：按钮 0ms 变成进度圈，留在编辑页；成功后关闭编辑器并删除草稿；失败时原地显示原因，内容不动，可以修改后重发。

### 7.5 短消息
- 点发送后，消息立即作为气泡插入对话末尾，气泡旁显示小进度圈；服务器确认后进度圈消失。
- 失败时气泡旁常驻一个红色感叹号，点它弹出 `重发` / `删除`；删除走“删除与撤销”。
- 15 秒冷却按第 7.3 节倒计时。

### 7.6 消息与提醒
- 见第 3 节。提醒按单条已读；“全部已读”在“提醒”标签的顶栏。

### 7.7 搜索
- 初始状态（还没提交搜索）：显示“最近搜索”（每条右侧 `×` 删除，可撤销）和筛选胶囊（版块、标题/全文、作者）。不显示任何空状态。
- 筛选胶囊点开是一个可打断展开和收起的面板（`spatialDefault`）。
- 只有提交搜索后返回 0 条，才显示 `没有找到相关内容`（按钮：`清除筛选`，没有筛选时不显示按钮）。
- 搜索框识别站内地址（第 3 节）。

### 7.8 用户资料
- 上方固定资料头（头像、用户名、主要统计），下方两个标签 `资料 | TA 的帖子`，各自有自己的骨架、空、错状态；切换按“同级换内容”。TA 没有发过帖子时显示空状态 `TA 还没有发过帖子`，不报错。
- 操作：`发短消息`、`加入黑名单` / `移出黑名单`。

### 7.9 图片加载
- 帖子里的图片默认自动加载（缩略图或常规尺寸），点开看图时再加载原图；头像总是自动加载。
- 只有系统的“流量节省程序”开启、并且当前是计费网络时，帖子里的图片才改为点击加载：占位上显示 `点击加载图片（{size}）`（不知道大小时不带括号），点击后显示确定进度圈，再点可以取消。应用里不设单独的开关。

### 7.11 登录与账号
- **登录页**：一个页面完成。字段：用户名、密码、安全提问（下拉，默认“无安全提问”）；选了提问后，才在下面展开“提问回答”。点“登录”后按钮内 0ms 变成进度圈，留在本页；失败时保留所有已填内容，在出错的字段下面原地显示原因（例如 `用户名或密码错误`），并聚焦那个字段。成功后回到触发登录之前的页面，并继续那个操作。登录过程中遇到 Cloudflare 验证时走第 7.12 节的统一流程。
- **账号页**（我的 → 账号）：已保存的账号列表，点一下直接切换，不确认；`添加账号`；`退出登录`（不确认：账号仍在列表里，点一下就能登回来；退出后停在当前页，并记下“手动退出”，之后不再静默重新登录，直到用户再次登录）；最下面是 `清除登录信息`（确认：`清除 {用户名} 的保存密码并退出？`）。

### 7.12 Cloudflare 验证
- 系统先在后台用不可见的 WebView 自动完成验证，用户看不到，原来的加载指示照常显示。
- 后台等待超过 2 秒时，原地的加载提示换成 `正在检查安全环境…`。
- 需要人工操作时才弹出验证面板：窗口宽度小于 600dp 用底部面板，600dp 及以上用居中对话框（最大宽 480dp）。标题 `安全验证`，按钮 `刷新`、`取消`。验证通过后自动收起，原来的请求自动继续。
- 用户取消、或连续失败进入冷却时，原地显示 `安全验证未完成`（按钮：`重新验证`）；过了验证仍被拒绝（60 秒冷却）时显示 `验证未通过`（按钮：`重新验证`）。用户点“重新验证”是主动操作，不受冷却限制。

## 8. 文案
- 语气：简短、直接、口语化；不用感叹号；用全角中文标点。
- 按钮写成动词：回复、发送、重试、登录、撤销。
- 进行中的提示写清楚是什么动作：`正在发送…`、`正在登录…`，不写“请稍候…”“正在处理…”。
- **错误提示的格式**：
  - 旁边有动作按钮时，只写原因，一个短语，不加句号：`网络连接失败`（按钮：`重试`）、`登录已失效`（按钮：`登录`）。
  - 没有按钮，或者需要用户改输入、等待时，写“原因，怎么办”，用全角逗号连接：`密码错误，请核对后重试`、`发送太快，请等 18 秒后再试`。
  - 主提示里不出现异常类名、HTTP 状态码、原始的异常信息、BBCode 标签名（如 `[attachimg]`）。技术细节只放在可展开的 `查看详情` 里，供排错和复制。
- **术语表**（左边是唯一的标准说法；右边是禁止出现的精确词组，扫描测试按词组匹配，不按单字匹配，所以“账号信息”“按发帖排序”这类正常用法不受影响）：

| 标准说法 | 禁止的精确词组 |
|---|---|
| 回复 | 回帖、回复帖子 |
| 发新帖 | 发表新帖、发表主题、发布新帖、发布帖子 |
| 按发帖排序 | 按发表排序、按发表时间排序 |
| 引用回复 | 引用回帖 |
| 短消息 | 私信、站内信 |
| 提醒 | 信息提醒、消息提醒、帖子提醒 |
| 通知（指系统通知栏的通知） | 消息通知 |
| 只看楼主 | 只看主帖作者 |
| 只看此人 | 只看该作者、只查看该作者 |
| TA 的帖子 | 搜索帖子（指用户资料里的帖子列表时）、他的帖子 |
| 版块 | 版面 |
| 浏览历史 | 浏览记录 |
| 黑名单 | 屏蔽列表 |
| 退出登录 | 注销 |
| 清除登录信息 | 清除账号、退出并清除 |
| 第 N 楼（正文、标题里）／ N楼（楼层角标） | 第N层、N层 |
| 具体的空状态（见 copy.md） | 没有数据、暂无数据 |
| 具体的进行中提示 | 请稍候、正在处理 |

- 全部界面文本（导航、空状态、加载、错误、验证、登录与账号、跳页、Snackbar、确认框、设置项）见 `docs/design/copy.md`。页面卡直接从那里取文本，不另写。

## 9. 关键流程
- **首次启动**：直接显示论坛的帖子列表（默认“今日新帖”或第一个关注的版块），未登录也可以浏览论坛允许游客看的内容。需要登录的操作，在原地显示 `登录后即可操作`（按钮：`登录`）。
- **Cloudflare 验证**：第 7.12 节。
- **登录**：第 7.11 节。
- **读帖**：第 7.3 节。
- **回复**：第 7.3 节“回复”和“冷却”。
- **发新帖**：论坛顶栏点“发新帖”打开完整编辑器，版块默认是当前版块（在“今日新帖”里打开时需要先选版块）；提交成功后关闭编辑器，回到列表并刷新，Snackbar `帖子已发出`（按钮：`查看`）。
- **从提醒进入帖子**：第 3 节“消息”。

## 10. 验收条件
每条都有可检查的证据。M4 及以后，每张界面卡从这里挑出适用的条目写进它的验收。

### 10.1 全局
- [ ] **截图矩阵（分级，与 tech-plan §8 一致）**：
  - 外壳和双栏的核心页面（论坛、帖子详情、双栏）：4 种宽度（411、700、900、1280dp）× 深浅色。
  - 其他页面的主状态：3 种宽度（411、700、900dp）。
  - 空、错、加载状态：2 种宽度（411、900dp）。
  - 另加 3 种特殊窗口，只跑外壳和核心页面：手机横屏 891×411dp（应为单栏、紧凑胶囊）、分屏窄窗 340×800dp、最大字号（第 5 档且系统字体缩放 1.3）——不得有文字裁切、重叠或溢出。
  - 证据：CI 中 `verifyRoborazziDebug`（以 C1 落地的任务名为准）通过。
- [ ] **动效令牌唯一**：除了令牌文件，业务代码里不得出现 `tween(`、`spring(`、`keyframes(`、`durationMillis`、`snap(`，以及不传动画参数的 `fadeIn()`、`fadeOut()`、`slideIn…()`、`slideOut…()`、`scaleIn()`、`scaleOut()`、`expandVertically()`、`shrinkVertically()`、`animateContentSize()`；`animate…AsState` 和 `Animatable.animateTo` 必须传入令牌。证据：扫描源码的单元测试；例外放进只能缩短的白名单。
- [ ] **减少动态效果**：在动画时长缩放为 0 的条件下运行 UI 测试，所有页面切换、面板出现和消失都在一帧之内完成，没有残留的中间状态。证据：测试报告。
- [ ] **可打断**：对层级前进和返回、面板出现和消失、选择指示器的移动，在动画进行到一半时触发相反的操作，逐帧检查位置连续：相邻两帧的位移不超过正常动画中单帧的最大位移。证据：Compose UI 测试（用 mainClock 控制时间）。
- [ ] **无布局跳动**：以下每种情况前后，第一个可见楼层（或列表项）到屏幕顶部的距离变化不超过 1dp（被展开的那一项本身除外）：图片加载完成（含真实比例和占位不同、图片在屏幕上方的情况）、下拉刷新、展开引用、**从中间页向上加载并插入上一页**。证据：UI 测试。
- [ ] **键盘**：键盘弹出时，导航胶囊隐藏；快速回复输入条在键盘上方；正在读的那一楼仍然可见；表情面板和键盘互换时输入条零位移。证据：UI 测试（模拟 IME insets），加截图。
- [ ] **主题切换保持状态**：在帖子详情里滚到中间、快速回复里有输入时切换深浅色和主题色，页面不重建，滚动位置、输入内容、焦点都不变。证据：UI 测试。
- [ ] **性能**：日常 CI 用重组次数断言守住不退化（滚动长帖时，楼层项不因无关状态变化而重组）。阶段验收（M4、M5、M7）在真机上测长帖（300 楼以上，带图）滚动：P90 帧时间低于该设备刷新率的一帧（报告里注明设备和 60Hz 或 120Hz），卡顿帧不超过 1%。没有真机时用模拟器的硬件渲染，并注明数据仅供参考。证据：CI 测试报告；阶段验收的基准报告。
- [ ] **术语统一**：字符串资源里不得出现第 8 节术语表右栏的任何词组。证据：扫描字符串的单元测试。
- [ ] **错误提示**：用户可见的字符串资源里不含异常类名或 HTTP 状态码；错误映射函数对每一类网络、HTTP、解析、验证异常都有单元测试，断言主提示文本不包含 `Throwable.message`、异常类名和状态码，且有按钮时只有原因短语。证据：扫描测试 + 错误映射单测。
- [ ] **无障碍**：触摸目标不小于 48dp；所有图标按钮都有内容描述；文字对比度不低于 4.5:1，含毛玻璃降级后。证据：Robolectric 中开启 Compose 无障碍检查。

### 10.2 自适应
- [ ] 截图矩阵的各宽度和特殊窗口下，导航形态和单栏、双栏符合第 4.1 节和第 4.2 节；700dp 宽时是双栏加居中的底部胶囊；高度小于 480dp 时一律单栏。证据：截图矩阵。

## 11. 不做的事
- 不学 fluxdo 的这些部分：AI 功能、小应用、实时聊天、徽章和积分、可自定义的底栏、桌面多窗口、无限层叠的“胶片带”页面栈。
- 暂不做（以后再评估）：桌面姿态（tabletop）下看图和回复的上下分区布局；大屏上的第三栏；应用内单独的“减少动态效果”开关（以系统设置为准）；出错时左右晃动的动画；自定义字体导入。
- 不做“举报”：旧版的举报只是随机等待后提示成功，并没有提交（用户决定删除）。
- 不加装饰性的动效：不加视差（层级后退时旧页的 1/4 退让除外）、不加入场时的逐项级联动画、不在列表上做弹性滚动。
