## 1. 为谁、做什么
- 用户：HiPDA 的老用户。高频操作依次是：刷帖子列表、读长帖（翻页、跳楼层、看引用）、看图、快速回复、看短消息和提醒。
- 设备：单手用的手机；折叠屏合上时当手机用，展开后大屏三栏协同（切版块、刷列表、读长帖一步到位）；平板；分屏时的窄窗口；手机横屏。
- 目标：读得舒服，找得快，回得顺手。所有复杂的事都由系统处理，用户只管看帖和回帖。
- 功能范围与现有应用一致（tech-plan §1）。删除的只有：举报（旧版是假提交，用户决定删除）、检查更新（已失效），以及第 7.10 节列出的、可以由系统判断或随旧界面一起消失的设置项。

## 2. 设计原则（每条都对应第 10 节的验收）
1. **系统能判断的，不留给用户。** 编码、主题、图片加载策略、阅读位置、登录续期、Cloudflare 验证，都由系统自动处理。
2. **此刻没用的，就不出现。** 不显示数值为 0 的角标；刷新按钮和不再有用的提示不常驻；安全提问的答案框只在选了提问时出现；失效的功能直接删除。
3. **能替人做的，就直接做。** 草稿自动保存；发送失败时内容保留，可以原地重试；离开再回来，从上次读到的地方继续。
4. **同一件事，处处一样。** 一套术语、一套组件、一套动效语言。
5. **按下去有回应，再按能收回。** 按下立即有反馈；收藏、关注、删除这类操作立即生效，可以撤销。
6. **不打断人手上的事。** 错误在出错的地方原地提示，不弹窗；新消息只用角标提醒；刷新时不把人拉回顶部；在前面的页回复后不把人拽到末页。
7. **常用的好做，会丢东西的难误碰。** 回复入口在拇指够得到的位置；清除登录信息要确认，删除能撤销；去掉双击就跳页这类容易误触的手势；常用但不会丢东西的操作（切换已保存的账号）不加确认。
8. **界面自己说明自己。** 不加不必要的次级标签和说明文字；当前处于什么模式（例如“只看楼主”）始终看得见；空状态和错误状态直接告诉用户下一步能做什么。

## 3. 信息架构
应用按窗口形态提供两套完全对称的主导航载体，共享同一套底层目的地与状态，确保窄屏与宽屏无缝切换：

### 3.1 窄屏、矮屏与铰链分隔形态（底部胶囊：4 个一级目的地）
在窗口宽度 `< 600dp`、高度 `< 480dp` 或竖向物理铰链分隔时，不设抽屉菜单，底部悬浮液态玻璃胶囊固定承载 **4 个一级目的地**：**论坛**、**消息**、**搜索**、**我的**（**不在中间增加“+”快捷按钮**，`发新帖` 保留在论坛顶栏，与 `≥ 600dp` 宽屏保持一致）。胶囊除点击切页外，支持横向**跟手拖拽预选**（拖动中实时高亮经过的目的地，松手切页，拖离取消弹回原项，见第 5 节与第 6.3 节）。旧版抽屉里的每一项都有明确落点（见下表和附录 A 的 S05）：

| 目的地 | 内容 | 旧版对应 |
|---|---|---|
| 论坛 | 顶栏上行：当前版块名，右侧动作“发新帖”（图标按钮）和“更多”（排序：按回复排序 / 按发帖排序，按版块记住）。顶栏下方是一行**吸顶版块标签**：第一项固定为“今日新帖”，后面是用户关注的版块，最右侧固定一个不随标签滚动的“管理版块”图标按钮；标签按可用宽度自适应排布（全部放得下时等分居中，放不下时横向滑动并自动滚入选中项），选中项加粗略放大并在文字下半部绘主题色横向渐变荧光笔底条，每项触控区高 ≥ `48dp`。向下滚动时**仅收起上行标题与动作行，版块标签行吸顶不隐藏**，稍微向上滚动即重新展开上行；列表内容从透明液态玻璃顶栏与标签行背后滚过 | 抽屉里的版块、“新帖”、右下角发帖按钮、版面选择 |
| 消息 | 顶部分段标签 `短消息 \| 提醒`，各自显示未读点；两者的未读数加起来显示在导航的“消息”角标上。“提醒”标签的顶栏有“全部已读”。点一条短消息打开对话；点一条提醒打开对应的帖子并定位到目标楼层（短暂高亮），打开即算已读 | 抽屉里的短消息、提醒；通知悬浮按钮 |
| 搜索 | 搜索框（提示：搜索标题、正文或作者）。没输入时显示“最近搜索”和筛选胶囊（版块、标题/全文、作者）。粘贴或输入站内地址时，结果第一行是“打开这个链接”，点一下直接打开对应的帖子、版块或用户 | 抽屉里的搜索；列表菜单的“打开站内地址” |
| 我的 | 顶部是账号卡（头像、用户名，点进“账号”）；下面依次是：收藏与关注（两个标签 `收藏 \| 关注`，各自保留滚动位置）、我的帖子（两个标签 `主题 \| 回复`）、浏览历史、设置 | 抽屉里的我的帖子、我的回复、收藏、关注、历史、设置；长按头像退出 |

- 未读提醒：底部胶囊只在“消息”图标上显示总未读角标，没有未读时不显示。
- 二级页面（不是一级目的地）：帖子详情、短消息对话、收藏与关注、我的帖子、浏览历史、用户资料（`资料 | TA 的帖子` 两个标签）、管理版块、看图、编辑器（发新帖、回复、编辑）、登录、账号、设置的子页。
- 在单栏里，导航胶囊只出现在一级目的地的页面上，进入二级页面时随页面推入一起退场。

### 3.2 宽屏与折叠屏展开形态（≥ 600dp：常驻左侧栏）
当窗口宽度 `≥ 600dp`（且高度 `≥ 480dp`、无竖向物理铰链分隔）时，底部胶囊与原 80dp 导航轨均不再出现，改为**常驻左侧栏**（`600–839dp` 默认收起为 `64dp` 图标轨并可 `240dp` 浮层展开；`≥ 840dp` 默认常驻展开并可主动收起）。左栏整合了旧版抽屉的全部内容（包含用户拍板保留的 `搜索`），并取代中栏列表顶部的横向版块标签行（此时版块标签行隐藏）：

- **顶部固定区**（高 `48dp`，不随左栏内容滚走）：
  - **展开态（`176–220dp` 或 `240dp` 浮层）**：圆形头像 + 当前用户名（未登录时显示默认头像 + `登录`，点开账号页或登录页），最右侧为 `收起侧栏` 图标按钮（`48×48dp`）。
  - **收起态（`64dp` 图标轨）**：顶部居中为 `展开侧栏` 图标按钮（`48×48dp`）。
- **中间可滚动区**（上方功能入口 + `1dp` 分隔线 + 下方关注版块列表，确保矮宽窗口如 Fold8 横屏 `749 × 559dp` 在首屏直接露出关注版块）：
  - **上方 5 行主功能入口**（每行 `48dp`，共 `240dp`；所有文案严格遵循第 8 节术语表）：
    1. `今日新帖`
    2. `搜索`
    3. `短消息`（附独立未读数字角标；为 0 不显示，>99 显示 `99+`）
    4. `提醒`（附独立未读数字角标；为 0 不显示，>99 显示 `99+`）
    5. **`我的`** 可折叠分组（对应旧版抽屉的 `ExpandableDrawerItem`），内含 4 项个人归档入口：`收藏与关注`（中栏带 `收藏 | 关注` 分段标签）、`我的帖子`（直达“我的帖子 → 主题”）、`我的回复`（直达“我的帖子 → 回复”）、`浏览历史`。
       - **按窗口高度自适应默认态**：窗口高度 `< 760dp`（如 Fold8 自然横展 `749 × 559dp`、Fold6 横拿 `744dp`）时默认**收起**，为下方关注版块腾出首屏空间；窗口高度 `≥ 760dp`（如平板竖屏、Pixel 9 Pro Fold 等）时默认**展开**。展开态下点击 `我的` 标题行可随时切换展开/收起（当前会话记住切换态）；收起时若当前正停在其任一子页，高亮 `我的` 行本身。
       - **`64dp` 图标轨态交互**：显示 `我的` 图标（当前处于其子页时高亮该图标）；点一下立即弹出 `240dp` 浮层（`600–839dp`）或原地展开左栏（`≥ 840dp`）并自动展开 `我的` 分组，一步直达 4 个子项。
  - **分隔线（`9dp`，含上下留白）+ 下方关注版块列表**：
    - 展开态显示分区标题 `版块` 与右侧 `管理版块` 图标按钮（行高 `48dp`，替代已隐藏的版块标签行末尾入口）；收起态不占独立标题行，直接紧接关注版块列表，列表末尾放 `管理版块`（`+`）图标按钮与 `设置` 图标。
    - **首屏可见性保障（以 Fold8 `749 × 559dp` 为例）**：扣除约 `48dp` 系统状态栏与手势条、顶底各 `48dp` 固定区、上方 5 行（`240dp`）与 `9dp` 分隔线后，首屏仍余约 `166dp`——`64dp` 图标轨首屏完整可见至少 **3 个**默认关注版块（`Discovery`、`Buy & Sell`、`Geek Talks`）无需滚动；`240dp` 浮层展开态首屏可见 `版块` 标题行 + **2–3 个**关注版块。
    - **版块图标、短标与碰撞/未知回退**：不依赖已计划删除的旧版 FontAwesome；为 HiPDA 21 个内置版块建立统一的 Compose 静态元数据表（`fid`、全名、互不撞车的矢量图标、1–2 字短标，如 `D` / `BS` / `极` / `墨` / `果` / `安`）。
      - **展开态**：`20dp` 版块矢量图标 + 完整版块名；遇到表外新增 `fid` 时回退为 `20dp` 圆角首字徽标。
      - **收起态（`64dp` 图标轨）**：每项（`48×48dp` 触摸目标、`44×44dp` 选中胶囊）采用 **`18dp` 矢量图标 + 下方 `10sp` 1–2 字短标**（短标上限 `1.25×` 缩放不裁切）；若某版块无内置图标（未知 `fid`）或用户关注的多个版块映射到同一图标，自动回退为 **`28×28dp` 圆角短标/首字徽标**（最多 2 个拉丁字母或 1 个汉字），保证 `64dp` 轨上每个版块一眼可辨、绝不撞车；完整版块名同时提供无障碍描述与长按/悬停 Tooltip。
    - 未关注任何版块时，展开态显示空引导 `去管理版块添加关注的版块` 与 `管理版块` 按钮，收起态保留 `+`（`管理版块`）按钮。
- **底部固定区**（高 `48dp`，不随左栏内容滚走）：
  - **展开态（`176–220dp` 或 `240dp` 浮层）**：固定 `设置` 入口（上方带 `1dp` `outlineVariant` 细线）。
  - **收起态（`64dp` 图标轨）**：固定圆形账号头像（`48×48dp`，点击打开账号页/登录页；`设置` 置于上方滚动列表末尾，或在展开侧栏后于底部一步点击）。

**左栏入口与底部胶囊目的地的双向映射**（保证窗口跨越 `600dp` 断点时不丢状态、不迷路）：

| 底部胶囊目的地（`< 600dp` 等） | 宽屏左栏对应入口（`≥ 600dp`） | 宽 → 窄（进入底部胶囊）时的落点 | 窄 → 宽（进入左侧栏）时的落点 |
|---|---|---|---|
| **论坛**（`今日新帖` + 关注版块标签行） | `今日新帖` + 下方关注版块列表 | 高亮 `论坛`，恢复列表顶部的版块标签行并选中当前版块 / `今日新帖` | 左栏高亮当前版块或 `今日新帖`，隐藏列表顶部版块标签行 |
| **消息**（`短消息 \| 提醒` 分段标签） | `短消息`、`提醒`（各自独立入口与角标） | 高亮 `消息`，分段标签选中对应项，角标合并为两项未读之和 | 左栏高亮对应项（`短消息` 或 `提醒`），中栏直接展示该列表，不再重复显示分段标签 |
| **搜索** | `搜索` | 高亮 `搜索`，保留搜索词、筛选与结果 | 左栏高亮 `搜索`，中栏保留搜索框、筛选与结果 |
| **我的**（账号卡 + 子菜单） | 顶部账号行 + `我的` 分组（`收藏与关注`、`我的帖子`、`我的回复`、`浏览历史`）+ 底部 `设置` | 高亮 `我的`；若宽屏正停在具体子页（如浏览历史、设置），保留在当前子页，返回即回“我的”总菜单 | 若窄屏正停在某子页，左栏直接高亮对应入口并迁入中栏；若停在“我的”总菜单未进子页，**优先恢复本次会话最近访问的“我的”子项，未访问过时默认高亮 `收藏与关注`** |

## 4. 自适应布局
### 4.1 窗口分档与导航形态
先看高度，再看物理铰链分隔，最后看宽度。宽度和高度均指应用当前可用窗口尺寸（不是物理屏幕），**不按机型特判**，一套通用规则覆盖手机、折叠屏（含 `~560–900dp` 整段内屏宽）、平板与分屏多窗口。

| 档位 | 条件（按优先级自上而下匹配） | 导航 / 左栏形态 | 内容栏数与每栏宽度规则 | 典型设备 |
|---|---|---|---|---|
| **矮屏** | 高度 `< 480dp`（不论宽度） | 底部紧凑胶囊（高 ≥48dp，4 项无“+”，仅选中项带文字，支持跟手拖拽预选），向下滚动收起 | **单栏**，论坛顶栏上行随滚收起、下方版块标签行吸顶，正文最大行宽 `680dp` 居中 | 手机横屏、折叠屏外屏横拿（`797–968 × 411dp`） |
| **铰链分隔** | 竖向物理铰链 `isSeparating == true`（半折书本态） | 启用铰链双栏时：紧凑胶囊（高 ≥48dp，4 项无“+”，支持跟手拖拽预选），放在列表侧居中，不压铰链，列表顶部保留吸顶版块标签行（顶栏用纯色以守住全屏 ≤ 3 块实时玻璃上限）；退回单栏时：紧凑胶囊居中放在铰链外较宽一侧（等宽取左侧；若该侧 `< 280dp` 则整窗底部居中），恢复单栏透明玻璃吸顶顶栏 | **铰链双栏**：分界对齐 `hingeBounds`，满足 `左栏 ≥ 280dp` 且 `右栏 ≥ 360dp` 时启用；任一侧不足时退回单栏铺满窗口 | 半折书本态折叠屏（如 Fold8 横展 `749dp` 单侧 `~374dp`、Fold6 横展 `860dp` 单侧 `~430dp`、Pixel 9 Pro Fold `852dp` 单侧 `~426dp`） |
| **窄屏单栏** | 宽度 `< 600dp` | 底部悬浮液态玻璃胶囊（高 ≥64dp，4 项无“+”，`< 360dp` 仅选中项带文字，支持跟手拖拽预选），向下滚动滑出、向上滚动回来 | **单栏**，论坛顶栏上行随滚收起、下方横向版块标签行吸顶不隐藏 | 手机竖屏（`360–443dp`）、折叠屏外屏、分屏窄窗（`340dp`）、Galaxy Z Fold8（用户当前缩放竖拿 `559 × 749dp`） |
| **图标轨单栏（2 栏）** | 宽度 `600–679dp` | **左侧 `64dp` 常驻图标轨**（取代底部胶囊与原 80dp 导航轨；隐藏版块标签行）。点顶部 `展开侧栏` 按钮（或点 `我的` 图标）以 **`240dp` 浮层**（带暗罩覆盖内容）展开完整文字侧栏，左滑抽屉/点选条目/遮罩/返回/`Escape` 即自动收回（不设左缘右滑触发） | **单栏内容**（宽 `W − 64dp`，即 `536–615dp`），列表推入详情 | Fold8（480dpi 竖拿 `609dp`）、vivo X Fold 初代竖拿（`639dp`）、Lenovo Legion Tab 8.8" 竖屏（`640dp`）、Xiaomi Pad 6 竖屏（`641dp`） |

- **正文栏最小宽度的理由（`360dp` 硬底线）与窄栏底部三段工具条适配**：默认字号 `16sp` 下，扣除左右各 `16dp` 安全边距后，净文本行宽为 `328dp`（每行约 `20.5` 个汉字，等同标准小屏手机的全屏阅读宽度）；楼层引用块额外内缩 `12dp + 3dp` 边框后仍保有约 `19.5` 字/行；同时完整容纳楼层头部信息与右栏底部**三段式液态玻璃工具条**（左 `回复` 胶囊 + 中 `第 N / M 页` 进度胶囊 + 右 `收藏`/`更多` 独立双按钮胶囊，段间 `8dp`，连同 `48dp` 触摸目标常规约需 `316–340dp`）。低于 `360dp` 时长帖折行碎裂、最大字号（第 5 档 `18sp`）每行不足 16 字，因此以 `360dp` 作为**任何三栏或铰链双栏配置下右栏不可跌破的硬底线**；在 `≥ 840dp` 完整三栏下右栏默认起步即达 `398dp`，`749dp` 紧凑三栏下达 `411dp`。当右栏处于窄区间（如 `360–384dp`）且叠加 `1.25×` 字体缩放或三位页码导致三段工具条自然总宽超过 `右栏宽 − 32dp` 时，底部工具条自动切换为**紧凑三段工具条态**：左段 `回复` 仅保留笔形图标（`48×48dp`，无障碍描述 `回复`），中段进度胶囊缩短为 `{N}/{M}`（保留主题色进度填充，无障碍描述 `第 {N} 页，共 {M} 页，点按展开跳页`），右段 `收藏` 与 `更多` 保持两个独立 `48×48dp` 触控区，确保绝不挤压裁切。点按中段原地展开的**内联跳页条**在三栏与铰链双栏下同样严格限定于右栏宽度内（不跨分隔线或铰链），窄右栏下采用紧凑双行排布（上行 `首页` + 预览 + `末页`，下行滑块 + 页码输入框 + `/ {M}` + 关闭/跳转），保证每项触控区 ≥ `48dp`。
- **栏宽整数取整顺序（消除浮点累加误差）**：纯函数 `calculateShellPaneLayout` 统一按整数 `dp` 顺序计算——先 `L = clamp(0.20 × W, 176, 220).roundToInt()`（收起态固定 `64`，单栏/铰链为 `0`），再令 `S = W − L`，再 `M_default = clamp(0.40 × S, 256, 380).roundToInt()`，最后 `R_default = S − M_default`；均衡档 `M_balanced = min(0.50 × S, S − 360, 480).roundToInt()`。确保任意整宽 `W`（如 `840`、`1024dp`）严格满足 `L + M + R == W` 无 1dp 舍入偏差。
- **左栏宽度、开合与无障碍规则**：
  - 左栏与中栏之间是一条 `1dp` 静态分隔线，**不可自由拖拽调宽**（避免触屏上双拖拽柄误触）。
  - **展开态最小宽 `176dp`（上限 `220dp`）**：按最宽 5 汉字中文入口（`收藏与关注`，`14sp` 宽 `70dp`，字体缩放 `1.25×` 上限 `87.5dp`）或带 `99+` 角标的 `短消息`（`76dp`）加 `20dp` 图标、`10dp` 间距与内外边距（`36dp`）推算，净文本区 `110dp` 无截断；宽屏放大至 `1100dp` 以上封顶 `220dp`（对齐 Material 3 `WideNavigationRailExpanded` 下限）。
  - **收起态固定 `64dp`**：居中排布，每项保留 `48×48dp` 触摸目标（左右各 `8dp`），版块项采用“小图标 + 1–2 字短标（缺失或撞车时回退为圆角短标/首字徽标）”，未读项在图标右上角叠数字小角标；**所有项的无障碍描述均合并完整名称与未读数**（如 `短消息，3 条未读`），长按/悬停弹出完整名称 Tooltip。比 `80dp` 轨多释放 `16dp` 给中右两栏，并在 `680dp` 时恰好满足 `64 + 256 + 360 = 680dp`。
  - **两种展开机制与触发方式（不与系统边缘返回手势冲突）**：
    - `600–839dp` 宽度不足以同时容纳三个带文字完整栏，采用**浮层展开（`240dp` 宽，配半透明暗罩盖在内容上方）**，不挤压重排中右两栏。**展开触发**仅由点击顶部 `48×48dp` `展开侧栏` 按钮或点击 `我的` 图标发起，**不设屏幕左缘右滑手势**（避免与 Android 系统左缘预测性返回手势及第 7.1 节冲突）。**收回触发**支持在已展开的浮层抽屉或暗罩上向左跟手拖拽（起点位于屏幕内部 `x > 64dp`，不碰边缘返回区）、点遮罩/收起按钮/任一条目、按系统返回键或外接键盘 `Escape`。浮层展开时**锁定无障碍与键盘焦点**（底层中右内容对 TalkBack 与 `Tab` 隐藏）；从浮层内点击 `管理版块` 或顶部账号行打开居中模态框时，同步先关闭该 `240dp` 浮层，避免双层模态叠放。
    - `≥ 840dp` 空间充裕，默认**常驻展开**，点击顶部按钮在“常驻展开 `176–220dp` ↔ 常驻收起 `64dp`”间原地伸缩（`spatialSlow`），并按横竖方向分别记住用户偏好（默认展开，进程回收后可恢复）。
  - **三栏无障碍遍历顺序**：三栏外层容器为左栏、中栏、右栏分别声明 `isTraversalGroup = true` 与语义 `paneTitle`（左→中→右），防止 TalkBack 在多栏顶栏间横向乱跳。
- **中右分隔线与拖动吸附**（适用于 `≥ 680dp` 的三栏）：
  - 中栏与右栏之间是一条 `1dp` 分隔线，**不占布局宽度**；拖动热区宽 `48dp`，横跨中右两栏边缘之上。
  - 拖动时完全跟手，松手后带着松手速度用 `spatialSnap` 吸附到最近档位。令 $S = W - L$（中右两栏总宽）：
    1. **列表收起**（中栏宽 `0dp`，右栏占满 $S$，左栏保持当前展开/收起态便于切版块）：**只有右栏有内容时可用**；右栏为空占位时这一档不存在，拖到最左弹回默认宽度。
    2. **默认宽度**：$M_{\text{default}} = \text{clamp}(0.40 \times S,\ 256\text{dp},\ 380\text{dp}).\text{roundToInt}()$（保证 $S - M \ge 360\text{dp}$）。
    3. **均衡**：$M_{\text{balanced}} = \min(0.50 \times S,\ S - 360\text{dp},\ 480\text{dp}).\text{roundToInt}()$；若与默认宽度相差不到 `24dp`，不单独设这一档。例：`680dp`（$S=616$）与 `701dp`（$S=637$）合并为 2 档；`744dp`（$S=680$）→ `320dp`；`749dp`（$S=685$）→ `325dp`；`840dp` 展开（$S=664$）→ `304dp`；`900dp` 展开（$S=720$）→ `360dp`；`1280dp` 展开（$S=1060$）→ `480dp`。
  - **分隔线无障碍与键盘操作**：分隔线节点暴露 `CustomAccessibilityAction`（`默认宽度` / `均衡` / `收起列表`，右栏为空时不暴露 `收起列表`），并支持外接键盘聚焦后按 `Enter` 或左右方向键在可用档位间切换。
  - 系统按横竖方向分别记住中右分隔线的上次吸附位置；恢复时若右栏为空而记住的是“列表收起”，改用默认宽度。
  - **详情透明顶栏的圆形“全屏阅读”按钮**：置于右栏透明液态玻璃顶栏右侧（`40dp` 视觉圆钮包裹于 `48×48dp` 触控区），点一下同时隐藏左栏与中栏（进入真沉浸全屏，右栏铺满窗口、正文最大 `680dp` 居中），按钮切换为 `显示列表`；再点一下一键恢复进入全屏前的左栏状态（展开或图标轨）与中栏吸附档位。铰链分隔双栏下无左栏，效果等同于收起/显示列表。
- **600dp / 680dp / 840dp 断点处的连续性**：
  - `599dp ↔ 600dp`：底部胶囊以 `exit(spatialDefault)` 退出，左侧 `64dp` 图标轨以 `spatialSlow` 滑入，论坛顶部版块标签行收起，内容区保持单栏与当前阅读位置。
  - `679dp ↔ 680dp`：左栏保持 `64dp` 图标轨不变，内容区以 `spatialSlow` 由单栏平滑展开为 `256dp` 中栏 + `360dp` 右栏（若原本正在看帖子，帖子无缝落在右栏）。
  - `839dp ↔ 840dp`：无底部胶囊与侧栏的形态跳变——`839dp` 时为 `64 + 310 + 465dp`，`840dp` 时左栏原地以 `spatialSlow` 展开到 `176dp`，中右两栏平滑过渡至 `266 + 398dp`（若用户在 `≥ 840dp` 主动收起了左栏，则 `839dp → 840dp` 栏宽完全连续无变化：`64 + 310 + 465 → 64 + 310 + 466dp`）。
- **铰链**：物理铰链将屏幕竖向分开（`isSeparating` 为真，例如半折书本态）时，强制不启三栏（防止中栏横跨物理折痕），按 `hingeBounds` 计算 `leftW = hingeBounds.left` 与 `rightW = W − hingeBounds.right`：
  - **满足 `leftW ≥ 280dp` 且 `rightW ≥ 360dp`**（如 Fold8 横展 `749dp` 单侧 `~374dp`、Fold6 横展 `860dp` 单侧 `~430dp`、Pixel 9 Pro Fold `852dp` 单侧 `~426dp`）：启用**铰链双栏**，分界严格对齐铰链（左栏列表 + 右栏详情，既守住右栏 `≥ 360dp` 硬底线又保证左侧紧凑胶囊在 `1.25×` 字号缩放下不裁切），分隔线固定于铰链处仅保留“列表收起”切换；导航退回**紧凑胶囊**，放在列表侧居中不压铰链，同时恢复列表顶部的版块标签行。
  - **任一侧不足（`leftW < 280dp` 或 `rightW < 360dp`，如 `701dp` 半折单侧 `350.5dp` 或窄窗跨铰链）**：内容退回**单栏铺满窗口**（保留版块标签行，列表推入详情）；导航仍使用**紧凑胶囊**，水平居中于铰链外**较宽的一侧**（等宽取左侧）以避开物理折痕，仅当较宽一侧 `< 280dp` 时改为整窗底部居中。
  - 内屏完全展平时（`isSeparating` 为假）不避让折痕。半折横放的桌面姿态（tabletop）不做特殊上下布局。
- **键盘**：软键盘可见时（`WindowInsets.isImeVisible`），底部胶囊（`< 600dp`、矮屏或铰链分隔）立即隐藏，不随键盘上推；键盘收起后恢复。`≥ 600dp` 左侧栏固定贴边，不受软键盘高度遮挡影响。
- **字号**：正文和列表标题共 5 档，每档相差 1sp（14、15、16、17、18sp，默认 16sp），再乘以系统的字体缩放。导航胶囊、左侧栏文字和底部工具条里的文字最多放大到 `1.25` 倍；胶囊和工具条用最小高度（胶囊 64dp），文字变大时长高不裁切；左栏项最小高 `48dp`，单行超出时省略号不换行。窗口宽度 `< 360dp` 时，底部胶囊只给选中项显示文字，其余只显示图标。
- 帖子正文的最大行宽为 `680dp`（16sp 中文约 40 字一行），超出部分居中留白。
- 何时单栏、图标轨单栏、紧凑三栏或完整三栏完全由窗口尺寸与铰链状态决定，不设手动强制开关（用户只需用左栏收起按钮、中右分隔线与“全屏阅读”按需调节）。中等宽度不用 Material 默认的单栏策略，改用上表规则（tech-plan §7）。

| **Galaxy Tab S9 11"（One UI 默认 711dp 档）** | `711 × 1138` → **紧凑三栏**（`64 \| 259 \| 388`） | `1138 × 711` → **完整三栏**（`220 \| 367 \| 551`） |
| **Galaxy Tab Ultra 14.6"（924dp 档）** | `924 × 1480` → **完整三栏**（`185 \| 296 \| 443`） | `1480 × 924` → **完整三栏**（`220 \| 380 \| 880`，正文 `680` 居中） |
| **小平板 8.8"（Legion Tab / Xiaomi Pad 6 档）** | `640–641 × 1024` → **2 栏**（`64 \| 内容 576–577`） | `1024–1026 × 640` → **完整三栏**（`205 \| 328 \| 491–493`） |

结论：在统一规则下，**全部主流折叠屏内屏（含用户当前高缩放的 Fold8 自然展开 `749dp`、甚至 2022 年初代 vivo X Fold 横拿 `720dp` 与国产大折叠最保守 480dpi 推算）至少在一个常用握持方向上呈现三栏**，且右栏正文始终维持在 `360–680dp` 舒适区间。

**三栏、铰链双栏与图标轨单栏的返回栈规则**
- **点左栏的版块或功能入口（三栏 `≥ 680dp`）**：**替换**中栏的根列表，不压入左栏切换历史（连点 5 个版块后按返回不会逐个回退看过的版块）；同时按目标更新右栏——跨版块或跨列表类入口切换时，右栏重置为对应空占位（防止左中与右栏内容错位）；点 `设置` 时右栏默认展示第一组 `外观与阅读`。各版块与功能入口的列表滚动位置各自记住，切回时恢复。
- **在图标轨单栏（`600–679dp`）下点左栏入口与按返回**：
  - 点左栏（或 `240dp` 浮层）的任一版块或功能入口，**清空单栏当前的详情与下钻栈**，直接将单栏根列表替换为目标入口列表（不压入左栏切换历史；各入口列表滚动位置各自记住）。
  - 按系统返回（含预测性返回）优先级：(1) 关闭顶层浮层（`240dp` 左侧栏浮层、看图、完整编辑器、登录/账号、管理版块）；(2) 若单栏位于详情或下钻页，逐级退回根列表原滚动位置；(3) 若当前停在非默认首页入口的根列表，回到默认论坛入口；再按一次交还系统退出应用。
- **在中栏（或铰链左栏）点另一条帖子（会话、提醒、设置分组）**：**替换**右栏的根页面，不压栈。右栏返回栈始终是 `[当前项, 当前项内的下钻页…]`。
- **在右栏内下钻**（帖子 → 用户资料、帖子 → 站内链接的另一篇帖子）：压入右栏自己的栈，右栏顶栏出现返回箭头。
- **三栏与铰链双栏下按系统返回（含预测性返回）优先级**：
  1. 若存在顶层浮层（左栏 `240dp` 浮层展开态、看图、完整编辑器、登录/账号、管理版块）→ 先关闭该浮层；
  2. 否则若处于“全屏阅读”态 → 退出全屏恢复分栏；
  3. 否则若右栏有下钻页 → 退回右栏上一页；
  4. 否则若右栏处于根页面（非空占位、且非设置页默认选中态）：
     - 三栏与常规铰链双栏：清空右栏回到安静占位；
     - 铰链双栏中左栏已晋升为 `浏览历史 / 我的帖子 / 收藏与关注` 子列表且右栏为帖子详情时：关闭帖子详情并退回 `左：我的菜单 | 右：原副列表（保持滚动位）`；
     - 铰链双栏中处于 `左：设置分组 | 右：设置子页`（右栏无下钻）时：退回 `左：我的菜单`；
  5. 否则若当前停在非默认首页入口（如 `短消息`、`提醒`、`搜索`、`我的`、`设置` 等）→ 回到默认论坛入口；再按一次交还系统退出应用。
- 因此在中栏连点 5 篇帖子后，按一次返回即回到“列表 + 占位”，不会逐条回退看过的帖子。

### 4.3 折叠、展开、旋转时的状态迁移
- **单栏（外屏 / `< 600dp`）→ 三栏（`≥ 680dp`，例如 Fold8 或 Pixel 9 Pro Fold 直接展开）**：
  - 单栏正在看帖子（或 `[帖子, 用户资料]`）时：直接进入三栏（`680–839dp` 紧凑三栏或 `≥ 840dp` 完整三栏）——左栏高亮来源版块或功能入口（如 `提醒`、`浏览历史`），中栏自动定位到该帖所在列表并标出选中，右栏保持 `[帖子, 用户资料]` 栈顶与原阅读位置（页码、楼层、偏移量）及未发送的快速回复输入。
  - 单栏正在看列表时：左栏高亮当前版块/入口，中栏延续列表与滚动位置（隐藏版块标签行），右栏显示对应安静占位（`设置` 则展开第一组子页）。
- **三栏（`≥ 680dp`）→ 单栏（`< 600dp`，如合上外屏或 Fold8 旋转至 `559 × 749dp` 竖拿）**：
  - 若右栏有打开的内容（帖子、对话、设置子页、用户资料），单栏直接显示右栏栈顶，阅读位置与输入态原封不动；返回栈重建为 `[当前列表, 帖子/对话, 下钻页…]`，逐级返回回到列表时停在原滚动位置，并按第 3.2 节映射表点亮底部胶囊对应一级目的地。
  - 若右栏为空占位，单栏直接显示中栏当前列表与滚动位置（论坛恢复顶部版块标签行）。
- **展平三栏（`isSeparating == false`）↔ 半折铰链双栏（`isSeparating == true`）**（同宽度姿态变化，如 Fold8 `749 × 559dp` 或 Fold6 `860 × 744dp` 半折书本态）：
  - **展平三栏 → 半折铰链双栏**：
    - 当 `leftW ≥ 280dp && rightW ≥ 360dp` 时：左栏退场，列表侧居中出现紧凑胶囊（论坛恢复横向版块标签行）；中栏直接承接为铰链左栏、右栏直接承接为铰链右栏，正在阅读的帖子/对话/设置子页、页码/楼层/偏移量、右栏下钻栈 `[帖子, 用户资料]` 与快速回复输入零丢失。其中：`短消息`/`提醒` 在左栏恢复消息分段标签并选中当前项；`浏览历史 / 我的帖子 / 我的回复 / 收藏与关注` 若右栏正打开帖子 `T`，左栏承接该子列表（顶栏出现返回 `我的` 箭头）、右栏原样保活帖子 `T` 与输入态；若右栏为空占位，左栏显示 `我的` 菜单、右栏显示该子列表并保持原滚动位；`设置` 则左栏承接 5 个设置分组（带返回 `我的` 箭头）、右栏保活当前设置子页。
    - 当任一侧不足最低宽（如 `701dp` 半折单侧 `350.5dp < 360dp`）而触发铰链退回单栏时：按“三栏 → 单栏”规则保活右栏栈顶与输入并重建返回栈，紧凑胶囊居中置于较宽一侧避开铰链。
  - **半折铰链双栏 → 展平三栏**：
    - 紧凑胶囊退场，左侧栏按当前宽度恢复（`680–839dp` 为 `64dp` 图标轨，`≥ 840dp` 恢复常驻展开或用户收起偏好）并高亮当前版块/入口，论坛隐藏横向版块标签行；铰链左栏与右栏直接恢复为中栏与右栏，阅读位置与输入零丢失；若半折时停在 `我的菜单 | 子列表`，展平后左栏高亮该子项（未进子项则按第 3.2 节映射优先最近访问或 `收藏与关注`）、子列表晋升至中栏（保留滚动位）、右栏显示对应安静占位。
- **紧凑三栏（`680–839dp`）↔ 完整三栏（`≥ 840dp`）**（如 Z Fold6 / Z Fold7 / 国产大折叠横竖旋转或拖拽分屏）：
  - 左栏在 `64dp` 图标轨与 `176–220dp` 常驻展开间原地平滑伸缩（`spatialSlow`），中栏与右栏组件树不重建、选中态与阅读位置完全不变；若从紧凑三栏的浮层展开态直接拉宽过 `840dp`，浮层平滑过渡为常驻左栏并消去暗罩。
- **图标轨单栏（`600–679dp`）↔ 紧凑三栏（`680–839dp`）** 与 **单栏（`< 600dp`）↔ 图标轨单栏（`600–679dp`）**：
  - 分别只变化内容栏数或导航载体（正交切换），已打开帖子/列表滚动位置均通过单一状态源与同树搬移（`movableContentOf`）原地保活，不重新发起网络请求。
- **跨形态恒定保持的状态**：完整编辑器在任何形态变化后均保持打开，输入内容、光标、已上传图片全部保留，仅按第 4.2 节切换居中浮层或右栏承载；正在输入的快速回复、草稿、滚动位置、展开的引用、分段标签选择、左栏展开/收起偏好与中右吸附偏好（按方向分存），在任何形态变化和进程被系统回收后全部保留。
- 布局切换的动画见第 6.3 节“布局变化”。

### 4.4 三栏方案的取舍
以下备选方案经实测数据与源码调研后明确否决：

1. **否决：将三栏门槛定在 Material 3 Large 断点（`1200dp`）**
   - 理由：所有主流折叠屏内屏（Z Fold8 实测 `559×749dp` / 推算 `933dp`、Z Fold6 `744×860dp`、Pixel 9/10 Pro Fold `852×883dp`、国产大折叠 `719–902dp`）和 11" 平板竖屏均不足 `1200dp`，将导致折叠屏永远无三栏。M3 默认 `1200dp` 三栏是按 `3 × 412dp` 内容面板估算，而本应用的左栏是紧凑中文导航栏（收起 `64dp` / 展开 `176–220dp`），不需要 `1200dp`。
2. **否决：只在 `≥ 840dp` 启三栏，让 `680–839dp` 继续停留在“底部胶囊 + 双栏”**
   - 理由：用户真机 Galaxy Z Fold8 自然展开实测为 `749 × 559dp`，此外 Z Fold6 竖拿（`744dp`）、Pixel Fold 竖拿（`701dp`）、荣耀/vivo/OPPO 480dpi 保守推算（`719–827dp`）及 Pixel Tablet 竖屏（`800dp`）全部落在此区间。不仅无法在这些折叠屏上展示三栏，且底部胶囊与右栏帖子底部工具条上下叠放两层会吃掉 Fold8 横屏 `559dp` 高度中近四分之一的阅读区。改由 `64dp` 常驻图标轨（可浮层展开 `240dp`）接管，既实现三栏并多出 `72dp` 纵向高度，又把正文维持在 `360–465dp`。
3. **否决：在 `680–839dp`（如 `744–749dp`）强行常驻三个带文字完整栏**
   - 理由：`749dp` 减去带文字左栏（最低 `176dp`）与中栏（最低 `256dp`）后右栏仅剩 `317dp`，跌破 `360dp` 阅读底线，长帖与引用块严重局促。用“常驻 `64dp` 图标轨 + 一键 `240dp` 浮层展开”在空间与辨识度之间取得最优解。
4. **否决：保留原 `80dp` 左侧导航轨、再新增一栏只放版块**
   - 理由：白白占用 `80dp` 横向宽度并制造重复导航层级。左栏直接整合旧版抽屉全部功能入口与关注版块并取代导航轨，所有横向空间都留给阅读。
5. **否决：左栏与中栏之间也做可拖拽分隔线**
   - 理由：折叠屏 7.6–8" 触摸屏上双拖拽柄极易误触且增加布局状态组合复杂度。左栏为低熵导航列表，响应式宽度（`176–220dp`）+ 一键收起至 `64dp` 已覆盖“看全名”与“要空间”两种诉求。
6. **否决：直接套用 Compose `NavigationSuiteScaffold` + `ListDetailPaneScaffold` 默认配置**
   - 理由：核实 AndroidX 源码（`NavigationSuiteScaffold.kt:1168-1181`、`PaneScaffoldDirective.kt:48-76, 345-348`、`ListDetailPaneScaffold.kt:226-258`），前者默认仅在 Medium+ 提供 `96dp` 收起轨而不支持带关注版块长列表的可切换侧栏与毛玻璃底部胶囊；后者原生三槽位是 `List + Detail + Extra`（且须 `≥ 1200dp`、默认每栏 `412dp`），而非“常驻导航侧栏 + List + Detail”。因此采用自研自适应外壳承载左栏（`HiNavigationSidebar`）+ 中右内容双栏；具体实现优先复用 Compose / Material 3 现成组件（如 `Column`/`LazyColumn` + `ModalNavigationDrawer`/`ModalWideNavigationRail`、`Row` + `AnchoredDraggable` 或自定义 `PaneScaffoldDirective` 的 `ListDetailPaneScaffold`），确需自写 `Layout`/`Modifier.Node` 时须说明理由。
7. **对 FluxDO（`Lingyan000/fluxdo`）的借鉴与取舍**：
   - **借鉴**：(a) 从 `600dp` 起用左侧紧凑常驻图标轨取代底栏，并在轨内直接内嵌用户置顶/关注的版块快捷图标（`AdaptiveNavigationRail` + `CategoryShortcuts`），零底部高度损耗；(b) 分栏判定轴与布局分配轴严格同轴——先扣掉左栏应占宽再计算中右两栏，避免中间宽度的挤压带（`NavChromeMetrics`）；(c) 宽窄切换采用单一状态栈 + 同树保活（不 push 合成全屏路由），防止折叠/旋转丢状态或关闭不掉。
   - **不借鉴**：(a) FluxDO 将默认双栏门槛定在整窗 `852dp`（搜索 `992dp`、设置 `932dp`），导致 Fold8 实测 `749dp`、Fold6 竖拿 `744dp` 与 Pixel Tablet 竖屏 `800dp` 全部只能看单栏，且全宽度无常驻文字侧栏（线上 `extendedRail` 恒为 `false`，始终停留在 `72dp` 纯图标轨）；(b) FluxDO 未做物理铰链避让，无“列表收起 / 一键全屏阅读”吸附档，且按宿主分散多套阈值；(c) FluxDO 首页无限压栈的“胶片带”模型（§11 明确不做）与多套列表宽契约增加了理解成本，本应用坚持清晰的“左栏常驻 + 中栏列表 + 右栏单根下钻栈”。

## 5. 视觉
- **颜色**：Material 3 配色。Android 12 及以上默认从壁纸取色，只取一个主色作为种子，再按统一规则生成整套颜色；用户也可以从一组预设色里选一个作为种子；取不到壁纸色时用 HiPDA 的品牌色。深色模式保留“纯黑”选项（OLED）。主题默认跟随系统。
- **字体与排版**：使用系统中文字体（暂不做自定义字体导入）。帖子列表标题默认 16sp，行高 1.4；已读的帖子降一级字重并变灰。正文默认 16sp，行高 1.65（行距可选三档：1.5、1.65、1.8）。字号档位见第 4.1 节。
- **形状**：圆角统一分 4 档：小 8dp（标签、按钮）、中 12dp（卡片、楼层引用）、大 20dp（底部面板、对话框）、全圆角（胶囊导航、搜索框、筛选胶囊）。头像统一为圆形。
- **层级**：内容区卡片不用阴影，靠表面颜色深浅区分层级；悬浮在内容之上的液态玻璃浮层（透明顶栏、底部导航胶囊、帖子详情三段工具条、毛玻璃快速回复面板）靠光学折射、方向高光描边与极淡柔影区分层级。
- **顶栏**（取消“顶栏纯色不用毛玻璃”旧规定，按场景分层）：
  - **论坛顶栏与吸顶版块标签行（`< 600dp` / 矮屏）**：内容区全屏滚动并通过 `contentPadding(top = 顶栏总高)` 避让，列表从顶栏后方滚过。未滚动时背景为纯净 `surface`；向下滚动仅折叠上行（版块名 + `发新帖` + `更多`），下方**版块标签行吸顶不隐藏**，稍微上划即重新展开上行，顶栏背景随滚动/折叠以 `effectsDefault` 平滑过渡为 `TopBar` 透明液态玻璃。标签行采用 `BalancedTabRow` 自适应排布（全部放得下时等分居中，放不下时横向滑动并自动滚入选中项），右侧固定不随标签滚走的 `管理版块` 按钮；选中项字重提升、略放大（未选中 `15sp Regular onSurfaceVariant` → 选中 `16–17sp Bold onSurface`，遵循 `1.25×` 缩放钳制），文字下半部绘圆角横向渐变**荧光笔底条**（使用 `MaterialTheme.colorScheme.primary` 或 `primaryContainer` 的半透明横向渐变，**严禁使用 kudo 品牌黄 `#FFB003`**，叠加后文字对比度 ≥ 4.5:1），每项触控区高 ≥ `48dp`。
  - **大屏列表栏顶栏（`≥ 600dp` 图标轨单栏与 `≥ 680dp` 三栏中栏）**：继续隐藏横向版块标签行（避免与左侧栏重复），中栏顶栏（版块名 + `发新帖` + `更多`）采用 `TopBar` 透明液态玻璃，列表从其背后滚过，滚动后由纯净 `surface` 以 `effectsDefault` 渐进过渡为液态玻璃，作为三栏同屏最多 3 块实时玻璃之一。
  - **帖子详情透明极简顶栏**：取消实色分割感，楼层列表从顶栏背后滚过（`contentPadding(top = 顶栏高)`），顶栏与正文为严格兄弟节点共享同一 `layerBackdrop`，滚动后渐进显现 `TopBar` 轻护读液态玻璃。左侧为独立 `40dp` 视觉圆形动作按钮（`48×48dp` 触控区，`返回`，单栏常显、三栏/铰链双栏仅右栏下钻时显示）+ 帖子标题/楼主简讯；右侧为独立 `40dp` 圆形动作按钮（三栏/铰链双栏独有的 `全屏阅读 / 显示列表` 与 `只看楼主` 快捷切换，不搬运 kudo 实心黄“关注作者”按钮）。
  - **纯色顶栏例外**：(a) `≥ 600dp` 左侧栏主体与顶部固定区保持纯色 `surfaceContainerLow`（滚动后顶部固定区以 `effectsDefault` 渐变为 `surfaceContainer` 并显现 `1dp` `outlineVariant` 底线，不使用毛玻璃）；(b) 铰链双栏的左列表顶栏与吸顶版块标签行保持纯色 `surface → surfaceContainer`（为左紧凑胶囊 + 右详情顶栏 + 右底部工具条留出 3 块上限配额）；(c) 表单/设置子页、登录、完整编辑器与 Cloudflare 验证 WebView 宿主保持纯色顶栏，不建立无谓采样层。
  - 双栏或三栏时，左栏顶部固定区、中栏顶栏、右栏顶栏各自独立随本栏滚动响应。
- **液态玻璃（毛玻璃，底层引擎由 Haze 换为 Kyant `io.github.kyant0:backdrop`，Apache-2.0）**：
  - **适用部位与同屏上限（放宽至 3 块）**：用于(1) 底部悬浮导航胶囊（`< 600dp` / 矮屏 / 铰链分隔）、(2) 透明吸顶顶栏（单栏论坛顶栏、大屏中栏顶栏、帖子详情顶栏）、(3) 帖子详情底部三段式工具条（含展开后的内联跳页条）、(4) 毛玻璃快速回复面板。**任何布局下全屏活跃实时玻璃区域（slot）同时最多 3 块，且独立 `layerBackdrop` 采样源最多 2 个**（同一栏内的三段工具条或顶栏圆形动作按钮共享同一个兄弟 `layerBackdrop`，按 1 个逻辑区域计数）：
    - 单栏一级页：论坛吸顶顶栏（1）+ 底部导航胶囊（1）= **2 块**（1 采样源）；
    - 单栏帖子详情：详情透明顶栏（1）+ 底部三段工具条（1）= **2 块**（1 采样源）；
    - 图标轨单栏（`600–679dp`）：左轨纯色（0）+ 单栏顶栏（1）+ 进入详情时的底部三段工具条（0 或 1）= **1–2 块**（1 采样源）；
    - 三栏（`≥ 680dp`）：左栏纯色（0）+ **中栏顶栏（1）+ 右栏详情顶栏（1）+ 右栏底部三段工具条（1）= 3 块**（2 采样源：中栏列表 + 右栏详情）；
    - 铰链双栏：左列表顶栏纯色（0）+ **左紧凑胶囊（1）+ 右栏详情顶栏（1）+ 右栏底部三段工具条（1）= 3 块**（2 采样源）；
    - 展开毛玻璃快速回复面板时：面板覆盖底部三段工具条并**暂停被覆盖工具条的实时玻璃绘制**，使活跃实时玻璃仍严格 ≤ 3 块（单栏 2 块、三栏 3 块）。
  - **三级硬件分档与 4 路系统自动降级**：
    - **Android 13+（API 33+）且系统允许模糊（液态玻璃档）**：启用实时模糊 + `vibrancy()` / `colorControls()` 色彩保真（去脏灰）+ AGSL 光学边缘透镜折射 `lens()`（仅适度边界折射，护读顶栏/工具条/面板抑制中心畸变与过强色散）+ 中性容器色罩（浅色 `surfaceContainerLowest`，深色/纯黑 `surfaceContainer`）+ 方向高光描边；
    - **Android 12 / 12L（API 31–32）且系统允许模糊（纯模糊档）**：关闭 `lens()` 光学折射，保留实时模糊 + 色彩增强 + 中性容器色罩 + 左上→右下方向渐变高光描边；
    - **Android 11 及以下（API ≤ 30）或 4 路系统信号任一命中**（API ≤ 30、省电模式、系统“降低透明度/禁用窗口模糊”、高对比度文字/高色彩对比度）：完全停用 `drawBackdrop` 并释放 `layerBackdrop` 离屏录制，改为**不透明度 94% 的纯色表面**（回复面板高隔离态 94%–96%）+ `0.5dp` `outlineVariant` 细描边。
  - **四档预设参数起点（M4/C3b 真机校准后回写本文，均以 HiPDA M3 中性色为基底，不用 kudo `#FFB003`）**：
    - `Navigation`（底部导航胶囊，轻透）：模糊 `8–10dp`，着色 `surfaceContainerLowest @ 0.40–0.46`（浅）/ `surfaceContainer @ 0.42–0.48`（深），提饱和 `vibrancy()`，API 33+ 边缘 `lens()`；
    - `TopBar`（论坛吸顶顶栏、三栏中栏顶栏、详情透明顶栏，轻护读）：模糊 `12–16dp`，着色 `0.58–0.66`（浅）/ `0.62–0.70`（深）（**严禁照抄 kudo 的 `4dp + 20%`**，防止高对比配图透出花眼），提饱和 `vibrancy()`，API 33+ 轻边缘 `lens()`；
    - `Toolbar`（帖子详情底部三段工具条与内联跳页条，护读）：模糊 `14–16dp`，着色 `0.56–0.64`（浅）/ `0.62–0.68`（深），提饱和 `vibrancy()`，API 33+ 边缘 `lens()`；
    - `Sheet`（毛玻璃快速回复面板，高隔离护读）：模糊 `16–18dp`（暗 `10–14dp`），着色 `0.68–0.76`（浅）/ `0.60–0.70`（深），`20dp` 顶部圆角，`1dp` 高光/边界描边，背后叠淡暗罩（`scrim @ 0.32–0.38`）。
  - **可读性硬要求（模糊态与降级态双保障）**：模糊开启态（含极端彩色配图、纯白/纯黑正文从背后滑过时）与 94% 纯色降级态下，玻璃上的全部文字、版块标签（含荧光笔底条叠加）、进度胶囊页码（含进度填充条叠加）、输入框与图标前景对比度均不得低于 **4.5:1**；若真机极端背景实测不达标，优先提高对应档位着色不透明度，绝不降低对比度要求。
  - **防循环采样铁律**：`layerBackdrop` 采样源与所有消费它的毛玻璃表面必须保持**严格兄弟节点**关系，严禁毛玻璃表面自身或其祖先落入该采样源（防止 RenderThread `libhwui.so` 崩溃）；`WebView` 页面严禁接入 `layerBackdrop`。
  - **真机 120Hz 帧率不达标时的预定回退顺序**（每降一级在真机复测 120Hz 滚动帧率，达到 P90 < 8.3ms 且卡顿率 ≤ 1% 即停止）：
    1. **第 1 级（先关高开销折射，保留 3 块模糊）**：先关闭大面积顶栏的 AGSL `lens()` 边缘折射与色散（退为纯模糊 + 提饱和 + 渐变高光描边）；仍不达标则全屏关闭 `lens()`，保留 3 块实时模糊。
    2. **第 2 级（三栏缩为 2 块——先退中栏顶栏为纯色）**：三栏态下将**中栏（列表栏）顶栏**退回纯色 `surface → surfaceContainer` 并移除中栏 `layerBackdrop` 采样源（只保留右栏顶栏 + 右栏底部三段工具条 2 块玻璃、1 个采样源）；铰链双栏同理先将右栏顶栏退纯色（保留左胶囊 + 右工具条共 2 块）。
    3. **第 3 级（全部顶栏退纯色，仅留核心底浮层）**：进一步将帖子详情顶栏与单栏论坛吸顶顶栏均退回纯色 `surface → surfaceContainer`（顶栏圆形按钮保持轻量半透明或纯色底），仅保留底部悬浮导航胶囊、详情底部三段工具条与展开态快速回复面板为实时玻璃（各形态均 ≤ 1 块常驻实时玻璃）。
    4. **第 4 级（兜底降级）**：缩小模糊半径/采样分辨率，或在性能不足机型/API 档默认关闭实时模糊、统一走 94% 不透明纯色降级态。
  - **内容延伸与上下留白**：
    - 上方：启用透明顶栏的列表与详情页，内容全屏延伸至顶栏与状态栏后方滚动，顶部按顶栏完全展开高度设置固定 `contentPadding(top)`，确保首项完整可见且折叠时不跳动；
    - 下方：内容延伸到毛玻璃浮层下方滚动，每一栏末尾按浮层完全可见高度留白（不随滚动收起变化，避免跳动）：单栏一级目的地留“胶囊 + 8dp + 底部手势区”；帖子详情留“三段工具条 + 8dp + 底部手势区”；`≥ 600dp` 侧栏态下，左栏与中栏只需留“底部手势区”，右栏帖子详情留“三段工具条 + 8dp + 底部手势区”；物理铰链分隔双栏时，列表栏留“紧凑胶囊 + 8dp + 底部手势区”，右栏留“三段工具条 + 8dp + 底部手势区”。
- **导航胶囊**：最小高 `64dp`；左右各留 `16dp` 边距，最宽 `420dp`，居中；距离手势条 `8dp`；**固定 4 项（`论坛` / `消息` / `搜索` / `我的`），不加中间“+”按钮**。选中指示器为半透明主题色淡底胶囊（`primary @ 12%` + `primary` 图标文字），不阻断毛玻璃连续透光；支持点击滑动切页与横向**跟手拖拽预选**（拖动实时高亮经过项，松手吸附切页，拖离取消弹回原项；API 33+ 拖拽期间滑动镜片可轻微放大并呈现边缘光学折射）。
  - **紧凑胶囊**（高度小于 `480dp`，或物理铰链分隔时）：最小高 `48dp`，4 项无“+”，只显示图标，选中项加文字，同样支持跟手拖拽预选。
- **左侧栏（`≥ 600dp`）**：纯色 `surfaceContainerLow` 表面（与内容区 `surface` 形成柔和层级差，顶部固定区同为 `surfaceContainerLow`，不使用毛玻璃），右侧 `1dp` `outlineVariant` 细分隔线；`600–839dp` 浮层展开（`240dp`）时使用大圆角右边缘（`20dp`）与半透明暗罩（`scrim`）。选中项以浅色胶囊（`secondaryContainer`）高亮，图标轨态为居中圆角胶囊（`44×44dp`），展开态铺满行内边距。
- **帖子详情的底部三段式工具条**：三段独立液态玻璃胶囊（`Toolbar` 档，高 ≥ `48dp`，段间 `8dp`，共享同一右栏/详情 `layerBackdrop`，距窗口底边 `8dp + 底部手势区`；三栏与铰链双栏居中置于**右栏底部**不跨分隔线）：
  1. **左段（回复胶囊）**：笔形图标 + `回复`；右栏窄宽且三段自然宽超 `右栏宽 − 32dp` 时自动缩为纯图标 `48×48dp` 胶囊；
  2. **中段（阅读进度胶囊）**：占满左右之间剩余宽，显示 `第 N / M 页`（紧凑态 `{N}/{M}`），胶囊内部从左向右绘 `MaterialTheme.colorScheme.primary @ ~22%–26%` 半透明阅读进度填充条（按当前可见首楼所在页 / 总页数计算，由胶囊形状裁切，保证叠加后文字对比度 ≥ 4.5:1，不用 kudo 黄色）；点按**原地展开**为全宽（右栏宽）内联跳页条（滑块 + 页码输入 + `首页` / `末页` 快捷按钮 + 关闭/确认，见第 7.3 节）；
  3. **右段（操作组胶囊）**：HiPDA 专属双操作组 **`收藏`** + **`更多`**（两个独立 `48×48dp` 触控区，不含点赞或助推）。
- **毛玻璃快速回复面板**：贴底 `20dp` 顶部圆角 `Sheet` 护读液态玻璃面板，顶部 `32dp` 拖动把手 + 回复对象提示 + 右上角 `48×48dp` `展开全屏` 按钮，底部单行横向滚动快捷工具行 + `发送` 按钮；单栏铺满宽，三栏与铰链双栏严格限定在**右栏底部**升起（背后暗罩仅盖右栏，不遮挡左栏与中栏）。
- **Snackbar 多栏对齐**：单栏下整窗底部居中（最大宽 `600dp`）；`600–679dp` 图标轨单栏居中于右侧内容单栏底部；三栏与铰链双栏下，右栏操作（回复、收藏/关注、复制等）居中于**右栏**底部（详情底部三段工具条上方 `8dp`，不横跨分隔线或铰链），左栏/中栏或全局操作（切换账号、发新帖、删历史、清缓存等）居中于**内容区**（三栏为中右合区、铰链双栏为列表侧避开铰链）底部，不推挤内容。

## 6. 动效系统
### 6.1 总则
- 动效是为了解释变化：东西从哪来、到哪去、和什么有关。不加装饰性的动效。
- 一套语言：所有动效只从第 6.2 节的令牌里取参数，代码里不能直接写时长、曲线，也不能调用会带默认动画参数的无参 API（见第 10.1 节的扫描规则）。
- 克制：越常用的操作越快。切换一级目的地只做淡入淡出，不做位移。
- 跟手、可打断：凡是和位置有关的动画都用弹簧，新的目标出现时从当前位置和速度接着走，不重新开始。拖动时内容跟着手指走。
- 只动必要的属性：优先只动透明度、位移和缩放（graphicsLayer），不在动画过程中改布局尺寸；必须改尺寸的（展开引用、布局切换）用带令牌的 `animateContentSize` 或面板自带的动画，并检查滚动位置不跳。
- **减少动态效果**：以系统设置为准（动画时长缩放为 0，或开了“移除动画”）。应用把系统的缩放值接到 Compose 的 `MotionDurationScale`；缩放为 0 时，所有过渡 0ms，一帧到位，不留中间状态；数字直接变；不做视差。不另设应用内开关。下面两类不是动画，照常生效：防闪的显示延迟（`loadingShowDelay`，避免加载指示一闪而过）和引用高亮（改为静态高亮，停 `highlightHold` 后直接消失）。

### 6.2 令牌
弹簧参数与 Material 3 `MotionScheme.standard` 的 6 档一致（R2 已对照 androidx 源码）。不用 Expressive 那套阻尼比 0.6 的弹簧，它在高频的文字界面里太弹。

| 令牌 | 用途 | 参数 |
|---|---|---|
| `spatialFast` | 小东西移动：选择指示器、开关、图标位移、按钮按压缩放 | 弹簧，阻尼比 0.9，刚度 1400 |
| `spatialDefault` | 页面推入推出、面板升降、右栏下钻、展开收起 | 弹簧，阻尼比 0.9，刚度 700 |
| `spatialSlow` | 大面积的布局变化：分栏出现、消失或左栏伸缩、看图的放大和缩回 | 弹簧，阻尼比 0.9，刚度 300 |
| `spatialSnap` | 松手后的吸附和弹回：分隔线吸附、看图下拉未达阈值弹回、面板未达阈值弹回 | 弹簧，阻尼比 0.85，刚度 1400 |
| `effectsFast` | 颜色、透明度的小变化，按压状态层，工具栏显隐 | 弹簧，阻尼比 1.0，刚度 3800 |
| `effectsDefault` | 内容替换时的淡入淡出、顶栏变色 | 弹簧，阻尼比 1.0，刚度 1600 |
| `effectsSlow` | 大面积遮罩、主题颜色切换、高亮淡出 | 弹簧，阻尼比 1.0，刚度 800 |
| `exit` | 所有退场：取对应入场令牌，刚度 × 2.0，阻尼比改为 1.0（不过冲） | 由入场令牌换算 |
| `spinnerPeriod` | 不确定进度圈转一圈 | 1000ms，线性，无限循环 |
| `skeletonPeriod` | 骨架屏的明暗呼吸一个周期 | 1500ms，无限循环 |
| `loadingShowDelay` | **被动加载**（进入页面、翻页、自动刷新）超过这个时间才显示加载指示；一旦显示，至少停留 `loadingMinShow` | 150ms；`loadingMinShow` 250ms |
| `highlightHold` | 引用跳转后目标楼层高亮的停留时间 | 1000ms |

- 主动操作（点发送、登录、移出黑名单）不用 `loadingShowDelay`：按下后 0ms 原地变成加载状态。
- 只有 `spatialSnap` 允许轻微过冲，而且只用在“回到原位或落到吸附点”；退场一律不过冲。

### 6.3 按状态变化分类的处理方式
| 变化类型 | 例子 | 处理方式 | 令牌 |
|---|---|---|---|
| 一级目的地切换 | 论坛 ↔ 消息 ↔ 搜索 ↔ 我的 | 原地交叉淡入淡出，没有位移；切换后导航胶囊如果被滚动收起了，就回到可见 | `effectsDefault` |
| 层级前进和后退（单栏） | 列表进入帖子；帖子进入用户资料 | 新页面从右侧整页水平推入，旧页面向左退让 1/4 宽度并略微变暗；返回时反过来。系统返回手势（预测性返回）跟手：页面随手指缩小到 0.9 并右移，松手后按位置和速度决定完成返回还是弹回 | 进：`spatialDefault`；退：`exit`；弹回：`spatialSnap` |
| 同级换内容（双栏 / 三栏） | 在中栏（或铰链左栏）点另一条帖子、另一个会话、另一条提醒或另一个设置分组 | 右栏原地交叉淡入淡出，没有位移（表示右栏同一个位置换了详情内容） | `effectsDefault` |
| 右栏下钻（双栏 / 三栏） | 右栏的帖子里点开用户资料 | 新内容从右侧 24dp 处滑入并淡入，旧内容淡出；顶栏出现返回箭头 | `spatialDefault` + `effectsDefault` |
| 左侧栏开合 | `600–839dp` 按钮/`我的` 展开与左滑/点罩收回 `240dp` 浮层；`≥ 840dp` 常驻左栏原地收起为 `64dp` 或展开 | 浮层展开：侧栏从左侧滑入、暗罩淡入，关闭跟手左滑或走 `exit`；常驻伸缩：左栏宽度与中右两栏平滑过渡，文字淡入淡出不折行 | 浮层 `spatialDefault` + `effectsDefault`（退场 `exit`）；常驻伸缩 `spatialSlow` + `effectsDefault` |
| 出现和消失 | 底部面板、菜单、对话框、毛玻璃快速回复面板 | 从来源方向出现：菜单从按下的按钮处展开；面板从底部升起（快速回复面板点 `展开全屏` 平滑进入完整编辑器）；对话框从中心淡入并从 0.9 放大。消失走 `exit` | 面板 `spatialDefault`（展开全屏 `spatialDefault` + `effectsDefault`）；菜单、对话框 `spatialFast` + `effectsFast`；退场 `exit` |
| Snackbar | 撤销、回复已发送 | 浮在对应栏或内容区底部（导航胶囊或底部工具条上方 8dp，多栏下不横跨分隔线与铰链，见第 5 节），从下方升起；**不推挤内容** | `spatialDefault`；退场 `exit` |
| 内容替换 | 切换版块（无论通过版块标签行还是左侧栏）、切换“只看楼主”、跳到不相邻的页 | 旧内容淡出；新内容淡入，同时从下方 8dp 移到原位 | 淡出 `exit(effectsDefault)`；淡入 `effectsDefault` + `spatialDefault` |
| 刷新 | 下拉刷新、过期后自动刷新 | 按帖子 ID（楼层按 pid）原地对比：没变的项不动、不淡出；新增的项淡入并让开位置；屏幕上方有新帖时不移动当前内容，顶部出现“有 N 条新帖”胶囊，点一下滚到顶部 | 项的位置 `spatialDefault`；淡入 `effectsDefault` |
| 连续加载 | 长帖向下滚到页尾、从中间页打开后向上滚 | 向下：距页尾 5 楼时静默预取下一页，接在末尾，不打断滚动。向上：插入上一页的楼层前，记住第一个可见楼层的 pid 和它到屏幕顶部的距离，插入后恢复，偏差不超过 1dp。失败时在列表头或尾原地显示“加载失败，点击重试” | 无位移动画 |
| 数值变化 | 未读数、回复数、页码、上传进度 | 数字逐位上下滚动：增加时向上，减少时向下。数字从 0 变成大于 0 时，角标从中心放大出现；变回 0 时缩小消失 | `spatialFast`；消失 `exit` |
| 图标变化 | 收藏和取消收藏；发送按钮变成对勾 | 旧图标缩小并淡出，新图标放大并淡入，同时进行。对勾用描线的方式画出来 | `spatialFast` + `effectsFast` |
| 选择指示器 | 导航胶囊点击与**跟手拖拽预选**、分段标签、版块标签荧光笔高光、主题色选中 | 导航胶囊/分段标签点击时指示器从旧位置滑到新位置。**导航胶囊跟手拖拽预选**：手指横向拖动中指示器用 `snapTo` 直接跟手实时更新 `previewIndex` 预选高亮（拖动中不切页，不每帧重启弹簧避免高刷滞后），API 33+ 拖动镜片轻微放大折射；松手吸附落位切页，拖离容差或取消弹回原项。**版块标签荧光笔高光**：随选中项原地淡入淡出，不做跨项位移动画 | 点击/松手吸附 `spatialFast`；取消弹回 `spatialSnap`；荧光笔 `effectsFast` |
| 底部工具条内联跳页与进度 | 点中段进度胶囊原地展开/收起内联跳页条；阅读进度填充更新 | 展开时左段与右段向两侧滑离淡出，中段原地扩至工具条全宽（三栏/铰链为右栏宽）；收起时反向还原。拖动滑块仅本地跟手预览不滚屏。中段进度填充条宽度随当前可见页平滑变化 | 展开 `spatialDefault` + `exit(effectsFast)`；收起 `exit(spatialDefault)`；进度填充 `effectsDefault` |
| 按压 | 列表项；按钮、图标按钮、标签、导航项 | **列表项**：按下立即显示状态层，不缩放。**按钮、图标按钮、标签、导航项**：按下立即显示状态层并缩小到 0.97，松开弹回。没有旧版那样的 200ms 延迟。确认类操作（收藏、发送成功、长按出菜单）配合轻微的触感反馈 | 状态层 `effectsFast`；缩放 `spatialFast` |
| 加载、完成、出错 | 发送、上传、首次加载 | 都在原地变化：发送按钮变成进度圈，成功后变成对勾，再恢复；失败时变回发送按钮，输入框下方原地显示原因和“重试”。被动加载按 `loadingShowDelay` 延迟显示。首次加载用和真实内容同样形状的骨架，内容到了以后原地淡入替换，不产生跳动 | 进度圈 `spinnerPeriod`；骨架 `skeletonPeriod`；替换 `effectsDefault` |
| 栏随滚动 | 论坛顶栏上行折叠与版块标签行吸顶、导航胶囊隐显、透明顶栏液态玻璃渐进、看图工具栏显隐 | `< 600dp`（及矮屏、铰链分隔）时，论坛仅**上行标题与动作行**随向下滚动收起、**版块标签行吸顶不隐藏**，稍微上划即重新展开上行，切换版块恢复展开；底部导航胶囊随滚动量跟手滑出，停止滚动按已滚出比例吸附全显或全隐（内容短于一屏、切换目的地、键盘收起后回到可见）。透明顶栏（论坛、中栏、详情）由顶部纯净 `surface` 随滚动渐进呈现液态玻璃。`≥ 600dp` 侧栏态左侧栏常驻不隐藏。看图时单击切换工具栏显隐 | 吸附 `spatialDefault`；玻璃/变色渐进 `effectsDefault`；工具栏 `effectsFast` |
| 引用高亮 | 点引用跳到被引用的楼层；从提醒打开定位楼层 | 目标楼层背景淡入高亮色，停 `highlightHold`，再慢慢淡出 | 淡入 `effectsDefault`；淡出 `effectsSlow` |
| 键盘联动 | 毛玻璃快速回复面板、内联跳页条聚焦输入框随键盘升起；表情面板和键盘互换 | 快速回复面板与内联跳页条逐帧跟随系统键盘动画（`WindowInsetsAnimation` / `imePadding()`），不自己跑弹簧，不会与键盘脱节或露缝。快速回复面板与完整编辑器内，表情面板与键盘同高、原地替换，底缘零位移（规则见第 7.4 节）。正在读的那一楼随内容上移，保持可见 | 跟随系统 |
| 布局变化 | 折叠和展开、旋转、分屏改变宽度（单栏 ↔ 图标轨单栏 ↔ 紧凑三栏 ↔ 完整三栏） | 各栏宽度平滑过渡；正在阅读的内容保持在同一个阅读位置 | `spatialSlow` |
| 尺寸变化 | 展开长引用；投票结果的柱条 | 引用展开时高度跟着内容一起变；柱条从 0 长到目标宽度 | `spatialDefault` |
| 图片占位 | 帖子里的图片加载完成 | 加载前按真实宽高比占好位置（服务器给了尺寸就用；没给时先读图片头信息；都没有时按 4:3 占位），加载完淡入。真实比例和占位不同时：图片在屏幕上方，就补偿滚动距离，当前看的内容不动；图片在屏幕内，就平滑改变这一项的高度 | 淡入 `effectsDefault`；高度 `spatialFast` |
| 删除与撤销 | 删除浏览历史、搜索历史、移出黑名单、删除失败的短消息 | 该行收起，下面的行补上来；Snackbar 给“撤销”，撤销后该行在原位置展开回来 | 收起 `exit(spatialDefault)`；展开 `spatialDefault` |
| 主题切换 | 深浅色、主题色、纯黑 | 不重启页面，所有颜色平滑过渡；滚动位置、输入内容、焦点都不变 | `effectsSlow` |
| 看图的进入和退出 | 点帖子里的缩略图；关闭看图 | 进入：从缩略图的位置和大小放大到全屏，背景遮罩淡入。退出（下拉关闭、点关闭、系统返回、预测性返回都走这里）：回到**当前这张图**对应的缩略图——缩略图完整位于可见内容区内（不被顶栏、工具条遮挡）时，缩回它的位置和大小；否则在原地缩小到 0.85 并淡出 | 进入 `spatialSlow`；缩回 `exit(spatialSlow)`；降级 `exit(spatialDefault)` + `exit(effectsDefault)` |
| 看图的拖拽 | 下拉关闭看图 | 竖向位移占优时开始跟手。下拉 0 → 240dp 期间，图片从 1 缩到 0.8，背景遮罩不透明度从 1 降到 0.3（不再更低）。松手时位移超过 120dp 或向下速度超过 800dp/s 就关闭，并带着这个速度进入退出动画；否则弹回 | 弹回 `spatialSnap` |
| 看图的高清切换 | 缩略图换成高清图；长图 | 高清图解码完成前一直用缩略图垫底，就绪后高清图淡入覆盖。宽高比大于 2.5 的长图，进入时直接以“贴合宽度、对齐顶部”为目标，加载后不再自动跑缩放动画 | `effectsFast` |
| 下载和播放 | 看图里下载原图；GIF | 原图下载显示确定进度圈，再点可以取消；GIF 左上角有“GIF”角标，点一下播放或停止 | 角标 `effectsFast` |
| 拖拽（通用） | 分隔线、毛玻璃快速回复面板下拉关闭/上拉展开全屏、底部面板下拉关闭 | 完全跟手；松手时按速度和位置决定结果，并带着这个速度进入动画（快速回复面板下拉关闭时静默保存草稿，上拉越阈值进入完整编辑器） | 吸附、弹回 `spatialSnap`；关闭 `exit`；展开全屏 `spatialDefault` |

### 6.4 性能
- 帖子列表和长帖滚动时保持满帧（按设备的刷新率：60Hz 每帧 16.7ms，120Hz 每帧 8.3ms）。日常 CI 用重组次数断言守住不退化；阶段验收在真机上测（第 10.1 节与第 10.3 节）。
- 列表项里不使用模糊；全屏同时最多 **3 块**活跃实时液态玻璃区域（独立 `layerBackdrop` 采样源最多 2 个，详见第 5 节）；真机 120Hz 实测不达标时按第 5 节预定 4 级回退顺序逐级降级。
- 图片按显示尺寸解码，不解码原图；看图时才按需加载原图。

## 7. 交互规范
### 7.1 对旧版问题的改法（审计发现）
| 原则 | 旧版的问题 | 新版的做法 |
|---|---|---|
| 系统能判断的 | 设置里有“使用 UTF8 编码”；图片按 Wi-Fi 和流量有多个设置项；主题要手动切换；重新打开帖子总是从第 1 页开始 | 编码自动识别；图片加载按第 7.9 节自动处理；主题默认跟随系统；帖子记住页码、楼层和偏移量，再打开时回到原处 |
| 此刻没用的 | 刷新按钮一直浮在屏幕上；抽屉里有显示“0”的角标；“检查更新”已失效；页码标签一直显示 | 去掉刷新按钮，改成下拉刷新，内容过期后回到页面时自动刷新；数值为 0 的角标不显示；删除“检查更新”；页码只在帖子详情的底部三段工具条中段显示一处，点它原地展开内联跳页条，不再另有浮动的页码标签 |
| 能替人做的 | 退出编辑时弹“放弃发表？”；发送失败后内容只能去草稿里找；上传前图片不压缩 | 草稿按第 7.2 节自动保存和恢复；发送失败时内容留在原处，原地重试；图片上传前自动压缩 |
| 同一件事处处一样 | “回复/回帖”“发表/发布”“只看楼主/只看该作者”等说法混用 | 统一术语（第 8 节），用测试检查（第 10.1 节） |
| 按下去有回应 | 列表项按下后 200ms 才高亮；600ms 内的第二次点击被直接丢掉，没有任何提示 | 按下立即有反馈；用状态防止重复提交（提交中按钮不可再点），不靠时间丢弃点击 |
| 再按能收回 | 收藏、关注不能撤销；删除搜索历史、日志等没有撤销 | 收藏、关注、删除立即生效，Snackbar 里给“撤销”；投票先选中选项，再点“投票”提交，这一步不变 |
| 不打断人手上的事 | 退出登录 1 秒后自动弹出登录框；错误用 Toast；切换主题时重启整个应用 | 退出登录后停在当前页，需要登录的地方原地显示“登录”按钮；错误在出错的位置原地提示；切换主题时颜色平滑过渡，不重启 |
| 难误碰 | 双击列表直接弹出跳页框；“退出并清除登录信息”和普通退出并排放着 | 去掉双击跳页；清除登录信息放在“账号”页的最下面，并且需要确认 |
| 不打断人手上的事 | 点其他账号的头像切换账号 | 在“账号”页点已保存的账号，直接切换，不确认（不会丢东西） |
| 系统能判断的 | 置顶帖或黑名单过滤后一页不足 10 条时，连续拉 5 页就停，然后让用户去网页版改设置（ThreadListFragment.java:614-616） | 后台自动继续加载，直到能填满一屏；不再让用户去改网页设置 |
| 系统能判断的 | “只看该作者”模式下点回复，提示“请先退出只查看该作者模式”（ThreadDetailFragment.java:1071） | 过滤模式下也能直接回复和引用 |
| 系统能判断的 | 登录过期后整屏显示“未登录”，即使保存了账号密码 | 用保存的凭据在后台静默重新登录一次；失败了，再在原地显示“登录已失效”和“登录”。**用户手动退出登录后，不再静默重新登录** |
| 不打断人手上的事 | 发帖时点发送，页面立即关闭在后台发送，失败后内容不在页面上了（PostFragment.java:517-518）。传图、发帖、清缓存都用不可取消的进度框 | 留在编辑页，直到服务器确认成功再关闭；失败时留在原页，可以直接修改后重发。进度一律原地显示，不用阻塞式的进度框，不人为拖延 |
| 难误碰 | 顶栏的返回箭头直接关闭编辑页并丢掉输入，系统返回键却会弹确认（PostFragment.java:387-389、736-748） | 所有返回途径（顶栏箭头、系统返回键、预测性返回）走同一条路径：按第 7.2 节保存草稿后返回 |
| 难误碰 | “右划返回”整屏宽度都响应；首页任意位置右滑 32dp 就打开抽屉（SwipeBaseActivity.java:24-29、MainFrameActivity.java:482-501） | 取消自定义的全屏滑动手势，用系统的预测性返回（只从屏幕边缘触发）；窄屏取消侧滑抽屉改底部胶囊，宽屏（`≥ 600dp`）以常驻左侧栏承载（仅通过 `展开侧栏` 按钮或 `我的` 图标打开 `240dp` 浮层，不设左缘右滑手势） |
| 难误碰 | 看图时单击直接关闭，长按才显示工具栏；下拉关闭要先横向滑过阈值（ImageViewerLayout.java:56-74、231-289） | 单击显示或隐藏工具栏，双击放大或还原，下拉关闭（第 6.3 节），长按弹出“保存图片 / 分享” |
| 难误碰 | 点通知按钮一次就把全部提醒清零 | 每条提醒在打开它时才算已读；“全部已读”是单独的按钮 |
| 按下去有回应 | 黑名单的“移除”点了直接消失，没有进度；用户资料页切换内容时先变白屏 | 按钮原地变成进度圈，完成后该行收起并给“撤销”；用户资料改为两个标签（第 7.8 节） |
| 界面自己说明自己 | 退出登录藏在“长按头像”里 | “我的 → 账号”里明确提供“退出登录”和账号列表 |
| 同一件事处处一样 | 跳页面板里，上一页、下一页不收起面板，首页、末页会收起（ThreadDetailFragment.java:885-918） | 内联跳页条的任何跳转（滑块/输入确认、首页、末页）都会自动收起（第 7.3 节） |
| 界面自己说明自己 | 错误提示直接显示异常类名或“错误代码 (403)”；空列表一片空白；搜索页一进来就显示“没有数据” | 错误提示按第 8 节的格式；技术细节放在可展开的“查看详情”里，只给排错用；空状态显示一个图标、一句话和下一步的操作；搜索页的初始状态见第 7.7 节 |

### 7.2 草稿
- 草稿按业务键自动保存：发新帖 `new:<fid>`（分类、标题、正文、已上传的图片）、回复 `reply:<tid>`（含引用的楼层）、编辑已发表的楼层 `edit:<pid>`。
- 任何返回途径都静默保存，不询问；返回后 Snackbar `已保存草稿`（按钮：`放弃`，点了删除这份草稿）。内容为空或和上次发出的一样时不保存、不提示。
- 再次打开同一个业务键的编辑器时自动恢复，输入框上方显示一条横条 `已恢复上次草稿`（按钮：`清空`）。
- **编辑已发表的楼层**：编辑器顶栏有“还原原文”，只在内容和线上原文不同时出现；点了把内容换回线上原文（可以用 Snackbar 撤销）。退出时照常保存 `edit:<pid>` 草稿；保存成功提交后删除草稿。
- 发送成功后删除对应的草稿。

### 7.3 读帖
- 打开帖子时回到上次读到的位置（页码、楼层、偏移量）。
- **连续加载**：长帖上下滚动时自动接续加载上一页和下一页（第 6.3 节“连续加载”）。底部三段工具条中段显示第一个可见楼层所在的页 `第 N / M 页`（窄右栏紧凑态 `{N}/{M}`），并用主题色半透明填充条直观表示阅读进度 `N / M`。
- **底部三段式工具条**：居中悬浮于详情栏底部（三栏与铰链双栏位于右栏底部，不跨分隔线），依次为左段 **`回复`** 胶囊、中段 **阅读进度胶囊**、右段 **`收藏` + `更多`** 独立双按钮胶囊（`收藏` 点按立即切换状态并出可撤销 Snackbar，`更多` 展开帖子次级操作菜单；详情透明顶栏左右采用独立圆形动作按钮承载 `返回`、大屏 `全屏阅读 / 显示列表` 与 `只看楼主`）。
- **内联跳页条（替代独立跳页面板）**：点中段进度胶囊不另弹遮挡正文的 BottomSheet，而是在原位将左右两段滑离淡出、中段原地扩至工具条全宽（三栏/铰链为右栏宽；聚焦输入框时通过 `imePadding()` 贴于数字键盘上方）。
  - 内容：**滑块**（拖动时仅在本地实时预览 `第 {目标} / {总页} 页` 并同步输入框数字，不实时触发列表滚动或网络请求）、**页码输入框**（可直接输入数字并回车确认，附 `/ {M}` 总页后缀）、**`首页` / `末页` 快捷按钮**（已在第 1 页时 `首页` 禁用，已在末页时 `末页` 禁用）、**动态动作按钮**（未修改或非法输入时为 `关闭` `×`，变更有效时切换为 `跳转` `✓`）。窄右栏（`360–384dp`）下自动采用紧凑双行排布，保证所有控件触控区 ≥ `48dp`。
  - 跳转与收起：任何一次跳转（点 `首页`、`末页`、`跳转` 或回车）均先压入位置栈，自动收起内联条恢复三段态，并跳到目标页开头；跳至不相邻页时按“内容替换”处理并重建连续加载范围。按系统返回、点 `关闭` 或点正文空白区则收起不跳。
  - 无障碍与减少动态效果：展开后 TalkBack 自动聚焦内联条并播报 `已展开跳页，当前第 {N} 页，共 {M} 页`，滑块支持无障碍步进并播报 `第 {目标} / {总页} 页`；减少动态效果下展开/收起与进度条变化均 0ms 一帧到位。
- **位置栈**：跳页、点引用跳楼层、点“回复已发送 · 查看”之前，都把当前位置压栈；按返回先回到跳转前的位置，再按才离开帖子。
- **引用**：点引用跳到被引用的那一楼，并高亮（第 6.3 节“引用高亮”）；长引用默认折叠，点开展开。
- **只看过滤**：开启“只看楼主”或“只看此人”后，顶栏下方常驻一个过滤胶囊 `只看楼主 ×` 或 `只看 {用户名} ×`。点 `×` 退出过滤，回到全帖，并定位到刚才正在看的那一楼。过滤模式下可以直接回复和引用。
- **楼层长按菜单**：`引用回复`、`回复`、`只看此人`、`复制`，自己的楼层另有 `编辑`、`删除`。没有“举报”。
- **回复（毛玻璃快速回复面板 + 展开全屏）**：点底部工具条左段 `回复` 或楼层菜单 `回复` / `引用回复`，升起贴底**毛玻璃跟手编辑面板**（`20dp` 顶部圆角，单栏全宽，三栏与铰链双栏仅在**右栏底部**宽度内升起且暗罩仅盖右栏，不遮挡左栏与中栏；展开覆盖底部工具条时暂停工具条实时玻璃绘制以守住 ≤ 3 块上限）。
  - 交互与布局：通过 `WindowInsetsAnimation` / `imePadding()` 逐帧随键盘升起并自动聚焦输入框；顶部为 `32dp` 拖动把手（支持向下跟手拖关并按第 7.2 节静默保存 `reply:<tid>` 草稿，点暗罩或按系统返回等效，保证非手势关闭路径）、回复/引用上下文提示（`回复 {用户名}` 或 `引用第 {N} 楼 · {用户名}`）与右上角 `48×48dp` **`展开全屏`** 图标按钮；中部为自适应限高输入框（草稿恢复条按第 7.2 节显示）；底部为单行横向滚动快捷工具行（`插入图片`、`表情`、`引用`、`粗体`）+ 右侧固定 **`发送`** 按钮。
  - 一键展开全屏：点右上角 `展开全屏`（或把手上拉越过阈值）无缝带着当前已输入文本、光标位置、引用楼层与已添加图片进入完整编辑器（不重复触发草稿保存提示），按第 4.2 节在单栏全屏或多栏居中模态/右栏内展开。
  - 发送成功后：如果用户本来就在最后一页的末尾附近，新楼层插入末尾并滚过去，面板收起；否则面板原地收起，不移动阅读位置，Snackbar `回复已发送`（按钮：`查看`，点了跳到新楼层，跳前压入位置栈）。
  - 无障碍与减少动态效果：面板打开即播报回复对象，全部按钮与把手具完整内容描述；减少动态效果下升降、关闭与展开全屏均 0ms 一帧到位。
- **冷却**：服务器对回复有 30 秒冷却、对短消息有 15 秒冷却。发送成功后，发送按钮原地变成剩余秒数的倒计时（向上取整），倒计时期间可以继续输入，结束后恢复发送按钮。无障碍描述：`{N} 秒后可发送`。

### 7.4 编辑器、上传与表情
- **与快速回复面板的衔接**：从毛玻璃快速回复面板点 `展开全屏` 进入完整编辑器时，文本、光标位置、引用楼层与已添加/上传中的图片全部无损承接；反之仍按业务键 `reply:<tid>` 统一维护同一份草稿。
- **多图上传条**：输入框上方一条横向滚动的缩略图条。选图后立即出现缩略图占位，叠着环形进度（先压缩，后上传）；条上显示汇总 `正在上传 {current}/{total}`。单张失败时缩略图上显示重试图标，点一下重传。点已上传的缩略图，在光标处插入这张图；还没插入正文的图片带一个小角标，点发送时按顺序自动附在正文末尾，不询问；缩略图右上角的 `×` 移除这张图。编辑器里不显示 `[attachimg]` 这类标签，正文里插入的图片显示为缩略图块。
- **表情面板**（同时适用于毛玻璃快速回复面板与完整编辑器）：
  - 键盘已经展开时点“表情”：面板沿用最近一次键盘的高度，原地替换键盘，面板底缘零位移；按钮图标在“表情”和“键盘”之间切换。
  - 没有可用的键盘高度时（分屏、浮窗、外接键盘、刚打开还没弹过键盘）：面板高 280dp，且不超过窗口高度的 45%；窗口高度小于 480dp 时不超过 35%。
  - 列数按面板宽度自适应（每格最小 48dp）。分类标签用每组表情的第一个图作为图标，选中指示器用 `spatialFast` 滑动。
- **提交**：按钮 0ms 变成进度圈，留在编辑页；成功后关闭编辑器并删除草稿；失败时原地显示原因，内容不动，可以修改后重发。

### 7.5 短消息
- 点发送后，消息立即作为气泡插入对话末尾，气泡旁显示小进度圈；服务器确认后进度圈消失。
- 失败时气泡旁常驻一个红色感叹号，点它弹出 `重发` / `删除`；删除走“删除与撤销”。
- 15 秒冷却按第 7.3 节倒计时。

### 7.6 消息与提醒
- 见第 3 节。提醒按单条已读；“全部已读”在“提醒”标签的顶栏。

### 7.7 搜索
- 初始状态（还没提交搜索）：显示“最近搜索”（每条右侧 `×` 删除，可撤销）和筛选胶囊（版块、标题/全文、作者）。不显示任何空状态。
- 筛选胶囊点开是一个可打断展开和收起的面板（`spatialDefault`）。
- 只有提交搜索后返回 0 条，才显示 `没有找到相关内容`（按钮：`清除筛选`，没有筛选时不显示按钮）。
- 搜索框识别站内地址（第 3 节）。

### 7.8 用户资料
- 上方固定资料头（头像、用户名、主要统计），下方两个标签 `资料 | TA 的帖子`，各自有自己的骨架、空、错状态；切换按“同级换内容”。TA 没有发过帖子时显示空状态 `TA 还没有发过帖子`，不报错。
- 操作：`发短消息`、`加入黑名单` / `移出黑名单`。

### 7.9 图片加载
- 帖子里的图片默认自动加载（缩略图或常规尺寸），点开看图时再加载原图；头像总是自动加载。
- 只有系统的“流量节省程序”开启、并且当前是计费网络时，帖子里的图片才改为点击加载：占位上显示 `点击加载图片（{size}）`（不知道大小时不带括号），点击后显示确定进度圈，再点可以取消。应用里不设单独的开关。

### 7.10 设置
分 5 组，每项说明在 `copy.md`：

| 分组 | 设置项 |
|---|---|
| 外观与阅读 | 主题（跟随系统 / 浅色 / 深色）；纯黑深色背景；主题色（跟随壁纸，Android 12 及以上 / 预设色）；字号（5 档）；行距（3 档） |
| 论坛与发帖 | 管理版块；显示置顶帖；小尾巴（开关、文字、链接）；黑名单 |

### 7.11 登录与账号
- **登录页**：一个页面完成。字段：用户名、密码、安全提问（下拉，默认“无安全提问”）；选了提问后，才在下面展开“提问回答”。点“登录”后按钮内 0ms 变成进度圈，留在本页；失败时保留所有已填内容，在出错的字段下面原地显示原因（例如 `用户名或密码错误`），并聚焦那个字段。成功后回到触发登录之前的页面，并继续那个操作。登录过程中遇到 Cloudflare 验证时走第 7.12 节的统一流程。
- **账号页**（我的 → 账号）：已保存的账号列表，点一下直接切换，不确认；`添加账号`；`退出登录`（不确认：账号仍在列表里，点一下就能登回来；退出后停在当前页，并记下“手动退出”，之后不再静默重新登录，直到用户再次登录）；最下面是 `清除登录信息`（确认：`清除 {用户名} 的保存密码并退出？`）。

### 7.12 Cloudflare 验证
- 系统先在后台用不可见的 WebView 自动完成验证，用户看不到，原来的加载指示照常显示。
- 后台等待超过 2 秒时，原地的加载提示换成 `正在检查安全环境…`。
- 需要人工操作时才弹出验证面板：窗口宽度小于 600dp 用底部面板，600dp 及以上用居中对话框（最大宽 480dp）。标题 `安全验证`，按钮 `刷新`、`取消`。验证通过后自动收起，原来的请求自动继续。
- 用户取消、或连续失败进入冷却时，原地显示 `安全验证未完成`（按钮：`重新验证`）；过了验证仍被拒绝（60 秒冷却）时显示 `验证未通过`（按钮：`重新验证`）。用户点“重新验证”是主动操作，不受冷却限制。

## 8. 文案
- 语气：简短、直接、口语化；不用感叹号；用全角中文标点。
- 按钮写成动词：回复、发送、重试、登录、撤销。
- 进行中的提示写清楚是什么动作：`正在发送…`、`正在登录…`，不写“请稍候…”“正在处理…”。
- **错误提示的格式**：
  - 旁边有动作按钮时，只写原因，一个短语，不加句号：`网络连接失败`（按钮：`重试`）、`登录已失效`（按钮：`登录`）。
  - 没有按钮，或者需要用户改输入、等待时，写“原因，怎么办”，用全角逗号连接：`密码错误，请核对后重试`、`发送太快，请等 18 秒后再试`。
  - 主提示里不出现异常类名、HTTP 状态码、原始的异常信息、BBCode 标签名（如 `[attachimg]`）。技术细节只放在可展开的 `查看详情` 里，供排错和复制。
- **术语表**（左边是唯一的标准说法；右边是禁止出现的精确词组，扫描测试按词组匹配，不按单字匹配，所以“账号信息”“按发帖排序”这类正常用法不受影响）：

| 标准说法 | 禁止的精确词组 |
|---|---|
| 回复 | 回帖、回复帖子 |
| 发新帖 | 发表新帖、发表主题、发布新帖、发布帖子 |
| 按发帖排序 | 按发表排序、按发表时间排序 |
| 引用回复 | 引用回帖 |
| 短消息 | 私信、站内信 |
| 提醒 | 信息提醒、消息提醒、帖子提醒 |
| 通知（指系统通知栏的通知） | 消息通知 |
| 只看楼主 | 只看主帖作者 |
| 只看此人 | 只看该作者、只查看该作者 |
| TA 的帖子 | 搜索帖子（指用户资料里的帖子列表时）、他的帖子 |
| 版块 | 版面 |
| 浏览历史 | 浏览记录 |
| 黑名单 | 屏蔽列表 |
| 退出登录 | 注销 |
| 清除登录信息 | 清除账号、退出并清除 |
| 第 N 楼（正文、标题里）／ N楼（楼层角标） | 第N层、N层 |
| 具体的空状态（见 copy.md） | 没有数据、暂无数据 |
| 具体的进行中提示 | 请稍候、正在处理 |

- 全部界面文本（导航、空状态、加载、错误、验证、登录与账号、跳页、Snackbar、确认框、设置项）见 `docs/design/copy.md`。页面卡直接从那里取文本，不另写。

## 9. 关键流程
- **首次启动**：直接显示论坛的帖子列表（默认“今日新帖”或第一个关注的版块），未登录也可以浏览论坛允许游客看的内容。需要登录的操作，在原地显示 `登录后即可操作`（按钮：`登录`）。
- **Cloudflare 验证**：第 7.12 节。
- **登录**：第 7.11 节。
- **读帖**：第 7.3 节。
- **回复**：第 7.3 节“回复”和“冷却”。
- **发新帖**：论坛顶栏点“发新帖”打开完整编辑器，版块默认是当前版块（在“今日新帖”里打开时需要先选版块）；提交成功后关闭编辑器，回到列表并刷新，Snackbar `帖子已发出`（按钮：`查看`）。
- **从提醒进入帖子**：第 3 节“消息”。

## 11. 不做的事
- 不学 fluxdo 的这些部分：AI 功能、小应用、实时聊天、徽章和积分、可自定义的底栏、桌面多窗口、无限层叠的“胶片带”页面栈、按宿主分散多套双栏门槛。
- **不搬用 kudo 的视觉资产与非 HiPDA 功能**：只借鉴形态与交互，严禁使用 kudo 的品牌色 `#FFB003`、Font Awesome 分类图标、应用图标与其他视觉资产；不增加 HiPDA 没有的功能（热门、排行榜、助推/Boost、点赞、关注作者）；不在窄屏底部胶囊中间添加 `+` 发帖按钮（发新帖保留在论坛顶栏）。
- 暂不做（以后再评估）：桌面姿态（tabletop）下看图和回复的上下分区布局；应用内单独的“减少动态效果”开关（以系统设置为准）；出错时左右晃动的动画；自定义字体导入。
- 不做“举报”：旧版的举报只是随机等待后提示成功，并没有提交（用户决定删除）。
- 不加装饰性的动效：不加视差（层级后退时旧页的 1/4 退让除外）、不加入场时的逐项级联动画、不在列表上做弹性滚动。
