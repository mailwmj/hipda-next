# hipda-next 界面文案表（v0.4）

> 来源：Hydrogen 第一轮评审给出的文案表，负责人按产品设计 v0.2 修订（去掉“举报”；用户资料标签用“资料”；退出登录不再确认；补齐冷却、过滤、设置项等），v0.3 补齐左侧栏与多栏文案，v0.4 按 2026-11-25 液态玻璃与 kudo 交互拍板补齐帖子详情顶栏圆形动作、底部三段工具条、内联跳页条与毛玻璃快速回复面板文案。规则见 `product-design.md` 第 8 节：短、直接、全角标点、不用感叹号、按钮用动词；有按钮的错误只写原因。
>
> 页面卡直接取这里的文本，放进对应的 `res/values/strings_<功能>.xml`。`{…}` 是占位参数。需要新文本时先改本表。

## 加载与进行中
| 场景 | 文本 |
|---|---|
| 首次加载、刷新 | 骨架屏，不带文字；必须有文字时：`正在加载…` |
| 列表底部加载下一页 / 帖子顶部加载上一页 | `正在加载…` |
| 列表底部没有更多 | `没有更多了` |
| 后台验证超过 2 秒 | `正在检查安全环境…` |
| 回复、发新帖、编辑提交中 | 按钮内进度圈；内容描述 `正在发送…` |
| 图片上传汇总 | `正在上传 {current}/{total}` |
| 发送短消息中 | 气泡旁小进度圈，不带文字；内容描述 `正在发送…` |
| 登录提交中 | 按钮内进度圈；内容描述 `正在登录…` |
| 清除缓存中 / 删除中 | `正在清除…` / `正在删除…` |
| 附件下载中 | `正在下载…` |
| 流量节省模式下的图片占位 | `点击加载图片（{size}）`；不知道大小时 `点击加载图片` |
| 点击后加载图片中 | 确定进度圈；内容描述 `正在加载图片，点击取消` |

## 错误与校验
| 场景 | 文本 |
|---|---|
| 通用加载失败（有按钮） | `网络连接失败`（按钮：`重试`）/ `加载失败`（按钮：`重试`） |
| 列表头尾加载失败（整行可点） | `加载失败，点击重试` |
| 需要登录才能看 | `需要登录才能查看`（按钮：`登录`） |
| 登录失效 | `登录已失效`（按钮：`登录`） |
| 未登录时点了需要登录的操作 | `登录后即可操作`（按钮：`登录`） |
| 没有版块权限 | `当前账号无权查看这个版块` |
| 帖子不存在或已删除 | `帖子不存在或已被删除` |
| 编辑器内联校验 | `请输入标题` / `标题至少 6 个字` / `内容至少 6 个字` / `请选择分类` / `请选择版块` |
| 发送失败（编辑器、快速回复） | `发送失败`（按钮：`重试`） |
| 服务器冷却（没有倒计时按钮的场合） | `发送太快，请等 {N} 秒后再试` |
| 短消息发送失败 | 气泡旁红色感叹号，内容描述 `发送失败`；点开：`重发` / `删除` |
| 图片加载失败 / 保存失败 | `图片加载失败`（按钮：`重试`）/ `保存失败` |
| 附件下载失败 | `下载失败` |
| 外部链接无法识别 / 无可用浏览器 | `无法识别该链接`（按钮：`在浏览器中打开`）/ `未找到可用的浏览器` |
| 单张图片上传失败 | 缩略图上的重试图标，内容描述 `上传失败，点击重试` |
| 编辑器图片上传拦截与实名提示 | 上传中点发送：`图片正在上传，请等待完成后再发送`；有失败图点发送：`有图片上传失败，请重试或移除后再发送`；不可读 URI：`无法读取所选图片`；实名认证：`需要完成实名认证后才能继续操作` |
| 错误详情 | `查看详情` / `收起详情` / `复制详情` |
