  2. **透明吸顶顶栏与严格兄弟玻璃拓扑（`ForumTopBar.kt`）**：
     - 按 `ForumChromeSpec` 分支驱动：`useGlassTopBar == true` 时顶栏为 **1 个 `HiGlassStyle.TopBar` 玻璃区域**（未滚动纯净 `surface`，向下滚动以 `HiMotion.effectsDefault()` 渐进呈现护读液态玻璃），且与 `LazyColumn`（挂 `shellGlassSource()` 或 `externalGlassState`）为**严格兄弟节点**；`useGlassTopBar == false`（如铰链双栏）保持纯色 `surface → surfaceContainer` 守住全屏 ≤ 3 区域配额；

     - `≥ 600dp`（`chromeSpec.showForumTabs == false`）：隐藏横向版块标签行，中栏顶栏为单行透明液态玻璃。
  3. **自适应版块标签行与荧光笔选中高光（`BalancedForumTabRow.kt`）**：
     - 第一项固定为 `今日新帖`，其后为 `settings.followedForums`（按 `ForumMetadataRegistry` 解析全名），最右侧固定不随标签滚动的 `管理版块` 图标按钮（`48×48dp`，触发 `onManageForumsClick`）；
     - 全部标签放得下时等分居中，放不下时横向滑动并自动滚入选中项；每项触控区高 ≥ `48dp`；
     - 选中项加粗略放大（遵循 `1.25×` 缩放钳制），文字下半部绘圆角横向渐变**荧光笔底条**（优先取 `primaryContainer` 且峰值 alpha 严守 `HiGlassTokens.TabHighlighterContainerLightMaxAlpha` ≤ `0.55` / `DarkMaxAlpha` ≤ `0.45`，**严禁使用 `#FFB003`**），切换使用 `HiMotion.spatialFast()`，减动效 0ms 到位。
  4. **列表项、窄中栏适配、刷新 diff 与 `V-C1` 对比度校准（`ThreadListRow.kt`、`NewThreadsPill.kt`）**：
     - 展示标题（最多 2 行省略）、作者、回复/浏览、时间、置顶/精华/图片/附件轻量标记、圆形头像（经 `LocalHiImageLoader` 自动加载）；三栏选中态高亮（`selectedTid`）；按压反馈使用 `hiPressScale`；
     - 中栏可用宽 **`< 300dp`** 时自动取消独立大头像列，改为紧凑副行排版，保证标题有效行宽且无拥挤截断；
     - **校准 `V-C1`**：在深色与 OLED 纯黑模式下，拉大已读标题相对未读标题的视觉弱化区分度（字重降级 + 更清晰的亮度分级），同时通过确定性 WCAG 2.1 单测锁死全 20 套主题预设 × 浅/深/OLED 纯黑下已读与未读标题对比度均 **`≥ 4.5:1`**；
     - 下拉刷新（Material 3 `PullToRefreshBox` + 令牌动效）按 `tid` 原地 diff；仅当顶部出现新帖时展示 `有 {N} 条新帖` 悬浮胶囊（点击滚顶并清胶囊）；自动续载下一页（距尾触底自动触发），加载中/失败（整行可点重试）/到底复用 `HiListFooter`。
  5. **数据流、排序持久化与 `今日新帖` 闭环（`ForumViewModel.kt`）**：

【验收】
1. **账号异步水合与登录自动恢复（B4-E1 ①）**：`ForumViewModelTest` 模拟 `currentAccount` 初始为 `null` 时加载返回 `AuthRequired`，随后发射 `SavedAccount`（以及已登录态切号/重新登录触发会话更新），断言自动重拉并成功展示帖子，不滞留错误页。
2. **顶栏上行折叠零跳动与吸顶标签行（B4-E1 ②）**：`ForumTopBarScrollTest` 驱动列表向下滚动折叠上行再略微上划展开，断言：(a) 上行收起后版块标签行仍保持可见吸顶；(b) 展开态与完全折叠态下 `LazyColumn` 的 `contentPadding(top)` 差值严格 `== 0dp`；(c) 减动效下 0ms 一帧到位无残留中间态。
3. **`今日新帖` `searchId` 翻页与黑名单/已读联动（B4-E1 ③）**：`ForumViewModelTest` 断言 `今日新帖` 载入第 2 页时原样传回第 1 页的 `searchId`，且更新 `BlacklistRepository` 立刻隐藏对应作者帖子、更新 `BrowseHistoryDao` 立刻令对应帖子切换已读态。
4. **`R-D4 S1`、`V-C1`、刷新 diff 与窄中栏**：
   - 排序切换写入 `SettingsRepository` 并始终以显式 `sortByPostTime` 调用 `ThreadListRepository`；
   - 下拉刷新顶部新增帖子后按 `tid` diff 并显示 `有 {N} 条新帖`，点胶囊滚顶；
   - `< 300dp` 窄中栏不渲染独立大头像列，标题/副行无溢出截断；
