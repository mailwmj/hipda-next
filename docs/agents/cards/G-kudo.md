【角色】调研与方案起草者。只读代码，不改仓库。

【用户诉求】（2026-11-25）用户认为 https://github.com/woliubang256/kudo-android 的顶部标题、顶部导航、发帖等处的毛玻璃效果、UI 和交互都比我们好，希望用到本项目。用户给的三张截图（kudo 实机）要点：
1. 列表页：顶部是**透明毛玻璃**的横向分段标签（未读 / 最新 / 新(389) / 热门 / 排行榜 / 我的帖子），选中项大号粗体并带一道荧光笔式下划高光，内容从标签下面滚过并被模糊；右侧一个图标按钮。底部是**悬浮毛玻璃胶囊导航**（首页 / 分类 / 中间突出的圆形"+"发帖按钮 / 消息 / 我的），选中项有淡色胶囊底。
2. 帖子详情：顶栏左侧圆形描边返回按钮 + 作者头像/名/时间，右侧"关注"实心按钮与圆形"更多"按钮；底部**悬浮毛玻璃工具条**分三段：左"写回复"胶囊、中间阅读进度胶囊（"1 / 13"，进度用填充色表示）、右侧点赞/助推胶囊。
3. 回复：点"写回复"后从底部升起**毛玻璃编辑面板**（顶部拖动把手、占位"回复 某某"、字数"0 / 16 字"、格式工具行与"发布"按钮），面板随键盘上推，背后内容被模糊。

【第一步：读 kudo 源码】`git clone --depth 1 https://github.com/woliubang256/kudo-android /tmp/kudo`。逐项回答并附 文件:行号：
- 许可证是什么，能否借鉴代码、只能借鉴思路，还是两者都不行。
- 毛玻璃用什么实现（Haze / RenderEffect / `Modifier.blur` / 液态玻璃类库如 Kyant backdrop，或自写 shader），具体参数：模糊半径、着色、饱和度、噪点、折射/透镜、描边高光、阴影，亮色/暗色分别多少；API 31 以下怎么降级。
- 顶部透明标签栏：结构、滚动时的行为（隐藏/吸附/模糊强度变化）、选中指示器（荧光笔高光）的绘制与动画。
- 底部悬浮导航与中间"+"按钮：尺寸、间距、选中态、随滚动的显隐。
- 帖子详情顶栏与底部三段式工具条：阅读进度胶囊如何计算与绘制、点按/拖动行为、与列表滚动的联动。
- 回复编辑面板：用的什么组件（ModalBottomSheet / 自写），如何随 IME 上推，毛玻璃背景，展开到全屏编辑的方式。
- 动效：各处用的时长/弹簧参数。
- 性能：模糊层数量、是否在滚动列表上实时模糊，有无已知卡顿处理。
