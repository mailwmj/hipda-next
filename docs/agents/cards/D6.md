   - **`fetchPrePost` + R-B9b S3 Emoji 往返闭合**：
     - 经 `ForumHttpClient.getHtml(..., requireAuth = true)` 拉取对应 `PrePostMode` 表单页；检测 `memcp.php?action=bind` 返回 `RealNameBindRequired`；复用 `B9b` `PrePostParser.parse`；

   - **6 种模式提交、小尾巴、未插图自动附尾与 30 秒冷却**：

     - 非编辑提交（含 `DeletePost`）先检冷却，活跃时立即返回 `CooldownActive(remainingSeconds)` 且**发起 0 次网络请求**；`EditPost`（非删除）不受冷却阻塞也不启动冷却；**仅服务器确认成功才记录冷却时间，失败绝不锁冷却**；
     - 若未传预取的 `PrePostInfo`（或缺 `formhash`），自动先拉取 `PrePost`（最多按约定获取 1 次，缺失则返回明确失败不发盲 POST）；
     - 正文处理：将未插入正文 `[attachimg]<id>[/attachimg]` 的已上传新图 ID 按顺序附在正文末尾（`product-design.md §7.4`）；对非 BBCode 标签区间的裸 URL 包装 `[url]...[/url]`；**仅在非 `EditPost`、非 `DeletePost` 且 `AppSettings.tailEnabled == true` 时拼接小尾巴**（编辑/删除绝不拼小尾巴）；回复/引用楼层拼接解码并重编码的 `quoteText` 与 `noticeauthor`/`noticeauthormsg`/`noticetrimstr`；
     - 成功/失败与草稿一致性：提交**成功**后自动调用 `draftDao.delete(draftKey)` 清除对应草稿；提交**失败**（冷却/网络/站点报错/鉴权/验证）**绝不删除草稿**；
   - **草稿读写 API（委托既有 `DraftDao`，不改 `Draft.kt`）**：
