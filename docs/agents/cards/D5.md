2. **帖子详情仓储（`data/threaddetail/{ThreadDetailRepository,DefaultThreadDetailRepository}.kt`）**：
   - **分页与定位加载**：
     - `loadPage(tid: String, page: Int = 1, filter: ThreadDetailFilter = ThreadDetailFilter.All, recordHistory: Boolean = true, forumName: String? = null, priority: AccessPriority = AccessPriority.UserBlocking)`：
       - 校验正整数 `tid` 与 `page >= 1`；若 `filter` 为 `AuthorOnly(authorId = null)` 且 `page > 1` 或尚未获知楼主 UID，先请求第 1 页经 `B8` `ThreadDetailParser.parseThreadAuthorId` 提取楼主 UID 后再按 `&authorid=` 拉取；
       - 按 `SettingsRepository` 当前 `forumServer` 推导 `forumBaseUrl` 与 `avatarBaseUrl` 传给 `ThreadDetailParser.parse`；
       - 鉴权策略：已登录态（`authRepository.currentAccount.value != null`）走 `ForumHttpClient.getHtml(..., requireAuth = true)` 自动享单飞静默重登一次；游客/手动退出态走 `requireAuth = false` 允许浏览公开帖，遇需登录站点提示返回 `AuthRequired`/`SiteError`；
     - `loadLastPage(tid: String, ...)`：请求 `redirect.php?goto=lastpost&from=fastpost&tid={tid}` 并解析落地页；
     - `loadByPostId(pid: String, tid: String? = null, ...)`：有 `tid` 走 `redirect.php?goto=findpost&pid={pid}&ptid={tid}`，无 `tid` 走 `gotopost.php?pid={pid}`，解析落地页与实际 `tid`/`page`。
   - **浏览历史自动写入与裁剪（`BrowseHistoryDao`，不改 DAO 定义）**：
     - 每次成功打开帖子且 `recordHistory == true`、拿到有效 `tid` 与非空 `title` 时，调用 `browseHistoryDao.upsert(BrowseHistoryEntity(...))`（记录 `tid`、`title`、`fid`、`forumName`、楼主/首楼作者、`lastVisitedAt = nowMs()`），随即调用 `browseHistoryDao.trimTo(maxBrowseHistory)`（默认上限如 `500`，可构造注入方便单测验证裁剪）。
   - **阅读位置记忆（`ReadingPositionDao`，不改 DAO 定义）**：
     - `getReadingPosition(tid: String): ReadingPositionEntity?`
     - `saveReadingPosition(tid: String, page: Int, pid: String, offsetPx: Int, filterMode: ReadingFilterMode = ReadingFilterMode.NONE, filterUid: String? = null, filterUserName: String? = null)`（写入 `ReadingPositionDao.upsert`）。
   - **黑名单响应式楼层遮蔽/过滤（`BlacklistRepository.blockedUsernames`）**：
     - 提供响应式过滤/标记转换流 `observeFloors(floorsFlow: Flow<List<PostFloor>>): Flow<List<ThreadDetailFloorItem>>`（及便捷过滤函数），实时订阅 `BlacklistRepository.blockedUsernames`，当黑名单增删/撤销/切号时立即重算 `isAuthorBlocked`（及隐藏黑名单楼层视图），**零额外网络请求**。
   - **1 楼投票提交与结果刷新（`submitPollVote`）**：
     - `submitPollVote(fid: Int, tid: String, formhash: String, optionIds: List<String>, maxChoices: Int? = null)`:
       - 校验 `fid > 0`、合法 `tid`、非空 `formhash`、去重后 `optionIds` 非空且不超 `maxChoices`（若有），按字典序排序拼装 `formhash` + 重复键 `pollanswers[]`；
       - 强制要求登录态（未登录/手动退出直接返回 `AuthRequired`、0 网络请求）；
       - 经 `ForumHttpClient.postGbkForm("misc.php?action=votepoll&fid=$fid&tid=$tid&pollsubmit=yes&quickforward=yes&inajax=1", fields, requireAuth = false)` 提交，检查响应 XML/HTML 是否含错误提示（`div.alert_error` / `div.alert_info` / `<root>` 报错文本）；
       - **提交成功后自动重拉该帖第 1 页**，返回刷新后的 `ThreadDetailPage`（含最新 `ThreadPoll` 票数与占比），使 `E2c` 无需二次拼装即刻刷新投票柱条。
