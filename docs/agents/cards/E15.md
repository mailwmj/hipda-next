# 任务卡 E15：登录页、临时退出登录出口与 `R-A6 S3/S4` / `V-A6` 收口

【目标】实现 M5 完整登录页并经 `E0` 的 `LoginOverlayRenderer` 插槽零耦合接入 `NextAppRoot`；同时交付两项关键收口：一是 `E12` 落地前的**临时退出登录出口**（经 `LoginOverlayMode.AccountMenu` 调用 `AuthRepository.logout()` 并提示 `已退出登录`），让里程碑 A 真机包可完整实测登录、手动退登不再静默重登与换号；二是集中闭合从 `E0` 移交的 **`R-A6 S3/S4` 与 `V-A6`** 历史遗留（`ChallengeStatusView` 未满 2s 加载插槽、`ComposeChallengeInteractionPresenter` 接入用户主题、`HiLoadingSpinner` 公开去重与 `ChallengeState.effectiveAt` 复用、`ChallengePanelHeader` `340dp`+`2x` 副行防挤占）。

- 具体实现项（预计生产代码净增/改动 ~420–620 行）：
  1. **完整登录页（`feature/login/{LoginViewModel,LoginScreen}.kt`）**：
     - 自适应形态（按 `product-design.md` §4.2）：窗口宽 `< 600dp` 全屏页面推入；`≥ 600dp` 覆盖全部栏居中模态卡片，最大宽 `480dp`（纯色表面，不用毛玻璃）；支持系统返回与顶部返回/关闭；
     - 表单字段（文案逐字取自 `copy.md`，放入 `res/values/strings_login.xml`）：标题 `登录 HiPDA`、`用户名`、`密码`（带密码显隐切换按钮，触控区 ≥ `48dp`）、`安全提问` 下拉菜单（默认 `无安全提问`，覆盖 Discuz 标准安全提问选项）；
     - **条件展开与载荷净化（闭合 B4-E15 ①）**：仅当选中具体安全提问（非 `无安全提问`）时，用 `hiExpandVertically` / `hiShrinkVertically`（`HiMotion.spatialDefault()`，减动效 0ms）展开 `提问回答` 输入框；**若用户选过安全提问、填了答案后再切回 `无安全提问`，提交时必须清空并净化载荷，传给 `AuthRepository.login` 的 `securityQuestionId == 0 && securityAnswer == ""`**；
     - **提交态、原地字段报错与精确焦点路由（闭合 B4-E15 ②）**：点击 `登录` 后按钮内 0ms 切换 `HiLoadingSpinner`（内容描述 `正在登录…`，防重复提交，留在本页）；失败时**保留全部已填输入**，按错误类型在对应出错字段下方原地展示 `copy.md` 规范文案（`用户名或密码错误` 挂在用户名/密码区并聚焦密码/对应出错框；`安全提问回答错误` 挂在 `提问回答` 字段下方并精确将焦点移至 `提问回答` 框；网络错误显示 `网络连接失败，请重试`）；遇到 Cloudflare 验证复用 `ChallengeStatusView`；登录成功调用 `onLoginSuccess()` 自动关闭并继续原操作。
  2. **零耦合插槽绑定与临时“退出登录”出口（`feature/login/LoginOverlayRendererImpl.kt`、`di/LoginUiModule.kt`）**：
     - 在 `di/LoginUiModule.kt` 中以 `@Binds` 将 `LoginOverlayRendererImpl` 绑定到 `E0` 的 `LoginOverlayRenderer`（`AppShellBindingModule` 已提供 `@BindsOptionalOf`，**严禁修改 `feature/app/` 或 `di/AppShellBindingModule.kt`**）；
     - 在 `LoginOverlayRendererImpl.Content(mode, onDismiss, onLoginSuccess)` 中分流两种模式：
       - `LoginOverlayMode.Login`：承载 `LoginScreen`；
       - `LoginOverlayMode.AccountMenu`（**临时退出登录出口，闭合 BATCH-5 S1**）：在 `E12` 账号页落地前，已登录态点击账号入口展示极简临时面板/对话框，显示当前用户名与 `退出登录` 动作（不设二次确认，遵守 §7.11；点击直接调用 `AuthRepository.logout()`，成功后关闭浮层并经 `LocalPaneSnackbarController` 提示 `已退出登录`，停留在当前页且触发手动退出标记不再静默重登；另提供 `关闭` 与系统返回关闭路径）。
  3. **集中收口 `R-A6 S3/S4` 与 `V-A6`（授权小范围改动 `ui/challenge/` 与 `HiStateViews.kt`）**：
     - **`R-A6 S3` ①（`ChallengeStatusView.kt`）**：新增可选参数 `pendingLoadingSlot: (@Composable () -> Unit)? = null`（默认 `null` 保持全部现有调用方 100% 源码兼容）；当处于 `ChallengeState.Solving` 且未满 `CheckingDelayMs`（2000ms）时渲染 `pendingLoadingSlot`（让调用方保留原本的加载指示），满 2000ms 后再平滑切换至 `正在检查安全环境…`；
     - **`R-A6 S3` ②（`ComposeChallengeInteractionPresenter.kt`）**：注入 `SettingsRepository`（同时保留对测试友好的内部构造重载，确保 `ChallengeStatusAndPresenterTest` 适配更新），在挂载 `ChallengePanelOverlay` 的 `ComposeView` 中经 `HiThemeSettingsAdapter` 实时订阅用户主题/纯黑/种子色/字号传入 `HiTheme`，使 Cloudflare 人工验证面板与用户主题一致；
     - **`R-A6 S4`（`HiStateViews.kt`、`ChallengeStatusView.kt`）**：将 `HiStateViews.kt` 的 `HiLoadingSpinner` 改为 `public`（支持自定义 `strokeWidth` 默认 `2.dp`），删除 `ChallengeStatusView.kt` 中重复手写的 `ChallengeCheckingSpinner` 改直接复用 `HiLoadingSpinner`；核查并彻底复用 `ChallengeState.effectiveAt(nowMs)` 消除重复冷却到期判断逻辑；
     - **`V-A6`（`ChallengePanel.kt`）**：修复 `ChallengePanelHeader` 在 `340dp` 窄宽 + `fontScale = 2.0f` 下副行挤占/截断问题（如在极端窄屏大字号下合理收敛副行行数与标题操作区排布，确保标题、`刷新`/`取消` 按钮 ≥ `48dp` 不重叠且不挤占 WebView 区域，同时保持 `411×891dp` 与 `900×600dp` 默认字号下既有 7 张 `challenge_*.png` 基线 0 漂移；如任何既有 `challenge_*.png` 存在有意微调须在报告说明并经审阅）。
- **明确不做**：不实现多账号列表/`添加账号`/`清除登录信息`（留待 M6 `E12`）；不改 `feature/app/*`、`feature/common/*`、`feature/forum/*`、`feature/threaddetail/*`、`data/*`、`di/AppShellBindingModule.kt`、`di/ImageLoaderModule.kt`、`src/debug/*`；测试严禁用真实账号访问真实站点（4d4y.com）。

【验收】
1. **条件字段展开与载荷净化（B4-E15 ①）**：`LoginViewModelTest` & `LoginScreenTest` 模拟默认隐藏 `提问回答` → 选安全提问后展开并输入 `"王芳"` → 再切回 `无安全提问`（输入框收起）后点击 `登录`，硬断言传给 `AuthRepository.login` 的参数满足 `securityQuestionId == 0 && securityAnswer == ""`。
2. **失败保留输入、原地报错与精确焦点路由（B4-E15 ②）**：分别注入 `InvalidCredentials`（用户名/密码错）与 `SecurityQuestionWrong`（安全提问错）与网络错误，断言：(a) 所有已填内容均原样保留；(b) 错误文案各自挂载在对应字段下方（无异常类名/状态码）；(c) 输入焦点精确移动至对应出错输入框；(d) 点击 `登录` 时按钮 0ms 变 `HiLoadingSpinner` 且禁用防连点；(e) Cloudflare 状态正确展示 `ChallengeStatusView`。
3. **临时“退出登录”出口与零耦合插槽**：`LoginScreenTest` 验证 `LoginOverlayMode.AccountMenu` 展示当前账号与 `退出登录`，点击直接调用 `AuthRepository.logout()`（无二次确认框）、关闭覆盖层并经 `LocalPaneSnackbarController` 发出 `已退出登录`；验证 `LoginUiModule` 正确绑定 `LoginOverlayRenderer`。
4. **`R-A6 S3/S4` 与 `V-A6` 闭合**：
   - `ChallengeStatusAndPresenterTest` 新增/更新单测验证：(a) `ChallengeStatusView` 传入 `pendingLoadingSlot` 在 `Solving` 0–1999ms 展示该插槽、到达 2000ms 切为 `正在检查安全环境…`；(b) `ComposeChallengeInteractionPresenter` 消费 `SettingsRepository` 将深色/纯黑主题传给 `ChallengePanelOverlay`；(c) `HiLoadingSpinner` 公开复用且无重复实现；(d) `ChallengePanelOverlay` 在 `340dp` + `fontScale = 2.0f` 下头部不重叠、按钮 ≥ `48dp` 且 WebView 区域保有足够可用高度。
