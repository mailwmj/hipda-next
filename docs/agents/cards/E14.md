【范围】
1. **全屏覆盖、多图横滑与交互栏（§7.1、§10.2，零毛玻璃）**：
   - 全屏暗色浮层，三栏（含 `933dp`/`1280dp`）下覆盖全部三栏，拦截系统返回（`BackHandler`）；
   - 顶栏显示标题（有楼层与作者时显示 `第 {N} 楼 · {用户名}`）、页码 `i / total`、关闭按钮（`≥ 48dp`）；底栏提供 `查看原图`（加载完成后切为 `已加载原图`）、`保存图片`、`分享`（`≥ 48dp`，纯色半透明暗底，零 `HiGlassSurface`）；
   - **手势规范（修正旧版误触）**：单击显示或隐藏工具栏（绝不关闭）；长按弹出 `保存图片` / `分享` 菜单；`HorizontalPager` 多图横滑。
2. **共享边界进入与退出双分支（§6.3、§10.2）**：
   - 接收 `args: ImageViewerLaunchArgs` 与可选边界回调 `resolveBoundsForIndex: (index: Int) -> Rect? = { if (it == args.initialIndex) args.sourceBoundsInWindow else null }`；
   - **进入**：有 `sourceBoundsInWindow` 时从该 `Rect` 位置和大小以 `HiMotion.spatialSlow()` 放大到全屏，背景遮罩淡入；
   - **退出（下拉关闭、点关闭、系统返回走同一出口）**：
     - 分支 (a)：当前图对应的缩略图完整位于可见内容区（`resolveBoundsForIndex(currentIndex) != null`）→ 缩回该缩略图的位置和大小（`HiMotion.exit(HiMotion.spatialSlow())`，起点/终点误差 `≤ 1dp`）；
     - 分支 (b)：横滑到缩略图在屏幕外或被顶栏/工具条遮挡的图（返回 `null`）→ 原地缩至 `0.85f` 并淡出（`HiMotion.exit(HiMotion.spatialDefault())` + `HiMotion.exit(HiMotion.effectsDefault())`），绝不飞向屏幕外、绝不闪现别的图；
     - 减少动态效果下 0ms 一帧到位。
3. **缩放、平移与下拉关闭手势（§6.3）**：
   - 双击在 `1.0f ↔ 2.5f` 间围绕双击点平滑切换（`HiMotion.spatialDefault()`）；双指捏合连续缩放并钳制边界平移；放大态（`scale > 1.01f`）优先平移图片，仅到边缘时交给 `HorizontalPager` 翻页；
   - **竖向跟手下拉关闭**（仅 `scale <= 1.01f` 且竖向位移占优时起手，绝不抢占横滑翻页）：下拉 `0 → 240dp` 期间，图片缩放线性由 `1.0f → 0.8f`，背景遮罩不透明度由 `1.0f → 0.3f`（下限钳制 `0.3f`，不再更低）；松手位移 `> 120dp` 或向下速度 `> 800dp/s` 带着速度进入退出动画关闭；否则以 `HiMotion.spatialSnap()` 弹回。
4. **高清切换、长图与 GIF（§6.3）**：
   - 高清/原图就绪前一直用已加载缩略图垫底，就绪后以 `HiMotion.effectsFast()` 淡入覆盖；
   - **长图（高宽比 `> 2.5f`）**：直接以“贴合宽度、对齐顶部”展示并允许竖向滚动浏览，加载完成后不自动跑缩放动画；
   - **GIF**：左上角显示 `GIF` 角标（切换动效 `HiMotion.effectsFast()`），点一下播放或暂停。
5. **原图字节级确定进度下载（收口 `R-E2b S4`）、保存与分享、严格 scheme 白名单**：
   - 定义可注入/可测试的 `OriginalImageDownloader` 抽象（默认基于项目 OkHttp `Call.Factory`，**不修改 `di/ImageLoaderModule.kt` 或 `okhttp/`**）：按流式读取字节并依据 `Content-Length` 实时发出 `0f..1f` 确定进度（未知长度时回退不确定态）；点击 `查看原图` 显示确定进度圈，再次点击立即取消下载与底层 HTTP Call；完成后切换原图并提示 `已加载原图`；
   - `保存图片`：API 29+ 写入 `MediaStore.Images.Media`（API ≤ 28 兼容写入，在 IO 调度执行），成功弹 `已保存到相册`，失败弹 `保存失败`；`分享` 经安全缓存 URI 发起系统分享（不改 `AndroidManifest.xml`）；
   - **严格 `http`/`https` 白名单**：对 `urls` 每一项及缩略图/原图/保存/分享全链路强制校验含非空 host 的 `http`/`https` 白名单（拒绝 `file://`、`content://`、`android.resource://`、`javascript:`、`intent:`、`data:`、`mailto:` 及大小写/空白/控制字符绕过），非法 URL 直接显示 `图片加载失败` 且发起 **0** 次 Coil/网络请求，并配全套危险 scheme 反例测试。

【验收标准】
1. **进退双分支逐帧几何测试**：`autoAdvance = false` 下验证 (a) 缩略图可见时进入起点与退出终点对齐缩略图 `Rect`（误差 `≤ 1dp`）；(b) 横滑到缩略图不可见（`resolveBoundsForIndex == null`）后退出原地缩至 `0.85f` 并淡出，不飞向屏幕外、不闪旧图；减动效 0ms 一帧到位。
2. **下拉关闭与缩放手势逐帧测试**：下拉 `0 → 240dp` 验证缩放 `1.0 → 0.8` 与遮罩 `1.0 → 0.3`（超过 240dp 仍保持 `0.3`）；位移 `> 120dp` 或速度 `> 800dp/s` 关闭，未达阈值 `spatialSnap` 弹回；水平滑动翻页不被下拉手势抢占；单击切工具栏、长按出 `保存图片`/`分享`、双击缩放/还原、放大态不触发下拉关闭。
3. **长图、GIF 与原图字节级确定进度取消测试**：长图（AR > 2.5）贴宽顶对齐且加载后无自动缩放；GIF 角标点按切播停；`MockWebServer` 节流响应验证 `OriginalImageDownloader` 逐块回调真实确定进度（`0 < p < 1`）及二次点击取消后中止传输与状态复位；`保存图片` 成功/失败发对应 Snackbar。
4. **Scheme 白名单反例测试**：全套危险 scheme（`file:`/`content:`/`android.resource:`/`javascript:`/`intent:`/`data:`/`mailto:` 及空白/控制字符/大小写/空 host）在看图加载、原图下载、保存分享全路径均拦截（0 Coil 请求、0 下载请求）。
5. **Roborazzi 截图基线与 CI**：新增 `image_viewer_*.png`（覆盖 `411/749/933/1280dp` 浅/深、长图、GIF、原图确定进度态，含 `933dp` 盖住全部三栏，约 11 张），既有非本卡快照 0 漂移；本地跑通 `feature/imageviewer`、`CopyTerminologyScanTest`、`MotionTokenScanTest` 与 `:hipda:assembleDebug`，GitHub Actions CI 全绿。
