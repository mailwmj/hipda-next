3. **三种编辑模式、多入口接通、草稿与 `R-D1` / `R-D6 S2`（`feature/compose/FullEditorViewModel.kt`）**：
   - **发新帖（`DraftKey.newThread(fid)`）**：接通 `ForumPane` 顶栏 `发新帖`（通过可选插槽或 `ForumPane` 内注入宿主，**不改 `NextAppRoot.kt`**）。版块默认当前版块；**收口 `R-D1`**：在 `今日新帖` 打开时版块未选中，必须先由用户选择有效版块（正整数 `fid > 0`）后才生成 `DraftKey.newThread(fid)` 读写草稿与预取 `PrePostRequest.NewThread(fid)`；若版块含 `typeOptions` 则显示分类选择器；提交成功后关闭编辑器、刷新帖子列表并弹 Snackbar `帖子已发出`（按钮 `查看`，点击打开新帖）；
   - **回复 / 引用（`DraftKey.reply(tid)`）**：承接 `E5` 交接或直接打开，提交成功后删除 `reply:<tid>` 草稿，关闭编辑器并联动刷新/压栈 `回复已发送`（按钮 `查看`），过滤模式下可正常回复；
   - **编辑已发表楼层（`DraftKey.edit(pid)`）**：接通 `ThreadDetailPane` 中 `FloorContextMenuOverlay.onEdit`；预取 `PrePostRequest.EditPost(fid, tid, pid, page)` 获取线上原文（标题/分类/正文/已有图片 `existingImages`）；顶栏显示 **`还原原文`** 按钮（**仅当当前标题、分类或正文与线上原文不同时出现**），点击将内容换回线上原文并弹 Snackbar `已还原原文`（按钮 `撤销`，走统一令牌撤销模型恢复编辑态）；编辑提交（`PostSubmitRequest.EditPost`，不受 30 秒冷却限制、不附小尾巴）成功后删除 `edit:<pid>` 草稿并刷新帖子；
   - **草稿自动保存、恢复与收口 `R-D6 S2`**：顶栏返回箭头、系统返回键（`BackHandler`）与预测性返回走同一出口：内容非空且与线上原文/上次已发不同时静默调 `saveDraft` 并弹 `已保存草稿`（按钮 `放弃`，点击调 `deleteDraft`）；再次打开同业务键自动恢复并显示横条 `已恢复上次草稿`（按钮 `清空`）；**收口 `R-D6 S2`**：若恢复了已有草稿（`hadPersistedDraft == true`），随后手动删空内容或点 `清空` 后退出，**必须显式调用 `postRepository.deleteDraft(key)`**，杜绝下次重开复活（附撤回即红单测）。
4. **多图上传条与内联缩略图块（`feature/compose/ImageUploadStrip.kt`、`EditorContentModel.kt`）**：
   - 输入框上方为横向滚动缩略图条；选图（系统多图选择，走安全 `content://` `ContentResolver` 流式读取，禁用不安全 URI scheme）后立即插入缩略图占位并叠加环形进度（区分 `Compressing` 与确定进度 `Uploading(fraction)`），条上显示汇总 **`正在上传 {current}/{total}`**；
   - 单张上传失败在缩略图上显示重试图标（无障碍 `上传失败，点击重试`），点按单张重传不影响其他项；点击右上角 `×` 移除该图（上传中立即取消对应协程与 OkHttp `Call`；编辑态移除 `existingImages` 记入 `deletedAttachments`）；
   - 点已上传缩略图在当前光标处插入该图，**正文内以可视化缩略图块展示，严禁向用户暴露原始 `[attachimg]` 标签文本**（提交或写草稿时透明序列化为 `[attachimg]{imageId}[/attachimg]`，恢复草稿或编辑原文时反向解析还原为缩略图块）；尚未插入正文的已上传图片带角标提示，点发送时按顺序自动附在正文末尾、不弹出询问框；
   - 上传期间允许继续编辑文字；点发送时若仍有图片在上传中或失败，原地清晰提示不丢失输入，待上传完成或移除/重试后提交；
   - 图片上传链路须配完整 **`MockWebServer`** 测试（压缩默认 `original = false`、分阶段进度、单图失败重试、移除取消、未插图自动附尾与表单字段校验）。
5. **多栏响应式形态（§4.2）、玻璃零新增、内联校验与提交（`feature/compose/FullEditorScreen.kt`）**：
   - **严格遵循 §4.2**：
     - 单栏（`< 600dp` 或高度 `< 480dp`）：全屏展示；
     - 2 栏（`600–679dp`）/ 物理铰链双栏：覆盖全部栏水平居中模态，宽 `≤ 680dp`；
     - 三栏（`≥ 680dp`）：右栏当前宽度 **`< 560dp`**（如 `749dp`/`933dp` 折叠屏与竖屏平板）时，**覆盖全部三栏水平居中模态打开**（宽 `min(W − 48dp, 680dp)`，可经 `Dialog(DialogProperties(usePlatformDefaultWidth = false, decorFitsSystemWindows = false))` 零改 `NextAppRoot.kt` 实现）；右栏宽度 **`≥ 560dp`**（如 `1280dp` 平板横屏）时，在**右栏内展开**（最大宽 `680dp`，覆盖详情区并向底部工具条传 `suppressBottomGlass = true`）；
     - 编辑器本身为纯色表面（**0 个 `HiGlassMarker`**），保持三栏全屏 `HiGlassMarker ≤ 3`、独立 `LayerBackdrop ≤ 2`、静止 `drawBackdrop ≤ 5`；
   - **内联校验与提交（`copy.md` 逐字对齐）**：发新帖校验 `请选择版块`、`请选择分类`（版块有必填分类时）、`请输入标题`、`标题至少 6 个字`、`内容至少 6 个字`；回复/编辑校验 `内容至少 6 个字`（无图片附件时）；点 `发送` 0ms 按钮内变 `HiLoadingSpinner`（`正在发送…`）且留在本页；失败原地展示 `发送失败`（按钮 `重试`）或服务端原因、保留全部文字与图片；非编辑态订阅 `PostRepository.cooldownUntilMs` 显示 30 秒冷却倒计时（`HiRollingNumber`，`{N} 秒后可发送`），倒计时期间允许继续编辑；未登录原地提示 `登录后即可操作`（按钮 `登录`）；
   - **返回优先级**：编辑器打开时 `BackHandler(enabled = isOpen)` 按打开态 key 重挂（遵 `lesson.md` LIFO 规则），高于 `PositionStack` 与多栏返回栈，低于看图/登录浮层；退出先静默存草稿再关闭。
