1. **设置页（5 组完整设置，对齐 §7.10 与 `copy.md`，纯色顶栏，零毛玻璃）**：
   - 单栏为 5 组列表 → 二级详情；宽屏三栏/铰链双栏为中栏 5 组 + 右栏当前组详情（复用 `SettingsGroup` 枚举，账号操作留在「我的 → 账号」不放进设置）：

     - **`论坛与发帖`**：`管理版块`（增删与排序关注版块，实时写入 `SettingsRepository`）、`显示置顶帖`、`小尾巴`（开关、`尾巴文字`、`尾巴链接`；非空链接须校验 `http`/`https` 白名单）、`黑名单`（进入黑名单子页）。
     - **`通知与免打扰`**：`接收提醒通知`（切换时联动 `NotificationScheduler.syncSchedule(enabled)`）、`通知声音与样式`（说明 `在系统设置中调整`，跳系统应用通知设置并安全捕获 `ActivityNotFoundException`）、`免打扰时段`（开关、`开始时间`、`结束时间`）。
     - **`网络与缓存`**：`论坛服务器`（严格校验 `http`/`https` 且 host 非空，拦截非法 scheme 并附反例单测）、`图片缓存上限`、`清除图片缓存`（显示 `已占用 {size}`，执行中 `正在清除…`，完成后发 Snackbar `已清除 {size}`）、`清除网页缓存`（执行中 `正在清除…`，完成后发 `已清除 {size}` 或完成提示）。

2. **黑名单管理页（§7.1、§7.10）**：
   - 展示黑名单用户；空态 `黑名单是空的`；未登录原地提示登录；
   - 点击 `移出黑名单` 按钮**原地变为进度圈**（禁用防重复点），成功后收起该行并弹可撤销 Snackbar `已将 {用户名} 移出黑名单`（按钮 `撤销`，点击调用加入黑名单恢复）。
3. **正式账号管理页 + 收口 `R-E15 S2` 删除临时账号菜单（§7.11）**：
   - 展示已保存账号列表（当前账号带 `当前账号` 标记）：点其他账号**直接切换，不弹窗确认**，调 `AuthRepository.switchAccount(...)`，成功发 Snackbar `已切换到 {用户名}`；
   - `添加账号`：切换至 `LoginOverlayMode.Login` 完成新增登录；
   - `退出登录`：**不确认**，直接调 `AuthRepository.logout()`（保留已保存凭据、设手动退出标记不再静默重登），发 Snackbar `已退出登录`；
   - 最底部 **`清除登录信息`**：弹出二次确认框（标题 `清除 {用户名} 的保存密码并退出？`，按钮 `取消`/`清除`），确认后删除保存密码并退出；
   - **收口 `R-E15 S2`**：删除 `feature/login/LoginOverlayRendererImpl.kt` 中约 71 行的临时 `AccountMenuOverlay` 与 `LoginViewModel.kt` 中仅供临时退登弹窗使用的 `isLoggingOut`/`logout(...)` 代码（以及 `strings_login.xml` 中不再复用的临时文案），由 `LoginOverlayRendererImpl` 在 `LoginOverlayMode.AccountMenu` 下直接渲染本卡的 `AccountManagementOverlay`（支持在浮层内切换到 `Login` 添加账号）；**不触碰 `ChallengePanel.kt`**，并保留既有登录表单与 `Bundle` 零凭据单测。
4. **用户资料页（§7.8，纯色顶栏，零毛玻璃）**：
   - 上方固定资料头（圆形头像、用户名、主要统计）；操作按钮 `发短消息`、`加入黑名单` / `移出黑名单`（按钮原地进度圈 + 可撤销 Snackbar `已将 {用户名} 加入黑名单` / `已将 {用户名} 移出黑名单` + `撤销`）；
   - 下方双标签 `资料` | `TA 的帖子`：各自维护独立骨架/空/错态，切换采用“同级换内容”无白屏闪跳；`TA 的帖子` 为空时显示 `TA 还没有发过帖子`（不报错），点帖回调 `onOpenThread`；资料页内所有站点链接/签名/图片严格走 `http`/`https`/经校验 `mailto`（图片仅 `http`/`https`）scheme 白名单，并配反例测试。
