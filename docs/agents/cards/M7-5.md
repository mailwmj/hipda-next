## 1. 全新安装与核心功能回归（操作 → 预期）
1. **桌面图标与正式启动**：全新安装后桌面仅有新版主图标（无残余旧版“预览”双图标冲突），点击冷启动直接进入新版论坛首页，无崩溃、无白屏卡顿。
2. **桌面快捷方式（4 项）**：长按桌面图标分别点击 `今日新帖`、`搜索`、`短消息`、`收藏与关注` → 均冷/热启动准确落地对应目标页，旋转屏幕不重复跳转。
3. **外部链接（`.ng.IntentActivity`）与防自环**：
   - 从外部应用点击 `https://www.4d4y.com/forum/viewthread.php?tid=...`、`forumdisplay.php?fid=...`、`space.php?uid=...` → 自动拉起新版并定位到对应帖子/版块/用户资料；
   - 点击无法识别的 `4d4y.com` 路径链接 → 弹 `无法识别该链接 | 在浏览器中打开`，点按钮拉起第三方浏览器（Chrome 等），**绝不循环拉起本应用自身**。
4. **通知权限（targetSdk 36 / API 33+）与后台提醒**：
   - 进入 `设置 → 通知与免打扰` 打开 `接收提醒通知` → 弹出系统通知权限弹窗；先试拒绝 → 不崩溃、原地提示并可跳系统通知设置；再授权 → 正常开启，有未读时通知栏显示隐私脱敏通知，点击直达对应短消息会话/提醒列表。
5. **登录、真机 Android Keystore 加密存储与 Cloudflare 通道**：
   - 登录账号（覆盖安全提问场景；如遇密码/安全提问错误核对提示文案，同步关闭 `R-E15 S5` 观察项）→ 强杀应用冷重启后自动保持登录态（验证真实 Android Keystore + Tink `hx_credentials` / `hx_site_cookies` 持久化）；
   - 如触发 Cloudflare 人机验证 → 桌面 Linux Chrome UA 下后台自动过盾或弹出验证面板，通过后原请求自动继续（关闭桌面 UA 过盾待观察风险）；
   - 切号、`退出登录`（不静默重登）、`清除登录信息`（二次确认）均正常。
6. **全面屏（Edge-to-Edge）与预测性返回**：
   - 分别在**手势导航**与**三键导航**、**浅色 / 深色 / 纯黑 OLED** 下检查状态栏与导航栏图标清晰可读，顶栏内容、底部胶囊、三段工具条、快速回复面板、完整编辑器、表情面板、看图工具栏无遮挡、无双倍留白；
   - 侧缘预测性返回动画流畅，返回优先级严格满足 `看图 / 登录 > 侧栏浮层 > 表情面板 > 快速回复 / 完整编辑器 > 位置栈 > 多栏返回栈`。
7. **读帖核心（M5）与发帖链路（E5/E6/E7）**：
   - 连续上下翻页不跳动、阅读位置记忆与位置栈、底部三段工具条与内联跳页条、只看楼主/只看此人、引用展开/跳楼高亮、1 楼投票；
   - 快速回复面板随键盘逐帧升降、矮屏限高不溢出、`展开全屏` / `插入图片` 无损交接文本/光标/引用、完整编辑器多图自动压缩上传与缩略图块（无 `[attachimg]` 原文）、草稿保存/恢复/清空不复活、编辑 `还原原文` 与撤销、删除自己楼层确认、表情面板与键盘等高原地互换（底缘零位移）（*写操作由用户按意愿选测*）。
8. **MediaStore 下载、看图保存与分享（零存储权限弹窗）**：
   - 在看图器点击 `保存图片` 与 `分享`，在帖子内点击附件下载 → Android 10–16 **全程不弹存储权限框**，文件准确写入系统相册 / `Download` 目录且分享正常。
9. **折叠、展开、半折铰链与状态迁移**：
   - 外屏单栏 ↔ 内屏展平三栏 ↔ 半折铰链双栏 ↔ 旋转反复切换（在正在读长帖、打开快速回复/编辑器或浏览二级页时）→ 零崩溃、阅读位置/输入草稿/分栏吸附偏好无损保持。

## 2. 真机 120Hz 性能、Baseline Profile 与极端可读性验收
1. **120Hz 滚动帧率实测（Galaxy Z Fold8）**：
   - 场景 A：单栏 300+ 楼带图长帖连续快速滚动；
   - 场景 B：**内屏展平三栏同时开启 3 块实时液态玻璃**（中栏顶栏 + 右栏顶栏 + 右栏底部三段工具条）连续滚动；
   - 采集命令（在连接真机的终端运行）：
     ```bash
     adb shell dumpsys gfxinfo net.jejer.hipda.next reset
     # 真机连续滚动 15–20 秒后执行：
     adb shell dumpsys gfxinfo net.jejer.hipda.next
     ```
   - **达标红线**：120Hz 下 **P90 帧时间 < 8.3ms**（60Hz 设备 < 16.7ms），**Janky frames ≤ 1%**；若不达标，按 `docs/design/product-design.md` §5 预定 4 级回退顺序逐级降级复测至达标，并记录最终档位回写 `product-design.md` §5。
2. **Baseline Profile 冷启动与首滑对比**：
   - 记录全新安装后冷启动耗时（`adb shell am start-activity -W -n net.jejer.hipda.next/.feature.app.MainActivity` 的 `TotalTime`）及首次进入 300 楼长帖是否顺滑无明显 JIT 卡顿（满足 `R-M0-2 R4` 真机帧时间验收）。
3. **液态玻璃极端样张可读性（API 33+ 折射 + 4 路系统降级）**：
   - 滚过纯黑图 `#000000`、纯白图 `#FFFFFF`、高饱和彩色图时，透明顶栏/胶囊/三段工具条/快速回复文字与图标清晰可读；
   - 开启系统省电模式 / 降低透明度 / 高对比度文字时自动降级为 94% 纯色 + 细描边，恢复后自动回到液态玻璃；
   - 同步确认液态玻璃四档最终参数（若此前尚未定稿回写 `product-design.md` §5）。
4. **历史真机观察项收口**：
   - `R-E2b S2`：快速惯性滑行（fling）途中首楼越顶图片解码完成时，观察是否存在可感知的惯性顿停；
   - `R-E15 S5`：如触发安全提问回答错误，记录站点原始提示文本。
