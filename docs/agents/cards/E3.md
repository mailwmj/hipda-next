  1. **中右分隔线与拖拽吸附（`≥ 680dp`，`PaneDividerHandle.kt`、`MultiPaneReadingContainer.kt`）**：
     - `1dp` 视觉分隔线 + `48dp` 跨边触控热区，优先复用 Compose 标准 `AnchoredDraggable` 实现跟手拖拽，松手继承初速以 `HiMotion.spatialSnap()` 吸附至 `calculateShellPaneLayout` 可用档位（`列表收起` / `默认` / `均衡`）；
     - **闭合 R-BATCH5 B4-E3 ①（空右栏拖动锚点硬底线）**：当 `hasDetailContent == false` 时，`AnchoredDraggable` 锚点集合严格不含 `0dp` 且不可恢复 `列表收起`，向左大幅拖动逐帧保持中栏宽度恒 `≥ M_default`；
     - 按横竖屏方向经 `SettingsRepository` 持久化 `paneSplitPortrait` / `paneSplitLandscape`；
     - 暴露 `CustomAccessibilityAction`（`默认宽度` / `均衡` / `收起列表`）并支持外接键盘焦点 `Enter`/方向键切换；三栏按左→中→右声明 `isTraversalGroup = true` 与 `paneTitle`。

     - 经 `DetailChromeSpec.fullScreenState` 驱动：点击 `全屏阅读` 一键隐藏左栏与中栏进入真全屏（正文最大 `680dp` 居中，释放中栏玻璃源）；再点 `显示列表` 一键还原进入全屏前的左栏状态（展开或图标轨）与中栏吸附档位；铰链双栏下等效为收起/显示列表。
  3. **三栏 3 区域实时液态玻璃协同与铰链双栏配额守卫**：
     - 三栏下中栏持独立 `middleGlassState` 并通过 `ForumChromeSpec(showForumTabs = false, useGlassTopBar = true, externalGlassState = middleGlassState)` 驱动 `E1` `ForumPane`，右栏由 `E2a` 自持 `detailGlassState`（跨栏隔离）；实测真实 `E1` + `E2a` 协同满足 `HiGlassMarker ≤ 3`、独立 `layerBackdrop` 采样源 `≤ 2`、静止 `drawBackdrop` pass `≤ 5`；
     - 铰链双栏通过 `ForumChromeSpec(showForumTabs = true, useGlassTopBar = false, externalGlassState = shellGlassState)` 强制左列表顶栏保持纯色（0 顶栏玻璃），为左紧凑胶囊 + 右详情顶栏 + 右底部工具条留出 3 区域上限配额。
  4. **物理铰链双栏、返回栈与非论坛入口迁移（闭合 R-BATCH5 B4-E3 ②，`MultiPaneBackStack.kt`、`NextAppState.kt`）**：
     - 消费 `WindowInfo` / `FoldingFeature`：`isSeparating == true` 且两侧满足 `≥ 280/360dp` 时严格对齐 `hingeBounds` 呈现铰链双栏，不足时自动退单栏居中于较宽一侧；
     - 返回栈规则：左栏切版块/入口替换中栏根并重置右栏占位；中栏连续点 5 篇帖子只替换右栏根不压栈；右栏下钻独立压栈；系统返回按 §4.2 5 级优先级执行；
