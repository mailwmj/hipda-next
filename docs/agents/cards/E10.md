【范围】
1. **搜索页（§3、§7.7，纯色顶栏，零毛玻璃）**：
   - 顶栏内嵌搜索框（提示 `搜索标题、正文或作者`，带清除按钮与软键盘提交）；
   - **站内地址识别与 scheme 白名单**：输入经 `ForumLinkResolver` 实时识别，命中合法 `http`/`https` 站内链接时在首行显示 **`打开这个链接`**（点击路由至 `onOpenThread`/`onOpenForum`/`onOpenUserProfile`）；必须强制校验 `http`/`https` scheme 白名单，拦截 `javascript:`、`intent:`、`file:`、`content:`、`data:`、`mailto:` 及空白/控制字符绕过（配反例测试）；
   - **初始态（未提交搜索）**：绝不显示空状态；展示 `最近搜索`（为空时不显示小标题与列表，每条右侧 `×` 删除立即生效并发可撤销 Snackbar `已删除` + `撤销`）与筛选胶囊（`版块`、`标题`/`全文`、`作者`）；
   - **可打断筛选面板**：点击筛选胶囊用 `HiMotion.spatialDefault()`（`hiExpandVertically`/`hiShrinkVertically`）可打断展开/收起（减动效 0ms）；
   - **结果与无结果态**：支持分页加载、下拉刷新、点击结果回调 `onOpenThread`；仅在提交搜索返回 0 条时显示 `没有找到相关内容`（有筛选条件时带按钮 `清除筛选`，无筛选时不显示按钮）。
2. **「我的」聚合页与 3 个子页面（§3、§4.2、§7.1，纯色顶栏，零毛玻璃）**：
   - **单栏「我的」菜单页**：顶部账号入口卡片（展示已登录用户名或未登录提示，点击触发 `onAccountClick`）+ 菜单列表：`收藏与关注`、`我的帖子`、`浏览历史`、`设置`（均满足 `≥ 48dp` 触控区与 `hiPressScale`）。
   - **收藏与关注**：顶部双标签 `收藏` | `关注`；下拉刷新与分页；点帖进 `onOpenThread`；支持取消收藏/取消关注并立即生效，经 `LocalPaneSnackbarController` 弹 `已取消收藏` / `已取消关注`（按钮 `撤销`，点撤销恢复）；空态 `还没有收藏` / `还没有关注`；未登录原地 `需要登录才能查看`（按钮 `登录`）。
   - **我的帖子**：单栏下顶部双标签 `主题` | `回复`（宽屏侧栏态由左侧栏区分 `我的帖子` / `我的回复`，隐藏重复标签行）；下拉刷新与分页；点帖进 `onOpenThread`（回复项携带 `targetPid`）；空态 `还没有发过帖子` / `还没有回复过帖子`；未登录原地提示登录。
   - **浏览历史**：读取 D1 Room `BrowseHistory`（纯离线无需登录）；点帖进 `onOpenThread`；支持单条删除与一键清空，立即生效并发可撤销 Snackbar `已删除` + `撤销`（撤销写回 Room 恢复）；空态 `暂无浏览历史`。
