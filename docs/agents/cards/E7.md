   - **键盘已展开 → 点 `表情`**：立即以记忆的键盘高度占位展示表情面板并隐藏软键盘，使底部占位区总高在 `IME 退场` 全程恒定为 `rememberedImeHeight`，确保 `QuickReplySheet` 输入栏与 `FullEditor` 底部工具栏**底缘零位移（逐帧 `|Δbottom| == 0dp`）**，严禁先塌陷到底再弹起；
   - **表情面板已展开 → 点 `键盘`（或点击输入框）**：先请求弹出软键盘并保持面板占位高度直至软键盘追上/接管，再切回纯键盘态，同样保证**底缘零位移**；
   - **无可用键盘高度时的回退限高（§7.4 硬规则）**：在分屏、浮窗、外接物理键盘或刚打开尚未弹过键盘（`rememberedImeHeight == 0`）场景下，面板高度严格按纯函数计算：
     - 窗口高 `≥ 480.dp`：`min(280.dp, windowHeight * 0.45f)`；
     - 窗口高 `< 480.dp`：`min(280.dp, windowHeight * 0.35f)`；
   - 表情面板为纯色表面（**0 个 `HiGlassMarker`**），在三栏右栏 `QuickReplySheet` 内展开时不突破 `≤ 3 / ≤ 2 / ≤ 5` 玻璃预算且严格限于右栏宽度内不跨分隔线；
   - 面板打开/关闭与减动效兼容：`HiTheme.isReducedMotion == true` 时一帧 0ms 到位，无残留中间态。
3. **表情网格、分类标签与闭合 `C1b#3`（`feature/compose/emoji/EmojiPickerPanel.kt`、`strings_emoji.xml`）**：
