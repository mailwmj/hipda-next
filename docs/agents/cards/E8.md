【范围】
1. **消息页形态适配（纯色顶栏，零毛玻璃）**：
   - 单栏（`< 600dp` / 矮屏）：纯色顶栏，下方双标签 `短消息` | `提醒`（Compose 标准 `SingleChoiceSegmentedButtonRow` 或 `TabRow`，动效用 `HiMotion.spatialFast()`）；切至 `提醒` 标签时顶栏显示 `全部已读` 动作按钮。
   - 宽屏侧栏态（`≥ 600dp`）：左栏已拆出独立 `短消息` 与 `提醒` 入口，中栏顶栏隐藏标签行；三栏右栏未选中时分别显示 `选一条短消息开始查看` / `选一条提醒查看对应帖子`。
2. **短消息会话列表与对话（§7.5）**：
   - 会话列表：圆形头像、用户名、摘要、时间、未读标记；下拉刷新；空态 `暂无短消息`；未登录原地 `需要登录才能查看`（按钮 `登录`）；支持清空会话二次确认（标题 `清空与 {用户名} 的全部短消息？`、副行 `清空后无法恢复。`、按钮 `取消`/`清空`）。
   - 对话页（单栏二级页或三栏右栏）：纯色顶栏（含返回按钮与对方用户名）+ 气泡列表 + 底部输入条（纯色背景，零毛玻璃）。
   - **乐观发送与失败处理**：点发送立即以气泡插入末尾并在气泡旁显示小进度圈（内容描述 `正在发送…`），服务器确认后进度圈消失；发送失败在气泡旁常驻红色感叹号（内容描述 `发送失败`），点击弹出 `重发` / `删除`（删除立即生效并经 `LocalPaneSnackbarController` 弹 `已删除` + `撤销`）。
   - **15 秒冷却**：发送成功后发送按钮原地切换为剩余秒数倒计时（向上取整，无障碍 `{N} 秒后可发送`），倒计时期间允许继续编辑输入，结束恢复发送按钮。
   - **内容渲染与 scheme 白名单**：对话气泡支持 `:emoji` C1b 表情；任何站点链接/图片打开或加载必须强制走 `http` / `https` / 经校验 `mailto`（图片仅 `http`/`https`）白名单，并配全套危险 scheme（`javascript:`、`intent:`、`file:`、`content:`、`data:` 及大小写/空白/控制字符绕过）反例测试。
3. **提醒列表（§7.6）**：
   - 展示帖子/回复/引用/系统提醒，明确区分已读与未读；下拉刷新与分页加载；空态 `暂无提醒`；未登录原地提示登录。
   - **按单条已读**：点击某条提醒时才标记该条已读并触发 `onOpenThread(ThreadNavArgs(..., targetPid = ...))`（绝不进入页面就全部清零）；顶栏 `全部已读` 为独立操作，成功后发 Snackbar `已全部标为已读`。
4. **收口 `R-D9 S2`（系统通知文案归口）**：
   - 在 `docs/design/copy.md` 追加「系统通知」小节记录通知渠道名与标题/正文标准文案（严格遵循 §8 术语表，禁止“私信/站内信/信息提醒/消息通知”）；
   - 新增 `hipda/src/main/res/values/strings_notification.xml`，将 `service/NotificationPoster.kt` 中硬编码的渠道名、默认标题与汇总/单条格式迁入字符串资源（经 `Context` 读取），纳入 `CopyTerminologyScanTest` 守卫并保证既有 `NotificationPollingWorkerTest` 全绿。
