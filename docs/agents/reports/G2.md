## 1. 第一步：Tracer Bullet（最小探针）与 Roborazzi 渲染实测评估

在全面重写前，先单独引入 `io.github.kyant0:backdrop:2.0.1`，完成依赖解析、字节码核查、最小 `HiGlassSurface` 探针渲染及 Release 构建验证（探针临时文件随后已彻底删除）。

### 1.1 依赖解析与兼容核验
- **Maven 坐标**：`io.github.kyant0:backdrop:2.0.1`（解析为 `backdrop-android:2.0.1`，`minSdk = 21`，Apache-2.0），传递引入运行时依赖 `io.github.kyant0:shapes:1.2.1`（`shapes-android:1.2.1`，Apache-2.0，为 `implementation` 作用域，不暴露给上游编译类路径）。
- **Compose BOM / Kotlin 对齐**：经 Gradle 依赖树核验，`androidx.compose.ui:ui` 维持 `compose-bom:2026.11.01` 锁定的 `1.13.0`，`kotlin-stdlib` 对齐项目 `2.4.21`，`androidx.window` 保持 `1.5.1`，**零传递冲突，无需改动 BOM**。
- **AAR 字节码核查（`javap`）**：
  - `backdrop-android-2.0.1.aar` 不含 `proguard.txt`，但全部类均为标准 Compose `Modifier.Node` / `DrawScope` / `RenderEffect` / `RuntimeShader` 静态调用，**无反射**。
  - 确认 `backdrop 2.0.1` **无噪点（noise）API**，因此移除旧 Haze 遗留的死参数 `NoiseFactor` / `noiseFactor` 及无效调参滑杆，不留空转控件。
  - 确认 `PlatformKt.isRenderEffectSupported()` = `SDK_INT >= 31`，`isRuntimeShaderSupported()` = `SDK_INT >= 33`。
  - 确认 `LensKt.lens` 仅支持圆角形状（`CornerBasedShape` / `AbsoluteRoundedCornerShape` / `RoundedRectangularShape`），对 `RectangleShape` 会抛 `UnsupportedOperationException`；因此我们在 `HiGlassSurface` 内将 `RectangleShape` 统一映射为 `RoundedCornerShape(0.dp)` 并以 `shape is CornerBasedShape` 守卫 `lens(...)`。
  - 确认 `LayerBackdropNode.draw` 只要节点挂在树上就会持续离屏录制，卸载（`onDetach`）时清空 `layerCoordinates = null`；因此通过 `HiGlassState.hasSourceDemand` 引用计数，在降级态卸下 `Modifier.layerBackdrop(backdrop)` 即可彻底释放离屏拷贝开销。

### 1.2 Robolectric + Roborazzi 跨 API 实测表现
在 `GraphicsMode.NATIVE` 下用高对比棋盘格背景实测 `rememberLayerBackdrop` + `layerBackdrop` + `drawBackdrop`：

| Robolectric API | 实测渲染结果 | 关键发现与工程处理 |
| --- | --- | --- |
| **API 35** | **真实渲染模糊 + 真实 AGSL `lens` 边缘折射 + 真实色散** | 像素对比实测：`blur_only` vs `blur+lens` 有 `48,712 / 493,200` 像素变化（`max_channel_diff = 191`）；`blur+lens` vs `blur+lens+chromaticAberration` 有 `39,749 / 493,200` 像素变化（`max_channel_diff = 149`）。API 35 在 Robolectric 4.18.1 下启用 Android 15 原生 RuntimeShader，完整支持 AGSL。 |
| **API 34** | **真实渲染 `blur()` + `vibrancy()`/`colorControls()`；`RuntimeShader` 抛出 `IllegalArgumentException`** | 根因：Robolectric 4.18.1 的 `ShadowNativeRuntimeShader`（`maxSdk = 34`）底层是 Android 12 SkSL 编译器，不支持 AGSL 的 `layout(color)`（`HighlightStyle.Default`）与 `content.eval(...)`（`LensKt.lens`）。处理：① `drawBackdrop` 传入 `highlight = null, shadow = null`（沿用我们自己的 Compose 方向渐变高光描边与阴影）；② 对 `lens(...)` 增加 `try/catch(IllegalArgumentException)` 兜底，在非标准/SkSL 运行时静默降级为纯模糊+活色而不崩溃，兼容既有 `@Config(sdk = [34])` 的壳/主题测试；③ 折射真机效果与 Roborazzi 截图验证统一用 `@Config(sdk = [35])`。 |
| **API 31** | **真实渲染 `BlurEffect` + `ColorFilter`（无折射）** | `BLUR_ONLY` 档位下 `lens()` 从不被调用，纯模糊 + 活色渲染干净。 |
| **API 30** | **94% 近不透明纯色降级** | `SOLID_DEGRADED` 档位下不挂载 `drawBackdrop` 与 `layerBackdrop`，渲染稳定无波动。 |
| **API 36** | Robolectric 需 Java 21（项目为 JDK 17） | 本地 Robolectric 折射测试用 `@Config(sdk = [35])`，API 36 真机/模拟器运行由 CI `Emulator Smoke Test (API 36)` 覆盖。 |

   - 降级态释放录制开销：`HiGlassSurface` 通过 `DisposableEffect(state, useBackdrop)` 管理 `HiGlassState.acquireSourceDemand()` / `releaseSourceDemand()`，`Modifier.hiGlassSource(state)` 仅在 `hasSourceDemand == true` 时挂载 `layerBackdrop(backdrop)`。
   - 闭合 R-G1 遗留：浅色激活态双层 `.border(...)` 调整顺序，使 `0.5dp` 暗轮廓（`outlineModifier`）在内/垫底、`0.75dp` 白渐变高光（`highlightModifier`）在外/居上。
   - 保持全部 20 套主题预设在降级态最差背景下的 WCAG 对比度 ≥ 4.5:1。
4. **Debug 调参面板（仅 `src/debug/`）**：
   - `GlassTuningPanel.kt`：移除无效的噪点滑杆，新增折射高度（`0–32dp`）、折射强度（`0–48dp`）滑杆及 `vibrancyEnabled` / `depthEffect` / `chromaticAberration` 三个 M3 `Switch` 开关；对彩虹背景 `rainbowBrush` 使用 `remember` 缓存（闭合 R-G1 建议）；更新 `formatGlassStyleParams(style)` 为单行 `Locale.US` 稳定格式：
     `blur=%.1fdp refractH=%.1fdp refractAmt=%.1fdp depth=%s ca=%s vibrancy=%s lightTint=%.2f darkTint=%.2f sat=%.2f border=%.2f indicator=%.2f`。
   - `PreviewActivity.kt` & `strings_preview.xml`：新增 `GlassPreviewMode.FORCE_BLUR_ONLY` 档位切换与三档状态文案。
   - 架构纯洁性：零手写自定义 `Layout` / `Modifier.Node`；`src/main` 零 `src/debug` 引用；`MotionTokenScanTest` 未改白名单且 7/7 全绿。
