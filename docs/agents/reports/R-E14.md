### 1. 「分享」在不改 `AndroidManifest.xml` 的前提下如何拿到可用 `content://` URI？

1. **主 `AndroidManifest.xml` 与 `@xml/provider_paths` 配置核实**：

2. **生成 URI 路径合法性与权限标志核实（[ImageViewerMediaActions.kt:53-81](file:///home/mir/Documents/hipda-next.wt/E14/hipda/src/main/java/net/jejer/hipda/feature/imageviewer/ImageViewerMediaActions.kt#L53-L81)）**：

### 3. 原图下载取消：底层 `Call.cancel()` 与 `.part` 临时文件清理核查

- **生产链路核实（[OriginalImageDownloader.kt:53-129](file:///home/mir/Documents/hipda-next.wt/E14/hipda/src/main/java/net/jejer/hipda/feature/imageviewer/OriginalImageDownloader.kt#L53-L129)、[ImageViewerOverlay.kt:111, 181, 265-290](file:///home/mir/Documents/hipda-next.wt/E14/hipda/src/main/java/net/jejer/hipda/feature/imageviewer/ImageViewerOverlay.kt#L265-L290)）**：

  2. **先关流、再删 `.part` 临时文件、零句柄泄漏**：
     - 取消在挂起点（`emit` / `ensureActive`）触发时，先退出内层 `FileOutputStream(partFile).use`、`body.byteStream().use` 与 `call.execute().use` 关闭文件描述符和响应体，再进入 `catch (cancelled: CancellationException)`（`:116-119`）执行 `call.cancel()`、`tempFile?.delete()` 并重抛 `cancelled`；

     - `finally`（`:126-128`）统一执行 `cancelHandle?.dispose()`；此外 `totalBytes != null && bytesRead < totalBytes` 短读异常分支（`:101-105`）也显式执行 `partFile.delete()`。
