     1. `feature/threaddetail/body/PostBodyRenderer.kt`（`sanitizePostUrl` → `SafeLinkPolicy.sanitizeLinkUrl`）
     2. `feature/search/ForumLinkGuard.kt`（`sanitizeAllowedForumUrl` → `SafeLinkPolicy.sanitizeHttpUrl`）

2. **裁定 2（未知外部链接行为与防 Intent 循环）**：
