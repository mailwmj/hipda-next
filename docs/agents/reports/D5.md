## 二、核心设计与健壮性说明

1. **稳定不可变领域模型与统一错误分级（`ThreadDetailModels.kt`）**：
   - `ThreadDetailFloorItem(floor: PostFloor, isAuthorBlocked: Boolean)` 提供稳定主键 `postId`，直接组合复用 `B8` `ThreadDetailPage`/`PostFloor`/`ThreadPoll`，便于 `E2a`–`E2c`/`E3` 跨单栏/图标轨/铰链双栏/三栏无损迁移。
   - `ThreadDetailError` 同时实现 `ThreadDetailLoadResult` 与 `PollVoteResult`，细分 `AuthRequired`、`ChallengeRequired`、`NetworkError`、`SiteError`、`InvalidPage`、`InvalidInput`；仅捕获 `IOException`，绝不吞掉 `CancellationException`（已由并发取消单测验证）。
2. **分页、只看过滤、末页与定位加载（`DefaultThreadDetailRepository.kt`）**：
   - 常规/只看加载走 `viewthread.php?tid={tid}&page={page}[&authorid={uid}]`；当 `filter` 为 `AuthorOnly(authorId = null)` 时，先请求第 1 页并经 `B8` `ThreadDetailParser.parseThreadAuthorId` 解析楼主 UID（若第 1 页报错或无帖子列表立即短路，不发第二次请求、不写历史），再拼 `&authorid=` 拉取目标页并在结果中回传解析后的 `AuthorOnly(authorId)` 与 `threadAuthorId`。
   - `loadLastPage` 走 `redirect.php?goto=lastpost&from=fastpost&tid={tid}`；`loadByPostId` 有 `tid` 走 `redirect.php?goto=findpost&pid={pid}&ptid={tid}`、无 `tid` 走 `gotopost.php?pid={pid}`，并从重定向落地 URL 或 DOM 自动回退解析实际 `tid` 与 `page`。
   - 每次请求动态读取 `SettingsRepository.settings.first().forumServer` 推导 `forumBaseUrl`（自动去重尾部 `/forum`）与 `avatarBaseUrl` 传入 `ThreadDetailParser.parse`。
   - 鉴权策略：已登录态（`authRepository.currentAccount.value != null`）传 `requireAuth = true` 自动享 `D2` `ForumHttpClient` 单飞静默重登一次；游客/手动退出态传 `requireAuth = false` 允许浏览公开帖，遇需登录提示或登录表单返回 `AuthRequired`、遇删帖/无权限等站点报错返回 `SiteError`。
3. **浏览历史自动写入/裁剪与阅读位置记忆**：
   - 成功加载且 `recordHistory == true`、具合法 `tid` 与非空 `title` 时，提取 `forumName`（调用方优先，缺省从 `div#nav` 链接解码提取）与楼主/首楼作者，调用 `browseHistoryDao.upsert(...)` 并立即 `browseHistoryDao.trimTo(maxBrowseHistory)`（默认 `500`，支持测试构造注入）。
   - `getReadingPosition` / `saveReadingPosition` 完整保留 `page`、`pid`、`offsetPx` 与 `ReadingFilterMode`（`NONE` 自动清空 `filterUid`/`filterUserName`，并钳制 `page >= 1`、`offsetPx >= 0`）。
4. **黑名单响应式遮蔽/过滤**：
   - `observeFloors(floorsFlow)` 与 `observeVisibleFloors(floorsFlow)` 通过 `combine(floorsFlow, blacklistRepository.blockedUsernames)` + `distinctUntilChanged()` 实时重算 `isAuthorBlocked` / 隐藏视图；提供 `mapFloorsWithBlacklist`、`filterBlockedFloors` 同步便捷函数，全程 **0 额外网络请求**。
5. **1 楼投票提交与结果自动刷新**：
   - 前置校验 `fid > 0`、正整数 `tid`、非空 `formhash`、`maxChoices >= 1`、去重非空 `optionIds` 且不超过 `maxChoices`，以及登录态强制门控（未登录/手动退出直接返回 `AuthRequired`，**0 网络请求**）。
   - 表单按 `formhash` + 字典序排序的重复键 `pollanswers[]` 经 `ForumHttpClient.postGbkForm("misc.php?action=votepoll&fid=$fid&tid=$tid&pollsubmit=yes&quickforward=yes&inajax=1", fields, requireAuth = false)` 提交，避免无 `#umenu` 的 AJAX XML 误触发未登录重试死循环。
   - 严格区分成功（AJAX XML 成功文案 / quickforward JS 跳转 / 已登录态 302 落地页）与失败（XML/`div.alert_error`/`div.alert_info` 报错、含延迟跳转脚本的报错 XML、未登录落地页）：失败不刷新并直接返回 `SiteError`/`AuthRequired`；成功后若 302 已落到已登录态第 1 页则直接解析复用，否则自动重拉第 1 页（`recordHistory = false`）返回最新 `ThreadDetailPage` 与 `ThreadPoll`。
