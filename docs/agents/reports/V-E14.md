## 4. FAIL 项触发路径与源码根因

### 缺陷 1：E2b 上方图片撑高后，真实链路看图退出飞回过期缩略图坐标（`probeM1b` FAIL）

- **触发路径**：在 `NextAppRoot + ThreadDetailPane + E14 ImageViewerRendererImpl` 中点击贴内第 2 张缩略图打开看图（[PostImageBlock.kt#L302-L310](file:///home/mir/Documents/hipda-next.wt/V-E14/hipda/src/main/java/net/jejer/hipda/feature/threaddetail/media/PostImageBlock.kt#L302-L310)），看图期间上方尚未完成测量的 E2b 图片加载完毕撑高列表，第 2 张缩略图实际窗口坐标从 `Rect(32.0, 897.0, 790.0, 1466.0)` 下移到 `Rect(32.0, 1181.0, 790.0, 1750.0)`；点击关闭退出时，动画末帧停在 `Rect(32.0, 897.3, 790.0, 1466.7)`，偏差 `~283.7px`。
- **源码根因**：
  1. `PostImageBlock.kt#L302-L310` 点击时仅把静态快照 `sourceBoundsInWindow = layoutTracker.boundsInWindow` 写入 `ImageViewerLaunchArgs`。
  2. `FeaturePaneSlots.kt#L116-L122` 定义的 `ImageViewerRenderer.Overlay(args, onDismiss)` 与 `NextAppRoot.kt#L192-L194,L277-L279` 没有透传实时坐标查询回调（或 `PostImageBlock` 按 URL/key 追踪的实时 `boundsInWindow` 查找表）。
  3. `ImageViewerOverlay.kt#L47-L55,L68` 中 `ImageViewerRendererImpl.Overlay` 直接使用默认参数 `resolveBoundsForIndex = { if (it == args.initialIndex) args.sourceBoundsInWindow else null }`，永远回读点击瞬间的旧 `sourceBoundsInWindow`。

### 缺陷 2：看图退场动画进行中连按两次系统返回，会穿透关闭底层帖子（`probeM3b` FAIL）

- **触发路径**：在单栏或详情页中点击打开看图浮层后先触发退场（例如点关闭按钮或发起一次返回进入 `ViewerTransitionPhase.Dismissing`），退场动画第 1 帧仍在播放且浮层可见时**连续按两次返回**，最终 `harness.hostViewModel.state.value.selectedThread?.tid` 从 `"1001"` 变为 `null`。
- **源码根因**：
  1. [ImageViewerOverlay.kt#L176,L246-L248](file:///home/mir/Documents/hipda-next.wt/V-E14/hipda/src/main/java/net/jejer/hipda/feature/imageviewer/ImageViewerOverlay.kt#L176-L248) 在 `phase == ViewerTransitionPhase.Dismissing` 时直接将自身的 `BackHandler(enabled = phase != ViewerTransitionPhase.Dismissing)` **禁用**。
  2. 退场动画进行中收到**第 1 次 Back** 时，E14 的 `BackHandler` 未启用，请求立刻下落到 `NextAppRoot.kt#L276` 的兜底 `BackHandler(enabled = isImageViewerOpen) { activeImageViewerArgs = null }`，把浮层直接置空并让 `isImageViewerOpen` 变为 `false`。
  3. 同一退场窗口紧接着到来的**第 2 次 Back** 时，`NextAppRoot` 与 E14 两个 `BackHandler` 均已关闭，直接穿透到 `MultiPaneReadingContainer.kt#L235-L238` 的 `hostViewModel.handleBack(...)`，误关闭底层帖子。

### 缺陷 3：933dp 三栏下打开全屏看图时，底层玻璃标记未清零（`probeM4` FAIL）

- **触发路径**：在 `w933dp-h696dp` 三栏态打开看图，`ImageViewerOverlay` 已渲染 `PaneTitle = "看图"` 且边界严格覆盖 `0..933dp × 0..696dp`；但随即执行 `assertGlassSurfaceCountAtMost(0)` 失败：`Expected at most 0 glass regions on screen, but found 2`。
