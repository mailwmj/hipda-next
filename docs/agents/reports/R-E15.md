- **逐层清理与并发代际守卫核实（对照基线 `DefaultAuthRepository.kt:407-423, 1058-1080` 及各仓库）**：
  1. **D2 代际与单飞重登拦截**：`DefaultAuthRepository.logout()` 在 `operationMutex.withLock` + `runExplicitOperation` 下先取消并 `join` 在途前/后台静默重登，写 `credentialsStore.markManualLogout()`（持久化 `manuallyLoggedOut = true, activeUid = null`），并在 `cookieWriteLock -> stateLock` 锁序下递增 `authGeneration++`、置 `_currentAccount.value = null` 与 `_authState.value = SignedOut`——任何退登前已发出的在途 HTTP 响应在晚到时都会被 `AppCookieInterceptor` 的 `AuthCookieWriteGuard` 拦截丢弃 `cdb_auth`/`cdb_sid`，杜绝晚到包复活会话；后续请求遇未登录时因 `manuallyLoggedOut == true` 直接返回 `SilentReloginResult.Suppressed`（0 网络重登请求）。
  2. **双端 Cookie 清理**：`clearAuthCookiesForServer(forumServer)` 在 `cookieWriteLock` 下清除 `SiteCookieStore` 论坛认证 Cookie，并切至 `@WebViewCookieDispatcher` 清除 Android `WebView` `CookieManager` 各作用域下的登录 Cookie 并 `flush()`（仅保留 `cf_clearance`/`__cf_bm`）。
  3. **各业务仓库账号作用域缓存联动清空**：随 `authRepository.currentAccount` 由 `uid -> null` 发射：
     - `DefaultFavoriteRepository.kt:65-73` 立即清空内存 `_activeSnapshot` 为空 `FavoriteCacheSnapshot()`；
     - `DefaultBlacklistRepository.kt:66-74` 立即清空 `cachedFormhash = null` 并发布空 `BlacklistSnapshot()`；
     - `DefaultNotifyRepository.kt:97, 510-539` 立即递增 `accountGeneration` 并清零内存未读计数与列表条目；
     - `DefaultSmsRepository.kt:74` 与 `DefaultPostRepository.kt:84` 立即重置按账号绑定的发送冷却计时；
     - `ForumViewModel.kt:96-99` 监听 `uid` 变化自动清空 `initializedQueries` / `todayNewInitialized` 并重刷当前列表；
     - `NotificationPollingWorker.kt:102, 119` 检测到 `currentAccount.value == null` 自动跳过后台轮询。
  4. **浮层关闭与提示时序**：`LoginViewModel.logout()` 在 `finally` 先复位 `isLoggingOut = false`，随后先 `onDismiss()` 卸载临时弹窗、再在 Activity 级 `viewModelScope` 中调用 `snackbarController.show("已退出登录")`（`LoginViewModel.kt:166-171`），既避免 `SnackbarDuration.Short`（4s）挂起阻塞按钮复位，又保证浮层卸载不中断宿主 Snackbar 展示。
