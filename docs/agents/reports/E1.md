## 4. 关键工程决策记录

1. **沿用基线 `ForumListSource.TodayNew` / `ForumListSource.Forum(fid)`**：`db7dba6`（E0 修复轮 1）已移除草案 `TODAY_NEW_FID = -1`，采用类型安全 sealed hierarchy，避免与任何业务 fid 冲突并保持 `NextAppRoot` 零改动。
2. **展开/折叠 `0dp` 跳动与滚动 0 重组**：`ForumPane` 将 `LazyColumn` 的 `contentPadding(top)` 固定为顶栏展开高度（不读取 `collapseOffsetPx`）；`ForumTopBar` 在 `graphicsLayer` 与 `drawBehind` 阶段读取折叠位移与玻璃过渡 alpha，滚动过程零冗余重组。
3. **荧光笔峰值 alpha 向下 8-bit 量化**：Compose `Color.copy(alpha = 0.45f)` 经 8-bit 四舍五入后实际为 `115/255 ≈ 0.45098f` 会越过 `0.45f` 上限；通过 `floor(rawPeak * 255f) / 255f` 保证深色 `114/255 = 0.4471f <= 0.45f`、浅色 `140/255 = 0.5490f <= 0.55f`，且 4 停靠点横向渐变在浅/深/OLED 20 预设下清晰可辨并满足 WCAG `>= 4.5:1`。
4. **列表行按压反馈分工**：遵循 `product-design.md §6.3`，长列表帖子行使用 `hiListItemPressIndication()` 状态层，图标按钮 / 版块标签 / 新帖胶囊使用 `hiPressScale()` 微缩放。
5. **配置感知资源读取**：`ForumPane` 刷新失败 Snackbar 文案改用 `LocalResources.current`，消除 `LocalContextGetResourceValueCall` 告警，使 E1 范围 Lint 告警归零。
