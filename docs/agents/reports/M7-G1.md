### 2. `#3` 点顶栏空白滚回顶部（设计系统统一基座 + 列表页接线）

  - `LazyListState.hiScrollToTop(reducedMotion)` / `ScrollState.hiScrollToTop(reducedMotion)` 与 `rememberHiScrollToTopAction(...)`：常规动效下平滑滚回顶部（`animateScrollToItem(0)` / `animateScrollTo(0, HiMotion.spatialDefault())`），`HiTheme.isReducedMotion == true` 时单帧 `scrollToItem(0)` / `scrollTo(0)` 到位。

### 4. `#8` 用户资料页点大头像清 Coil 缓存并重载
- **实现落点**：`feature/profile/UserProfileScreen.kt`（`evictProfileAvatarCache` + `ProfileFixedHeader`）、`res/values/strings_profile.xml`。
- **行为闭环**：
  - `64dp` 大头像显式设置 `memoryCacheKey(safeAvatar)` 与 `diskCacheKey(safeAvatar)` 并绑定 `.clickable(role = Role.Button)`。
  - 当 `safeAvatar != null`：点击后清除 `imageLoader.memoryCache` 中所有 `key == safeAvatar` 的条目（覆盖带尺寸 extras 的 `MemoryCache.Key`），在 `Dispatchers.IO` 调用 `imageLoader.diskCache?.remove(safeAvatar)`，随后递增 `avatarReloadNonce`；以 `key(avatarReloadNonce)` 绕过 Coil 3 `DefaultModelEqualityDelegate` 忽略 extras/`CachePolicy` 的限制确保确定性重新加载，同时使用 `lastAvatarPainter` 作为 `placeholder` 防止重载闪烁，首次刷新请求设置 `CachePolicy.WRITE_ONLY` 绕过旧缓存；通过 `LocalPaneSnackbarController` 提示 `头像已经刷新`。
  - 当 `safeAvatar == null`：不清除任何缓存、0 网络请求，提示 `用户未设置头像`。
