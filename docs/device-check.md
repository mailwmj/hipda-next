# 真机操作清单

适用版本：`main` @ `d45b6a2`（含 C4c 三栏外壳、G1 毛玻璃调参与 debug 调参面板）。M1 与 M4 已于 2026-11-25 验收通过，第一、二节留作记录。

## 0. 取安装包

debug 包在 CI 产物里（私有仓库，需登录 GitHub）：

- 网页：<https://github.com/mailwmj/hipda-next/actions/runs/45608688264> → 页面底部 Artifacts → `debug-apk`（下载后解压得到 `hipda-debug.apk`）
- 命令行：`gh run download 45608688264 -R mailwmj/hipda-next -n debug-apk`

安装：`adb install -r hipda-debug.apk`。包名 `net.jejer.hipda.next`，可与旧版并存。

> 2026-11-25 第一次实测因 UA 含 `Android` 拿到手机版模板而全部失败，已由 A5c 修复。请先卸载旧的 debug 包（或直接覆盖安装），重新登录后再抓取；遇到 Cloudflare 验证时留意能否在 WebView 里正常通过。

## 当前待办：毛玻璃调参（约 5 分钟）

1. 安装上面的新包（覆盖安装即可）。
2. 打开「**HiPDA 预览**」→「**外壳**」→ 打开「**调参**」面板。
3. 先看默认效果：彩带背景从胶囊下滑过时，透色是否干净、字是否清楚；深色、浅色各看一次。
4. 拖动滑杆调到满意（模糊、着色透明度亮/暗、饱和度、噪点、描边高光、指示器透明度）。
5. 点「**复制当前参数**」，把复制出的那一行发给负责人；深色和浅色如果想要不同值，各复制一次。

顺便看三栏外壳（同在「外壳」页）：内屏展开横拿应是左侧图标栏 + 列表 + 帖子三栏；点图标栏顶部按钮展开完整侧栏，按返回或点遮罩关闭；竖拿应是单栏 + 底部胶囊。有不顺手的地方一并告诉负责人。

## 一、样本导出 + M1 验收（约 10 分钟，已完成）

全程只发只读 GET 请求：不发帖、不回复、不发短消息、不改收藏，不保存密码。

1. 打开桌面「**HiPDA 预览**」→ 右上角「**样本导出**」。
2. 点「**登录**」，在内置网页里登录论坛（先出现 Cloudflare 验证就先完成验证）。
3. 登录后点「**完成登录**」，确认顶部显示「**已登录**」。
4. 隐私开关「**包含我的帖子、我的回复与收藏**」：这三页已去掉账号名、UID、令牌，但保留帖子编号，可在论坛反查到你。仓库以后若可能公开，建议关闭。
5. 点「**一键抓取并导出**」。中途弹出验证就按提示完成，抓取会自动继续。
6. **M1 验收**：第 1 项「版块列表 · 第 1 页」变为「**成功**」后截图，画面里要同时有「已登录」和这一项。
7. 个别项「失败」可点「重试」；出现「**脱敏校验未通过**」的项不会进压缩包，把详情记下来反馈即可。
8. 完成后点「**分享**」，把 `hipda-samples-<时间戳>.zip` 传到那台电脑。

## 二、M4 外壳验收（已完成）

「HiPDA 预览」→「**外壳**」：

1. **毛玻璃**：底部导航胶囊后面的内容是否真的模糊透出；深色、浅色各看一次；浅色下文字是否清楚。
2. **滚动**：快速上下滑，导航隐藏和出现是否顺滑，有无明显卡顿或闪烁。
3. **旋转 / 折叠**：横竖屏切换、折叠屏展开合上，布局是否正常、有无崩溃。
