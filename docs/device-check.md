# 真机操作清单

适用版本：`main` @ `21b1e3c`（含 C4c 三栏外壳、G2 液态玻璃、C4d 顶栏/面板玻璃档位与胶囊拖拽）。M1 与 M4 已于 2026-11-25 验收通过，第一、二节留作记录。

## 0. 取安装包

debug 包在 CI 产物里（私有仓库，需登录 GitHub）：

- 网页：<https://github.com/mailwmj/hipda-next/actions/runs/45645519789> → 页面底部 Artifacts → `debug-apk`（下载后解压得到 `hipda-debug.apk`）
- 命令行：`gh run download 45645519789 -R mailwmj/hipda-next -n debug-apk`

安装：`adb install -r hipda-debug.apk`。包名 `net.jejer.hipda.next`，可与旧版并存。

> 2026-11-25 第一次实测因 UA 含 `Android` 拿到手机版模板而全部失败，已由 A5c 修复。请先卸载旧的 debug 包（或直接覆盖安装），重新登录后再抓取；遇到 Cloudflare 验证时留意能否在 WebView 里正常通过。

## 当前待办：液态玻璃定稿 + 外壳手感（约 10 分钟）

1. 覆盖安装上面的新包，打开「**HiPDA 预览**」→「**外壳**」→ 展开「**调参**」面板。面板分四组：底部胶囊、工具条、顶栏、面板。
2. 每组先看默认效果：彩带从玻璃下滑过时透色是否干净、字是否清楚、折射是否自然（Android 13+）；深色、浅色各看一次。
3. 拖滑杆调到满意，点「**复制当前参数**」，把复制出的那一行发给负责人；某组默认就满意的，说"某组默认就行"。
4. 顺便试外壳手感：按住底部胶囊左右拖动预选、松手切换；手指上下拖离胶囊应弹回；内屏横拿三栏、点图标栏顶部按钮展开侧栏、返回关闭；滑动时是否流畅、有无掉帧。
5. 有不顺手的地方一并告诉负责人。

### W2 合入后真机验证（待出包）

> 待 Wave 2（`E1`、`E2a`、`E15`）全部合入 `main` 并产出新 `debug-apk` 后执行。

1. **登录和退出**：打开「**我的**」页的账号入口，用真实账号完成登录；随后点账号入口执行「**退出登录**」，确认退出后不再自动静默重登并可重新登录。
2. **Cloudflare 验证**：若触发安全验证，确认后台等待超过 2 秒时原地提示「正在检查安全环境…」，弹出验证面板后可正常完成验证并自动续行。
3. **顶栏玻璃**：检查论坛透明吸顶顶栏（含吸顶版块标签行与荧光笔选中高光）及帖子详情透明极简顶栏（含轻底圆形按钮），在浅色与深色模式下文字是否清晰、滚动是否顺滑无闪烁。
4. **单栏和三栏切换时阅读位置不丢**：在外屏单栏打开帖子并向下滚动到中间楼层，展开内屏切到三栏、再合上切回单栏并返回列表，确认帖子阅读位置与列表滚动位置均不重置且无重复刷网。
5. **今日新帖**：切换至「**今日新帖**」浏览帖子列表并向下翻页，确认内容正常加载、打开阅读与筛选表现一致。

## 一、样本导出 + M1 验收（约 10 分钟，已完成）

全程只发只读 GET 请求：不发帖、不回复、不发短消息、不改收藏，不保存密码。

1. 打开桌面「**HiPDA 预览**」→ 右上角「**样本导出**」。
2. 点「**登录**」，在内置网页里登录论坛（先出现 Cloudflare 验证就先完成验证）。
3. 登录后点「**完成登录**」，确认顶部显示「**已登录**」。
4. 隐私开关「**包含我的帖子、我的回复与收藏**」：这三页已去掉账号名、UID、令牌，但保留帖子编号，可在论坛反查到你。仓库以后若可能公开，建议关闭。
5. 点「**一键抓取并导出**」。中途弹出验证就按提示完成，抓取会自动继续。
6. **M1 验收**：第 1 项「版块列表 · 第 1 页」变为「**成功**」后截图，画面里要同时有「已登录」和这一项。
7. 个别项「失败」可点「重试」；出现「**脱敏校验未通过**」的项不会进压缩包，把详情记下来反馈即可。
8. 完成后点「**分享**」，把 `hipda-samples-<时间戳>.zip` 传到那台电脑。

## 二、M4 外壳验收（已完成）

「HiPDA 预览」→「**外壳**」：

1. **毛玻璃**：底部导航胶囊后面的内容是否真的模糊透出；深色、浅色各看一次；浅色下文字是否清楚。
2. **滚动**：快速上下滑，导航隐藏和出现是否顺滑，有无明显卡顿或闪烁。
3. **旋转 / 折叠**：横竖屏切换、折叠屏展开合上，布局是否正常、有无崩溃。
